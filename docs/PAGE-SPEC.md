# 原型页面当前约束

本文整理项目 AGENTS 中仍有效的页面约束。按任务读取对应章节；版本独有规则不跨版本套用。5.12.0 的模型运营与分析细节见[版本页面规格](../versions/moma_5.12.0_estack/PAGE-SPEC.md)，它覆盖本文明确标为 5.11.0 的旧业务结构。本文描述要求，不证明现有实现或发布已完成。

## 正式文案与交互

- 页面、弹窗、Tooltip、反馈、生成结果、复制文本和无障碍名称采用正式业务表达；不加入“模拟”“演示”“原型”“示例订购”等实施说明。实现边界记录在研发文档；权限、统计口径、有效期、失败反馈和 AI 内容核验说明保留。版本规定的“研发人员注意”入口遵守其专用例外。
- 已保存的已知样例文案通过显示层转换；不重写稳定 ID、正常用户自定义内容或业务状态。部署场景称“部署方式”。常驻文字只呈现业务信息和必要操作；分页保留记录数与操作，统计口径放在标题旁可键盘访问的 Tooltip，异常说明按实际条件出现。
- 后台反馈使用已有 Sonner：保存成功后才提示成功，失败保留输入；复制成功后才显示成功态。字段错误、持续冲突/存储错误、未保存确认、批量逐行结果和密码交接不能被短暂通知替代。普通导航与筛选不弹通知。
- 面包屑使用真实父路径和当前项语义；返回列表保留筛选和分页。详情不重复添加返回按钮，取消、向导上一步、关闭和错误恢复保留。弹层关闭恢复触发焦点；长表格在局部滚动，固定表头与操作区保持可达。
- 分页复用目标页面的共享配置；通常为 20/50/100、默认 20，版本明确保留的选择器例外继续有效。容量变化由调用方一次更新容量和第一页，避免重复回调覆盖 URL；视觉整理不改变分页政策。

## 订购与租户 API Key

- 5.10.2/5.11.0 的模型订购保持移动云风格的密集表格、筛选和按量付费/Token Plan 分类；不增加资源包或 Coding Plan 购买入口。独立订购页在当前版本新标签打开，完整处理规格、数量、有效期、协议、费用摘要、确认与结果。
- Token Plan 重复购买按订阅 ID 分开；API Key 页只有按量付费/Token Plan 两个页签。Token Plan 左侧为已购订阅搜索列表，右侧复用 Key 工作区；订阅 ID/有效期留在列表，页头一行显示名称、创建、搜索和工具。切换保留各订阅的凭证、编辑、搜索及分页；创建/编辑固定所属订阅，不出现按量配额控制。
- Key 名称/Key ID 与 API Key 分开；所有凭证显示复用目标版本 `api-key-utils.mjs` 的 `maskApiKey`：最多 8 位已有前缀、5 个星号、最多 4 位已有后缀，不补造隐藏字符，缺失显示 —，过短未脱敏值完全隐藏。复制底层凭证只沿用原来明确的复制入口；日志及其导出始终脱敏。
- Key 复制成功后图标显示绿色勾两秒；编辑、重置、删除及确认、模型访问列表和 IP 白名单回显保留。白名单校验 IPv4/CIDR、去重，空集合表示不限；这些本地配置不证明网关已执行。
- 5.11.0 按量 Key 新建默认不限额度，不显示无意义配额进度；编辑正确回显策略与上限。Token Plan 额度归订阅；额度周期/台账缺失显示 —，不以查询时段替代、不估算费用。
- 智能路由候选使用已有明确总参数量的国产模型，效果/成本/平衡按既有参数量、内部样例成本及其比值排序；候选只显示名称和总参数量，不展示价格。销售协议称《产品销售协议》；不将此原型排序宣称为真实模型效果评测。

## 模型体验

- 体验是 Web 页面，保留平台导航。文本、图片及仍提供的多模态页面共享居中欢迎区与输入区基线；首条消息前输入区位于欢迎文字下方，开始对话后历史独立滚动、输入区位于可用视口底部，参数面板向上展开。
- 文本保留输入区内模型选择和五个紧凑推荐；点击推荐直接填入完整提示词。输入框从 76px 随内容增长至 216px 后内部滚动，工具栏固定在文本下方。深度思考为可访问的图标开关，状态清晰；Temperature/Top P 依模型推荐值，说明通常只调一项。
- “新建对话”有反馈并保护当前草稿与输出；结果区有可读、可展开的错误和图标操作。仍启用历史的版本最多本地保存 20 条，并恢复模型、深度思考和采样设置。5.11.0 不显示侧栏历史列表，已存历史保留。
- 5.11.0 模型选择使用供应商侧栏、类型页签、模型/计费筛选和单行表格；每次打开默认勾选“仅看已订购”。不显示详情面板或单独操作列；未订购模型从订购状态中的“去订购”在新标签打开本版本订购页，原选择和草稿保留。
- 5.11.0/5.12.0 文本模型按 `inputModalities` 提供图片附件，校验格式、可解码内容、大小和数量，支持预览/移除。有图草稿切到纯文本模型需保护；图片仅驻留页面会话，历史只存文件名，不持久化图片二进制。
- 仍提供多模态体验的版本：四张图片任务卡在输入区下方；示例使用原创图片并填入完整任务与素材。附件作为输入区内不可编辑 token 与文字自然换行，支持多个、光标处插入及直接移除。
- 图片/仍提供的视频生成保留紧凑推荐、同宽输入区、圆形向上提交按钮和核验/额度说明；推荐填完整提示词。视频按具体模型提供模式、媒体、分辨率、比例、时长与声音选项，不套用通用规格。
- 仍提供语音体验的版本：合成使用模型选择、大文本输入、行内声音/设置及声音库；识别使用独立录音器，不改为文字或文件上传输入框。点击才申请麦克风，60 秒自动停止并释放；播放、真实波形及键盘定位、重录/删除后再识别，重置释放麦克风。识别结果仍是本地交互，未接实时转写服务。

## 注册认证与租户空间

- 5.11.0/5.12.0 均为手机号加短信验证码注册，固定 +86；注册后自动登录，选择实名认证/企业认证或稍后认证。账号中心/账号认证是认证入口；不恢复独立企业注册、流程合集、管理员注册或激活。
- 企业认证使用当前登录账号填写企业资料、授权信息并确认提交。授权经办人须填写授权说明及确认；申请人 ID/手机号来自有效登录状态，不能采信伪造表单身份。补充资料限定申请人拥有的需补充记录；申请只生成待审本地状态，不自动授予企业权限。
- 认证摘要区分个人结果与企业待审，未采集认证时间显示 —，不得拿提交时间替代。普通账号中心不展示注册成功；认证完成后恢复状态摘要。历史账号、申请、成员和独立激活记录保留。
- 认证页面沿用既有浅色双栏、绿色控件与无文字 AI 插图，窄屏单列；切换步骤保留焦点并让标题可见。后台 DESIGN 不用于登录/注册/认证。
- 租户 banner 的政企/个人切换：未登录仅保存版本独立的显示场景，登录后依据实际可访问空间，不凭控件建立成员关系或企业权限。两版本个人场景不渲染调用日志，直接访问回模型广场，日志及筛选记录保留。
- 5.12.0 的组织及成员、组织操作记录仅政企空间提供；个人直接地址回模型广场。账号管理中的账号认证两类空间均可用，未登录先登录。组织树、部门管理员范围、邀请确认、批量移动/停用、最后管理员与部门环路/非空删除保护保留；负责人身份不自动授予管理权。前后台组织数据保持独立。
- 补充流程见[认证文档](auth-prototype.md)及[成员批量导入](organization-member-batch.md)；其中早期企业注册和流程合集仅为历史，本节最终认证入口优先。

## 调用日志与租户用量

- 5.11.0/5.12.0 日志共享字段口径但源码和视图存储独立：请求时间、Request ID、模型 ID、服务/套餐、脱敏 API Key、状态码、输入/输出/缓存命中 Token、首 Token 时延、总时延及操作。Request ID 可查看详情和复制；不混入来源/流式副标题或额外状态文字。
- 右侧详情抽屉提供概览/JSON，优先失败原因；保留结束时间、服务与套餐标识、Key 名称/ID、客户端 IP、思考 Token、TPOT、超时/取消、User-Agent、请求/响应内容及复制/导出。缺失字段显示 — 或未采集，不从摘要补造正文、IP 或性能事实；时延统一 ms。
- 缓存已经包含在输入中，不重复累加；CSV/JSON 保留分项、零值、缺失并复用 Key 脱敏。日志只提供按量付费/Token Plan，不恢复资源包字段。
- 5.11.0 租户用量以客户计费项为中心：输入、输出、缓存读取/写入分别汇总和画线，单模型展示支持的分项，跨模型先汇总计费项，模型 ID 缩小范围。Token、张、秒、字符按实际接口单位分开，缺失为 —、已记录零为 0；夜间只改变价格，不增加夜间用量指标。
- 5.11.0 用量只保留语言、多模态理解、视觉、语音四类 Tab，删除日均/TPM 性能汇总、明细表及图表导航；保留时间/模型/Key、保存视图、刷新及趋势 CSV。档位、模式和模态直接进入折线分项；不恢复调用观测页面。
- 同一筛选事实驱动汇总、图表和导出，CSV 保留模型 ID、筛选范围与原始分项。Token Plan 按订阅选择匹配 Key；两个图每桌面行，设置在标题右侧，图例、单位和绘图区对齐。
- 详细计量解释见[5.11.0 租户用量](tenant-usage-5110.md)和[计费项说明](usage-billing-items.md)。

## 后台导航与运营分析

- 后台 2 使用运营/运维分段 Tab；系统管理员可切换，其他角色只见所属区域，账号管理仅系统管理员可见。运营默认概览，运维默认调用分析；5.12.0 名称为调用数据。直达地址同步区域，无权限不渲染业务内容；切换恢复各区域最近地址和筛选，并保护草稿。
- 平台 banner 保留角色及适用政企页的部署方式选择；编辑政企资料时部署方式禁用。面包屑栏不重复控件。工作台和整套安全治理入口已移除，不根据旧规格恢复；存储与审计保留。各版本实际菜单范围以版本功能范围为准。
- 5.11.0 运营概览、用量、用户数据及客户下钻使用北京时间完整自然日：昨日/近 7 天/近 30 天，默认和重置为昨日，自定义结束日不晚于昨日。比较前一等长完整期间；旧 URL/保存视图在应用时限制范围，不改写原记录。5.12.0 运营概览与四类运营分析支持今日、昨日、近 7 天、近 30 天、自定义至今日，具体口径见[版本时间规则](../versions/moma_5.12.0_estack/PAGE-SPEC.md#运营时间与事实)。租户面、运维调用分析保留各自时间规则。
- 运营月活按昨日所在自然月截至昨日的成功登录身份去重，独立于用量筛选，与上月同进度比较；DAU 不累加为 MAU。注册数按截止时刻累计身份去重，政企/个人构成与总数可对账，包含未调用用户。明确用户事件数据源与网关请求源边界。
- 5.11.0 概览保留注册总数、月活、模型请求次数、Token 使用总量、模型请求成功率，以及同源双趋势、供给/用户构成和客户/模型 Top 10。模型排行不增加使用客户数；名称下钻与查看全部用同一完整集合。零基数不产生伪造环比，成功率变化用百分点。
- 5.11.0 后台用量保留 Token 调用总量、模型调用次数、日均 Token、TPM 峰值、TPM 均值，显示对应单位并在 Tooltip 解释。Token 只统计显式 Token 事实；入口请求去重计次数，失败请求的确认计量保留，重试开销单列。日均含无活动自然日，分钟峰值来自自然分钟事实、均值含空闲分钟；不推算缺失计量。
- 5.11.0 用量全局筛选模型类型、供应商、模型及自产/引入，供应商与来源分开；分类变化清空不适用模型。趋势、类型图、排行与详情同源；不同单位单独选择，排行不补足虚构条目。图表排序只在既有分组内，通过保存提交，重置先作为草稿；固定筛选/KPI/明细。
- 保存视图区分已应用与修改状态，相对日期在应用时重算、自定义日期固定；搜索不清空跨结果多选，全选只影响明确范围，确认/取消草稿。各页保留自己的筛选维度、日期上限和存储命名空间。
- 用户分析全局仅时间；客户×模型明细内独立搜索、排序、分页、导出及详情下钻。实际用户仅来自明确 userId，不从共享 Key 或 tenantId 推断；首调用日只表示最早保留观测，不虚构试用转化或有效订阅。分项单位、待确认、成功率、自然分钟峰值及同源导出保持，缺少 TPOT/省份等来源时不提供该指标。
- 日/周统计按北京时间，日粒度最多 30 个自然日、周粒度最多 365 天，周一至周日；不完整边界周标明且不计算该周环比。5.12.0 用量布局、六区域和概览指标由版本规格单独规定。
- 5.11.0 的 11 个 calcloud 扩展入口及面包屑保留“（旧）”，使用独立页面/路由；参考[集成规格](admin-v2/CALCLOUD-INTEGRATION.md)。客户身份不得推断、成本保留缓存和价格生效时间，路由 Header/Query、多个模型名映射与 4xx/5xx 降级条件保留。未处理的上下架事件保持不可用，不宣称已切换现网。

## 客户与后台账号

本节适用于仍保留这些模块的 5.12.0；5.11.0 已删除其导航及渲染，不据此恢复。

- 政企管理使用列表→开户→详情；详情只含基本信息、组织及成员、项目空间、API Key。授权/配额和操作记录 UI 已删除，底层授权、台账、审计及模拟调用检查保留。项目、Key 和配额不随开户自动创建。平台指定企业管理员，企业管理员治理普通成员；管理员必须有明确角色和启用身份，至少保留一位。
- 政企主体名、税务/登记标识、国家地区、省州、业务联系人及电话必填；管理员电话与业务联系电话独立。国家缺失可在表单默认中国，保存才持久化；地区联动清空下级，无省州须明确选择不适用。行业使用已有 GB/T 4754—2017 分类，历史未知信息不编造。
- 列表入口称政企用户，部署方式为私有云/私有化；搜索 User ID/用户名，成员数包含所有租户成员，与详情全部成员一致。账号和关联 ID 固定，编辑在详情内，管理员电话与主体原子保存，离开/返回/刷新保护草稿。
- 基本详情依次用户信息、企业管理员、企业信息、地域行业、业务联系；企业管理员单独展示身份状态。税号、姓名、电话、邮件在只读详情和审计文本中脱敏，不通过 Tooltip/隐藏属性泄露；编辑与存储保留原值。冻结沿用租户事务，不等于冻结所有成员或 Key。
- 政企组织左侧为成员范围和组织树，右侧成员表；组织人数来自明确的本级和子部门归属，不把未分配成员算到根。管理员添加在标题区，包含子部门与搜索/状态/角色同排；长树和表各自滚动，前后台数据不拼接。
- 项目空间的所属部门来自同租户 `organizationId` 完整路径；缺失为未登记，跨租户/环路等为异常，不从负责人身份推断。
- 个人用户以手机号注册，手机号修改不替换稳定身份 ID。列表仅搜索手机号/昵称/User ID及状态；详情顺序为基本信息、项目空间、API Key、订购详情，旧历史页签回基本信息，底层审计保留。
- 个人批量冻结由“批量操作”显式进入；筛选、翻页、离开、权限丧失清除选择。确认对象、原因和五分钟的操作者/集合绑定校验码后一次事务提交，过期或非法目标整批拒绝；不新增批量解冻。
- 个人订购以自有订单和购买快照展示按量/Token Plan/Coding Plan及未知类型，默认全部，重置为全部并回第一页；资源包排除。详情保留订单号、购买/使用额度、单位、价格、有效期及进度，缺失为未记录；不把授权当订单，不从企业订单推导个人订购，创建时间与激活时间分开。
- 后台账号与客户、租户成员独立。平台管理仅账号管理，移除旧审计/审批/通知/基础配置页面但保留数据。角色为运营管理员、运维管理员、系统管理员；仅系统管理员可写，至少保留一个启用系统管理员。
- 后台登录标识手机/邮箱二选一，默认手机，姓名和角色必填；邮箱转小写并完整校验，手机归一化，跨启停状态去重。邮箱账号无需另填手机，标识创建后不可改，旧字母账号不重写，编辑可维护姓名、角色和选填联系手机。
- 新建和重置密码保留确认及交接弹窗，使用 `crypto.getRandomValues` 生成 20 位、覆盖四类字符的密码；仅临时持有，默认隐藏，关闭清除。持久化与审计只存版本/更新时间；不宣称真实密码验证、旧密码失效或短信已经实现。
- 政企细节另见[开户规格](admin-v2/ENTERPRISE-ONBOARDING.md)；入口/页签和账号规则以本节最终约定为准。

## 5.11.0 模型管理与供应

- 模型管理维护稳定平台 ID、资料、供给、采购/销售价格及上架范围；一模型可有多个供给，各自上游 ID、能力、验证和采购价独立。销售价为模型默认及显式供给覆盖，采购未知为待核算，价格版本不可变，模拟调用记录最终供给及售价版本，回退后仍准确。
- 列表保留模型编码、模态、上下文/最大输出、分类、价格、供应商/调用 ID、状态及操作；模型名称打开资料，预览不导航，管理进入配置。供应商最多三项并提供完整搜索弹层，调用 ID 展示 provider-code/model-code，但不冒充真实路由；相似上游名称不合并身份。
- 模型资料按类型维护，未知能力/规格与不支持分开；显式空资料不恢复默认值。图像/视频归视觉，内部任务与计价仍分开。输出模态与向量/分数等结果类型分开，类型变更清除不适用输入，隐藏的历史资料保留。
- 资料初始只读，编辑/保存/取消明确；持久化失败留在编辑态并保留输入。参数量用 B，上下文等单位在控件内，语言多选，架构/许可使用已有选项；Logo 校验 PNG/JPEG/WebP、大小不超过 1 MB 及真实可解码内容，只存本地。
- 批量导入复用表格解析，支持 XLSX/UTF-8 CSV/表头粘贴，最多 500 行/10 MB；先预览校验、明确跳过问题行，以同一原子事务创建下架且调用停用的草稿，不覆盖已有模型或自动配供给。
- 供应管理按供应商→接入→当前接入模型操作；保留稳定 provider/endpoint/supply ID。新映射模型和能力为空，RPM 可不填；配置变化停用接入并清除相关验证，当前配置通过检测并启用后才允许供给验证、启用或上架。
- 供应抽屉与列表保留完整错误、影响确认、草稿保护、权限和修订/存储校验。隐藏、暂停调用、下架是不同动作；查看与取消不保存业务状态。前台目录联动未接入时不改变其独立数据。
