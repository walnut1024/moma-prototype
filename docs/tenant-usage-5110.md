# 租户用量统计历史记录（5.11.0，已退役）

本文保留旧版本的计量说明，仅供追溯，不作为 5.12.0 的实现或验收结论。当前要求见 [PAGE-SPEC：调用日志与租户用量](PAGE-SPEC.md#调用日志与租户用量)。

本次修正仅涉及 5.11.0 租户用量统计。调用观测保留原性能指标；5.12.0 使用物理副本，不随此次修改同步。

- 本版本用量统计仅提供语言模型、多模态理解、视觉模型、语音模型四类，移除向量模型及排序模型入口和类别查询；已保存的旧类别视图不可恢复这些入口。
- 客户按计费项查看输入、输出、缓存读取、缓存写入的汇总和折线趋势。汇总区仅保留计费项名称、数值与单位，不显示输入未命中/命中辅助值及请求次数、输入输出合计等补充行。输入包含缓存读取：未命中输入 + 缓存命中输入 = 输入总量，缓存读取不能再与输入输出相加当作总消耗。
- 曲线设置与显示数量放在图表标题右侧，不增加额外工具栏行。同排图表的图例、纵轴单位、绘图区与横轴对齐；说明换行时仍按绘图区对齐。
- 删除用量明细表。跨模型先看计费项合计，通过模型 ID 与 Key 筛选定位来源；单语言模型在图中直接显示其支持的长度档位、思考模式、隐式/显式缓存分项。不支持的计量项不显示。
- 多模态按实际输入/输出模态拆线；视频按已提供的 Token 档位；图片张数、识别音频秒数、合成字符数各用独立图，不混用计量单位。
- 总览与折线使用同一时间、模型、Key、计费来源及订阅筛选。单日 10 分钟、多日按小时聚合，悬停查看时间桶的实际计量值。CSV 导出同范围各模型各时间桶，保留原始值、单位、模型 ID、订阅编号和 Key 筛选范围，不包含密钥。
- Token Plan 按订阅编号区分同名套餐重复购买。切换订阅清除 Key 选择；套餐有效期不是额度周期，额度台账缺失时周期/已用/剩余均显示 —。
- 请求次数包含成功和失败。真实用量以计量记录为准，有记录的失败请求也应计入，不能从失败状态推断为零。缺失计量保持缺失，已记录零值保持 0。

## 数据边界

当前 usage-data.mjs 仍生成确定性的五分钟本地样本，档位与模式比例仅用于交互展示和守恒验证，没有接入真实网关或计费系统。当前样本仅为成功请求生成用量，不能据此断言生产中的失败请求没有消耗。

真实接口需提供请求 ID、北京时间、租户 ID、模型 ID、Key ID、计费来源、订阅 ID，以及实际输入/输出/缓存、长度档位、模式及其他计量值。请求 ID 用于去重；原始计量缺失时不可用请求次数换算 Token。

费用金额需实际结算台账、计费项、价格版本、优惠与退款等事实，不能用统一目录价乘总 Token。当前页面展示计费用量分布，不填写估算人民币费用。套餐区另需订阅 ID、额度周期、额度单位、总量、已用量和更新时间。
