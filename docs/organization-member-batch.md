# 前台成员添加与手机号

适用范围为 5.12.0 前台「组织及成员」。前台和后台读取同一 D1 成员关系；写入按当前租户权限校验。

- 单个新增、编辑及批量添加均要求手机号；大陆号码规范化去空格、连字符及 +86，国际号码保留 +国家区号。企业内所有状态成员的手机号及账号均查重。
- 未填写邮箱的邀请使用手机号作为登录账号。编辑手机号保留成员 ID 与既有登录账号；列表和详情按号码本身独立脱敏，避免旧手机号账号泄漏。
- 已有平台账号匹配 D1 中可邀请的账号；有登记手机号时拒绝号码冲突，没有登记手机号时允许补齐本企业的成员资料。批量成员统一使用普通成员角色。
- 批量提供多行录入、Excel/CSV 和粘贴。支持 UTF-8 CSV，每批最多 500 条、文件最大 10 MB。服务端每个企业最多保存 1,000 位成员。
- 导入列为姓名、手机号、账号/邮箱、主部门。主部门空值继承当前选中部门；未选部门默认未分配。支持完整路径、唯一部门名和部门 ID；不存在或重名必须明确选择，不创建部门。
- 上传后预览，不自动提交。用户明确勾选跳过问题记录才能提交有效项；提交时针对最新成员状态再次校验。结果逐条显示成功、失败或跳过，提供清单导出及仅重试失败项。重复导入不覆盖原有资料或角色。
- 既有浏览器存档保持原状。D1 记录缺失手机号时，由企业管理员补齐成员资料。

## 实现边界

成员及操作记录保存在 D1。文件在浏览器解析，确认后提交有效成员。邀请链接由企业管理员生成，有效期为 7 天；成员本人确认后关系生效。演示环境通过链接交接邀请。
