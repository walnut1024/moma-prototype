# 前台成员添加与手机号

适用范围：moma_5.12.0_estack 前台“组织及成员”，不修改后台政企成员数据或角色。

- 单个新增、编辑及批量添加均要求手机号；大陆号码规范化去空格、连字符及 +86，国际号码保留 +国家区号。企业内所有状态成员的手机号及账号均查重。
- 未填写邮箱的邀请使用手机号作为登录账号。编辑手机号保留成员 ID 与既有登录账号；列表和详情按号码本身独立脱敏，避免旧手机号账号泄漏。
- 已有平台账号匹配独立平台账号目录；有登记手机号时拒绝号码冲突，没有登记手机号时允许补齐。批量成员统一使用普通成员角色。
- 批量提供多行录入、Excel/CSV/Excel 粘贴。下载 CSV 空白模板，Excel 可以打开；导入 XLSX 由 read-excel-file 9.3.10 延迟加载解析。支持 UTF-8 CSV，每批 500 条、文件 10 MB；这些限制仅为本地原型的处理限制。
- 导入列为姓名、手机号、账号/邮箱、主部门。主部门空值继承当前选中部门；未选部门默认未分配。支持完整路径、唯一部门名和部门 ID；不存在或重名必须明确选择，不创建部门。
- 上传后预览，不自动提交。用户明确勾选跳过问题记录才能提交有效项；提交时针对最新成员状态再次校验。结果逐条显示成功、失败或跳过，提供清单导出及仅重试失败项。重复导入不覆盖原有资料或角色。
- 保留已有浏览器成员资料；旧成员缺失手机号不凭空回填，编辑时补齐。新浏览器的 17 条种子和平台账号目录中的号码均为人工编写的虚构数据。

## 实现边界

全部成员及操作记录保存在原有 organization localStorage，文件只在浏览器本地解析。不发送短信、邮件，不验证号码归属，不调用真实身份目录或开通账号，不影响模型网关权限。待加入确认沿用原有本地交互；云版/私有版正式开户、邀请与审批仍需真实服务契约。
