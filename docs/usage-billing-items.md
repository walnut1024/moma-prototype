# 租户计费用量

模型订购与租户用量共用 `versions/moma_5.12.0_estack/src/model-billing-data.mjs` 的模型计费项。沿用既有订购价格与计量配置，不新增单价；只有资费场景数量、没有具体维度的模型保持待配置。订购模型加入租户模型筛选，调用观测仍使用原模型列表。

汇总展示总消耗 Tokens、输入 Tokens、输出 Tokens、缓存 Tokens，指标只作静态汇总，下方同时展示各指标折线图，桌面端每行两张。所有用量图表最小时间粒度为 1 小时，导出使用同一时间桶。输入包含缓存命中，总消耗为输入加输出，缓存不重复相加。模型没有缓存计费项时不显示缓存指标；未明确计费维度的模型保持待配置。缓存写入与计费档位保留在 CSV，不混入缓存命中。多模型只汇总适用模型，悬浮提示展示各模型贡献。汇总与曲线使用同一组计量样本。不同单位不混加。不增加用量明细表。

统计时间内已观测且无调用的指标为零，尚未观测的时段为缺失。未明确计费项的模型不生成猜测指标。Token Plan 查询仍按购买订阅与 Key 隔离，不推算费用或套餐额度。

当前是前端原型的确定性计量样本，未接入真实账单、请求计量或资费版本台账；历史资费生效时间需要真实台账接入后关联，不能声称已实现历史账单对账。本文说明计量要求，不代表当前实现或验收结果；当前页面要求以 [PAGE-SPEC](PAGE-SPEC.md#调用日志与租户用量) 为准。

指标说明仅放在信息图标的 Tooltip，汇总与折线复用同一句口径，不重复指标标题或罗列模型 ID。Tooltip 保留补充定义，键盘聚焦显示、Esc 关闭；沿用 Radix 的边界避让，悬停延迟 300 ms。参照 [Carbon Tooltip 规范](https://www.carbondesignsystem.com/building-blocks/core/components/tooltip/guidelines)。
