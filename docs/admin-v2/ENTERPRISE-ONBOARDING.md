# 企业用户开户原型

日期：2026-10-04。操作者：平台管理员、运营人员。仅浏览器演示数据。

## 页面与流程

1. 企业列表：企业名称/编号/管理员检索，状态筛选、重置、分页，新用户（企业开户），详情、编辑和启停。
2. 新用户抽屉：企业信息置顶，公司/机构名称必填并用作企业展示及根组织名称，无独立平台身份录入区；地域行业下拉、备注；新建登录账号或搜索选择已有账号，固定企业管理员角色。企业、根组织、用户（新账号时）和成员关系原子提交。
3. 开户结果：企业及管理员回显、登录初始化状态、复制演示交接信息、进入详情。
4. 企业详情：基本信息、组织及成员、项目空间、API Key四页签；移除授权额度及操作记录入口和弹窗，无效页签参数展示基本信息。企业/页签及关联项目保存在 hash 参数，返回保留列表筛选。企业列表不展示跨企业资源页签。
5. 编辑企业、添加管理员抽屉：共用字段校验；已有普通成员可升级为企业管理员，已有管理员拒绝重复添加。
6. 启停确认：显示对象及范围；企业停用保留子对象历史，管理员停用只影响本企业成员关系；最后一位正常管理员不能停用。

## 复用和数据

- 云版与私有化采用同一企业、账号、成员、根组织模型与表单。
- 场景切换明确标注为演示：多企业展示全量；单企业仅展示默认演示企业，不修改部署配置或删除其他企业。单企业容量由策略控制，已开户后不能重复创建；其他操作复用。
- users 登录身份与 memberships 分离；平台管理 admins 不作为企业账号候选。界面企业管理员对应租户管理员角色。
- 后台创建直接生效、账号待初始化为本轮建议演示规则。初始化标识无法登录，不发邮件、不创建真实凭证。
- 不自动建立项目、Key 或发放额度。后台查看企业内部组织、普通成员和项目；企业管理员在前台负责内部治理。后台可添加企业管理员、启停企业及所属 Key；企业详情不再提供授权额度配置入口，已有授权和流水数据保留。
- 企业额度为总额、输入加输出 Token 口径（缓存属于输入，不重复累计）；图片、视频、音频非 Token 计量不占此额度。新配置从零累计；未配置展示明确状态，不虚构历史用量。模拟调用叠加企业与 Key 约束；失败不扣减、请求重复不重复扣减。
- 企业负责人不自动获得管理员权限；有效管理员须有明确企业管理员角色、正常成员关系及有效登录身份。企业停用时禁止新增管理员、修改额度及启用 Key；子资源状态保留，恢复不自动启用已停用的 Key。
- 保存必须实际完成本地持久化后显示成功；发现存储冲突、读取/写入失败时保留表单并提示。危险操作确认展示对象与影响，审计可查看变更详情。

## 验收

- 必填、格式、同名提示允许核对后继续、账号不区分大小写唯一、重复管理员、最后一位管理员保护。
- 原子失败不留残留对象；操作进入共享审计；仅平台管理员、运营人员可写。
- 关闭保护输入；空结果、详情不存在、复制失败、保存错误、成功反馈可见；弹层键盘可用。
- 测试引用完整性、已有账号复用、单企业容量、权限；浏览器验收创建、详情、筛选、刷新、管理员、启停、场景切换和不同桌面尺寸。


## 企业用户元数据及管理员校验码

平台展示名称为“用户名称”，user_id 直接展示现有企业用户的稳定租户 ID，系统生成且不允许修改；不把首位管理员的登录身份 ID 当作企业用户 ID。

| 分组 | 字段 | 录入规则 |
| --- | --- | --- |
| 系统身份 | 用户名称、user_id、客户类型、状态、开户来源、创建/更新时间 | 用户名由公司名产生；不单独录入，ID及系统字段只读；新开户默认企业，编辑保持原类型 |
| 企业信息 | 公司/机构名称、税号/统一社会信用代码 | 公司名必填；税号可后补，转大写，仅格式校验，不核验主体 |
| 地域与行业 | 国家/地区、省份/州、城市、详细地址、所属行业 | 可后补；新开户默认中国，国家/省市联动下拉，行业选择20个国家标准门类 |
| 业务联系 | 联系人、电话、企业联系邮箱、网站、备注 | 可后补；联系人无权限含义，邮箱独立于管理员邮箱；网站限定 HTTP/HTTPS |

开户和编辑共用字段定义，资料保存至企业主体并随审计显示前后值。历史资料未填写时明确显示“未填写”；不补造公司、税号、地域。开户及编辑以公司/机构名称同步企业展示名称和根组织名称。列表检索覆盖用户名称、user_id、公司、税号、管理员登录账号。

停用企业用户、企业管理员、API Key 共用确认弹窗：对象与 ID → 操作角色与影响范围 → 获取管理员演示校验码 → 填入 6 位码 → 校验及本地持久化 → 状态和审计回显。未获取或未满 6 位不可点确认，错码显示恢复提示；有效期 5 分钟、重取间隔 60 秒，新码取代旧码，绑定对象/操作/当前角色；取消和成功清除本次挑战。保存失败保留输入。启用显示恢复影响，不要求停用校验码。

本轮校验为交互演示，不代表生产管理员认证或真实发送渠道，页面直接显示演示码。真实二次验证服务、实际身份绑定、服务端防重放及发送渠道不在本次原型实施范围。

## 地域行业及管理员手机录入

手机号为新建与关联管理员必填字段，保存在users.phone，共用登录身份资料；中国大陆11位或带+国际区号格式。已有身份缺失需补录，原子更新并审计；业务联系人电话与其独立。结果、交接及管理员列表回显。

行业选项为GB/T 4754—2017（第1号修改单）20门类；国家统计局资料：https://www.stats.gov.cn/xxgk/tjbz/gjtjbz/201710/t20171017_1758922.html 。国家/地区名称以Intl.DisplayNames中文翻译ISO代码；国际省州及城市为dr5hn/countries-states-cities-database静态快照，按国家加载，地域数据来源链接包含ODbL许可及可下载派生数据。中国大陆使用modood省市快照（2023-06-30）；直辖市归一为同名城市，补充港台澳。地名数据非实时权威服务，不宣称覆盖所有最新区划，未覆盖可录入详细地址。国际同名省州合并城市、城市去重；加载错误可重试。国家变更清空省市，省份变更清空城市；未知历史值保留。

## 后台组织及成员视觉复用

后台采用与前台相同的组织目录及成员表布局。全部成员/企业管理员/未分配部门和组织节点切换右侧范围，组织树支持名称搜索，成员支持姓名账号角色检索、状态角色过滤及分页。企业管理员视图保留手机号、身份状态、初始化状态、交接及启停；成员详情展示项目范围。只复用展示和筛选，不开放后台普通成员或组织编辑，不导入前台示例企业数据。未登记部门归属保持未知，不能视为根组织成员。


## 2026-10-04 项目空间所属部门

项目空间列表在负责人前增加所属部门列。projects.organizationId作为显式部门关联，按project.tenantId限定organizations，展示企业根组织至所属部门的完整路径。未登记显示“未登记部门归属”；关联不存在、跨企业或祖先链缺失/成环显示“部门归属异常”，不展示其他企业名称。不由负责人主部门推断、不默认归属根组织、不补造历史数据。后台仅展示关联，不扩展组织或项目管理入口。
