## 页面与状态

列表展示部署服务、模型/运行环境、集群、GPU/副本、就绪状态、服务端点及操作。状态Tab负责定位运行中、进行中、失败和停止的任务。点服务名称下钻，详情保留筛选上下文。创建三步：服务/模型/权重/运行时；集群/命名空间/副本/GPU并行/高级参数；配置核对与容量预检。更新复用同一表单。

详情运行概览并列呈现副本资源与端点，进度按各项实际登记值独立判断；历史运行状态不等于已通过就绪检查。配置页展示全部保存值，未登记显示—。事件页显示本地事务事件与审计，实际容器日志尚未接入。

配置提交预留目标GPU，启动检查完成才生成/启用内部OpenAI端点。目标副本和就绪副本分别显示。停止/失败释放资源；重启复用原端点。重建更新保存完整上一版配置，回滚仍需重新预检。失败或停止允许修正配置后重建；进行中禁止再次更新。
