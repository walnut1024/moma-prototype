- 每项为独立地址和业务页面；沿用原导航与工作区权限，原模型管理、供应、网关及分析保留。

- 统计使用已有本地调用事实；客户按客户ID归属，不推断个人身份。Token不与图像数量、音频秒数混算；缓存已包含在输入，不重复累计。缺失计量、时延或历史价格显示—。成本按请求快照或当时生效的供应/目录价格计算，不用当前价追算历史。
