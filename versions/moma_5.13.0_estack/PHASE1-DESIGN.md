# MoMA 5.13.0 第一批功能详细设计

设计日期：2026-10-24。设计先于实现；起点为已提交的 5.12.0，提交 `549495d`。

## 1. 目标与范围

用户在一个项目中完成创建项目、配置成员、开通模型、创建 Key、在线体验，再使用同一项目、模型、Key、Request ID 查询用量、费用与日志。后台读取相同项目和凭证记录。

本批包含项目列表/切换、项目概览、成员、模型权限与项目限流、项目设置、项目 Key、预算和有效期、一次性密钥展示、模型广场/详情/快速开始、项目在线体验、项目使用记录与审计。保留原有模型订购、智能路由、图像/视频/语音体验、组织成员与账号认证入口。

真实协议适配、模型网络调用、生产计费/限流、路由重试、供应商诊断与发布属于后续实施。本次不发出真实模型请求或自动发布。

## 2. 版本与视觉契约

- 一次性物理复制 `versions/moma_5.12.0_estack/{src,public,tests}` 到 5.13.0；新版本的源码、资源、Vite 别名与构建输出独立，不跨版本导入。
- URL 为 `/moma_5.13.0_estack/`；独立订单深入口同步生成。版本目录提供 5.13.0，5.12.0 继续作为历史入口。
- 浏览器键使用 5130 或 5.13.0 命名，不读取、迁移、清除 5.12.0 数据。
- 沿用现有前台深色平台栏、白色导航、蓝色操作、紧凑表格和体验页。后台遵守根 DESIGN.md；不将后台视觉令牌应用至前台。
- 使用已安装的 shadcn Button、Dialog、Input、Select、Tabs、Table、Checkbox、Textarea、Sonner 和现有图表组件，不增加依赖。
- 桌面验收 1440×900、1920×1080、1280×800；表格内部滚动，弹窗主操作固定可达，长名称不撑宽整页，键盘可完成主要操作。

## 3. 对象与数据

| 对象 | 归属与关键字段 |
| --- | --- |
| 账户空间 | 个人或企业资源主体，使用 tenantId；人员身份使用 userId；两者不混用 |
| 项目 | tenantId、ownerId、名称、说明、状态、金额预算、预算周期、预警比例、超额动作、内容日志开关 |
| 项目成员 | projectId、userId、项目角色、状态；只能从同账户正常成员添加 |
| 项目模型授权 | projectId、modelId、启用状态、RPM、TPM；受账户模型权限和平台可用状态约束 |
| API Key | tenantId、projectId、创建人、名称、用途、状态、允许模型、金额预算/周期、到期时间、脱敏值、指纹；不持久化完整密钥 |
| 体验 Key | 每项目一个系统托管 Key；不可手工编辑或删除；与普通 Key 共用调用校验和归属 |
| 请求 | Request ID、tenantId、projectId、userId、Key ID、modelId、supplyId、来源、最终状态、usage、费用快照、开始时间、耗时、可选输入输出 |
| 审计 | 操作人、空间、项目、动作、对象、时间和结果；不得包含完整 Key |

复用当前后台共享 store、models、modelSupplies、modelSalePrices、tenants、users、memberships、projects、apiKeys、requests 和 audits。新增项目成员及项目模型授权集合。全部项目写入通过同一事务入口提交，持久化成功后才更新 UI 和提示成功。

已登录时按实际 userId 和可访问空间确定资源归属；不按姓名、手机号或空间显示名称合并到已有企业。新个人身份以独立 ID 建立个人空间。未登录沿用现有原型的个人/政企预览场景，分别引用独立预置账户；该场景不等于真实登录授权。

## 4. 权限

| 角色 | 能力 |
| --- | --- |
| 账户所有者/企业管理员 | 创建项目；管理账户内项目与成员；交接负责人；删除项目；维护预算、模型和 Key |
| 项目管理员 | 管理自己所属项目的资料、成员、模型、预算和普通 Key；不能越权访问其他项目 |
| 项目成员 | 查看授权项目和模型、使用体验、创建并管理自己的普通 Key、查看自己的调用记录 |
| 项目只读成员 | 查看项目信息和获准统计；不能保存配置、创建 Key 或调用 |
| 后台运营/系统管理员 | 沿用后台权限查看同一账户项目、Key 与请求；本批不增加跨账户代操作入口 |

权限在事务层检查，隐藏按钮仅作呈现。无成员关系、跨空间项目/Key/模型、停用成员和只读角色直接提交均被拒绝。认证状态不参与功能门槛。

## 5. 导航与项目上下文

前台导航增加项目选择器和项目空间入口。主要页面：项目概览、模型广场、文本生成、项目模型、API Key、用量与费用、调用日志、项目成员、项目设置、操作记录。原有其他能力在原功能分组保留。

项目 ID 和页面保存在 URL 中，刷新/返回保持当前对象。每个空间分别保存最近项目。无项目显示创建入口；无权限 ID 显示访问不可用，不渲染其内容；项目切换清除对象详情和未提交的调用状态，表单有修改时先确认是否放弃。

## 6. 页面与交互

### 6.1 项目列表与概览

列表显示名称/ID、负责人、角色、模型数量、当前周期费用、预算状态、更新时间和进入/编辑/退出/删除。创建必填名称（2–50字，同账户内有效项目去重），说明最多200字。创建人加入管理员关系，初始不开通模型；自动建立托管体验 Key。

负责人不能直接退出，必须先交接给同项目正常管理员。删除需输入完整项目名称并确认 Key 停用影响；项目和 Key 标记为已删除，历史请求和费用保留，后续调用拒绝。删除当前项目后选择剩余可访问项目或返回列表。

概览按当前项目展示请求数、Token、费用、成功率和前一等长期间比较，支持今日/近7天/近30天；趋势和模型/Key排行从同一请求集合计算。配置摘要显示预算、已开通模型、有效Key和内容日志状态，提供直达入口。无样本显示零请求和不可计算的成功率，不伪造增长率。

### 6.2 项目成员

列表显示人员、账号、项目角色、负责人标识。添加弹窗只列同账户正常且未加入的成员，可选管理员/成员/只读。角色变更、移除有影响确认。禁止移除负责人或最后一位管理员；交接后原负责人保留管理员权限。成员被移除后立即失去项目访问，原操作审计和请求保留。

### 6.3 项目模型

按类型/名称筛选账户可用模型；展示账户授权、项目开通状态、平台服务状态、RPM/TPM及有效上限。开通/关闭由管理员执行；关闭后 Key 即使保留该模型范围也无法调用。RPM/TPM 为正整数或空（继承），保存后回显；有效限制显示项目配置与上层配置取到的实际约束。本批本地调用测试只验证项目范围内的窗口规则，不宣称生产分布式限流。

### 6.4 项目设置与预算

金额统一 CNY，底层按整数微元保存，0为有效预算，空为不限；不使用 Token 配额代替金额。预算周期为自然月/累计，预警阈值1–100%，超额动作预警/停止调用。周期切换不清除历史费用，按对应时间范围重新计算。输入输出默认不采集；开启后的新请求才保存内容，关闭不补采旧请求。保存失败保留表单。

### 6.5 API Key

普通 Key 支持创建、编辑名称/用途/模型/金额预算/周期/有效期、启停和删除。创建时所属项目固定；模型范围只能选择项目已开通模型。有效期不得早于当前时间。Key预算受项目预算独立约束；修改周期不删除历史用量。

创建前用 Web Crypto 生成凭证与指纹。事务只保存指纹和脱敏预览，成功弹窗在内存中显示完整 Key 一次，支持复制及“已保存，关闭”；关闭/离开/项目切换即清除。列表只复制 Key ID，不提供重新读取完整 Key 的入口。创建失败不显示成功或遗留 Key。

托管体验 Key 显示系统维护状态，不提供修改、删除或明文展示。普通 Key 与体验 Key 的调用、费用、日志使用同一归属规则。

### 6.6 模型广场与详情

从同一模型主档与销售服务读取目录。提供卡片/列表、名称搜索、模型类型、作者、系列、能力及上下文筛选，使用现有分页；价格按服务和计价单位展示。无配置价格展示待配置，0显示免费。

模型详情为独立内容页：名称/模型标识、作者/系列、介绍、任务、输入输出、上下文/输出限制、支持参数、按供应商的销售服务与价格、当前项目开通状态。详情提供开通模型、在线体验、快速开始；未开通用户可查看但调用被拒绝。

快速开始按模型实际支持能力展示调用端点和代码，至少覆盖 Curl/Python/JavaScript及流式开关。Chat Completions、Responses、Messages只能在有明确支持记录时可选；本批预置服务只声明其已记录的 OpenAI Chat Completions 支持。未知协议或参数显示未配置，不因网关目标能力而自动标为支持。代码使用环境变量占位凭证，不嵌入用户完整 Key；对客模型标识引用选定销售服务，与上游 Model ID 分开。

### 6.7 项目在线体验

复用现有文本体验，模型选项来自当前项目已开通、账户已授权、平台可服务且具备文本输出的模型。保留温度/Top P/系统提示词/图片校验；补最大输出Token和参数范围限制。详情进入时带入选定模型/服务。

每次发送/重新生成均先验证项目、成员、模型、托管Key、预算、有效期和限流，生成独立 Request ID。成功后同一事务记请求、使用量、费用快照和Key最近调用；失败记录原因且不扣成功费用。取消不会记录成功结果；失败保留输入以便调整。

对话历史按账户和项目隔离。切换项目卸载体验组件，清理计时器；历史恢复不得越过当前模型授权。费用提示显示按项目计费；展示本次请求ID和费用，支持跳转调用日志。所有输出、耗时和Token仍是本地交互数据，真实模型调用不在本批范围。

### 6.8 用量、费用、日志和审计

用户统计与日志按账户、项目和角色过滤，不把其他项目数据先渲染再隐藏。支持时间、模型、Key、来源、状态、Request ID筛选。列表显示分项Token、费用、耗时、结果；详情显示项目、操作者、Key、模型/销售服务和采集状态。历史未知费用显示未记录，不按当前价格回算。导出防公式注入，JSON和CSV不包含完整Key。

操作记录覆盖项目、成员、模型权限、预算、Key变化，按同项目权限过滤。日志内容开关关闭时，响应详情解释未开启采集；已记录内容仅项目管理员/请求操作者可看。后台沿用同一项目、Key、请求记录及标识，并展示项目金额预算。

## 7. 状态与错误

全部列表支持无数据/无筛选结果；表单支持必填、边界错误、保存失败、只读、未保存离开；Dialog具备标题、焦点约束、Escape关闭及焦点恢复。持久化失败保留旧状态和输入；并发修订冲突阻止覆盖并提供重新载入。存储读取损坏不自动覆盖已有内容。

调用错误区分：项目不可访问、项目已删除、成员只读、模型未授权/未开通/不可用、Key停用/删除/过期、Key或项目预算耗尽、RPM/TPM限制、价格未配置。返回稳定错误码与可操作说明。

## 10. 设计结论

本设计沿用既有前后台视觉体系和共享事务，不增加独立假数据列表。先完成版本隔离及项目领域，再接页面和体验/观测；功能与验收均以本文件为基准。
