# MoMA 5.13.0 第一批修复详细设计

修订日期：2026-10-25。基线：5.12.0 的页面与交互；修复起点 e69a5ac。本文先于本轮源码修复完成，取代上一版整体工作区替换方案。

## 1. 目标与不可变边界

在原页面增补项目能力。保留模型广场筛选/卡片、体验输入器与选择器、订购页签、调用日志抽屉/JSON/筛选视图、用量统计、调用观测、组织架构和账户操作记录。账户级页面无需先有项目。项目、Key、请求与后台使用同一业务记录；不跨版本导入，不修改5.12.0，不清除已有5.13.0浏览器数据。不接真实模型、支付或生产鉴权，不自动发布。

## 2. 页面地图与上下文

| 分组 | 页面 | 范围/增补 |
| --- | --- | --- |
| 模型服务 | 模型广场、智能路由 | 广场账户级，保留原筛选布局、模态、排序，增加价格/项目开通；路由按账户与项目隔离 |
| 模型体验 | 文本生成、图片生成、视频生成、语音识别 | 原页面、输入器及参数交互保留；显示实际所属项目与服务；项目授权/预算/记录统一校验 |
| 订单管理 | 模型订购 | 账户级，保留按量/Token Plan页签、列表、详情和独立订购页；共享订单读取，不能用历史模式 |
| 模型观测 | 用量统计、调用观测、调用日志 | 当前项目数据，复用原页面；个人不显示及不渲染调用日志 |
| 项目管理 | 项目空间、项目概览、项目模型、项目成员、项目设置、项目操作记录 | 新增能力放在此组，不替换原账户页面 |

## 3. 统一身份、成员与可用性

认证读取失败立即阻断工作区；仅正常未登录才使用预览身份。导航、认证入口、空间切换、退出、浏览器返回、刷新共用未保存保护。先确认再变更身份/URL；密钥一次性展示也受保护。

项目成员以projectMemberships为权威，后台成员项目范围从该集合读取；账户成员状态即时参与判定。只读成员可退出，不能调用/写配置。负责人先交接，最后管理员不可移除。企业管理员访问全部项目的身份需要明确展示。

有效模型=账户范围∩项目开通∩模型调用状态∩可用供给。供给复用既有校验/连接规则。可见性仅控制目录展示，详情遵循相同可见性；不可调用可展示明确原因。模型ID、显示名、供应商、调用ID分别传递，禁止用内部ID猜供应商。开通不等于订购。

## 4. 项目配置与Key

金额为整数微元，0有效、空不限；自然月/累计，预警/停服不改历史。Key保留模型明细、用途、IP白名单、预算/有效期、启停/删除/轮换；轮换仅一次明文，旧指纹失效。托管Key只能由系统使用，不允许前后台普通Key操作；模型范围随项目变化。管理状态和实际可调用状态分开，概览有效Key计数复用可用性判断。

Token Plan创建与调用均校验账户、订阅状态、起止日期、产品模型与剩余额度。本地请求按明确的Token额度扣减，记录套餐ID/扣减量，按量费用不能重复收取；信息不完整拒绝调用并解释原因。

## 5. 体验请求契约

保留现有体验UI。统一记录项目/人员/Key/模型/服务/计费方式、参数、输入模态、请求状态与用量。文本请求传入系统提示词、深度思考、采样参数、最大输出、多轮上下文与图片元数据；支持图片单独输入。正文开关关闭时不保存Prompt/响应，元数据不能夹带正文或图片二进制。历史记录按账户/项目/人员隔离，最新参数/模型/更新时间覆盖旧值。

本地输出继续使用既有固定结果，文档如实说明。发送前校验，取消不记成功；错误区分400参数、403授权/预算、429限流、503无服务/无价格。请求快照记录各阶段通过/拒绝/未执行，后台不得从Key当前状态推导历史结果。

## 6. 观测与审计

调用日志复用CallLogs，适配共享请求记录，保留日期快捷项、查询/重置、保存视图、分页、CSV、详情与JSON。新增项目、人员、费用/套餐扣减、参数与价格快照；未知字段保持未知，脱敏一致。列表时间倒序，来源统一；个人直接日志URL也拒绝。

用量统计与调用观测复用原布局，以共享请求替换独立fixture。文本按Token，图片按张，视频/语音按对应时长/字符，缺失量不填造。概览用北京时间自然日窗口、同窗口分桶和前期对比；费用未知不能显示确认零，排行无已知费用要解释。生效限流与执行复用规则。

项目和账户审计分开查询，同一底层记录按归属过滤；分页、时间/关键词筛选、变更详情；业务失败显示失败，不能用事务落库成功冒充业务成功。后台Key、项目、成员、请求详情与前台可相互核对。

## 7. 视觉与组件

前台以5.12.0为视觉基线，保留原侧栏密度、功能分组、页面标题、模型卡片、筛选工具栏、抽屉和体验布局；只添加项目选择器、项目范围提示及必要字段。后台遵守DESIGN.md，新增样式作用域隔离。新表单复用Button/Input/Select/Checkbox/Dialog，筛选必须有可见名称，状态文字配合语义颜色。主内容和宽表分别滚动，长名称、空态、只读态、错误态均可用。

## 8. 修改触点

App：移除失效的双重前台渲染，复用原页面作为工作区子页；ProjectConsole只负责项目上下文/新项目页。模型广场恢复原结构并接共享目录；模型选择helper修正字段；CallLogs/Usage/组织/订单组件新增共享数据入口。project-domain集中权限、Key、计费和请求规则，后台复用。AuthExperience导航在变更前统一确认。根测试与lint纳入5.13.0。
