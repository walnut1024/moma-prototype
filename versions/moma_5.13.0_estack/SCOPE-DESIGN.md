# 5.13.0 账户与项目范围优化详细设计

2026-10-25。实施前检查点：b46d4ac。本文先完成，随后实施；替代上一轮NAVIGATION-DESIGN.md的结构。

## 1. 目标与约束

项目选择器确定当前项目。项目内仅提供项目概览、项目配置；不再出现项目管理的外层包装。全部项目、企业管理、账户审计、认证属于账户。保留模型服务、模型体验、订单管理、模型观测四组的入口、顺序及原业务页面。仅调整5.13.0的范围、导航、配置拆分和重复标题，不重做上半部分，不新增依赖、不修改历史业务数据、不发布。

## 2. 范围、地址与返回

| 范围 | 页面标识 | 地址与上下文 |
| --- | --- | --- |
| 项目概览 | overview | #/projects/{projectId}?page=overview；账户 / 项目 / 项目概览 |
| 项目配置 | settings、models、keys、members、budget、audit | 同一项目地址；账户 / 项目 / 项目配置 / 页签 |
| 项目业务 | 智能路由、experience、compare、图片生成、视频生成、语音识别、usage、调用观测、logs | 同一项目地址，沿用原业务组件 |
| 全部项目 | projects | #/account?page=projects；账户 / 全部项目 |
| 企业管理 | 组织及成员、账户操作记录 | #/account?page={page}；账户 / 企业管理 / 页签 |
| 账户业务 | catalogue、detail、模型订购、账号认证 | #/account?page={page}；账户 / 对应功能 |

页面标识决定范围。账户地址不含项目ID；账户页的project、role、records、runtime为空，不自动把最近项目作为业务归属。项目页指定无权ID时不得回落到其他项目。最近项目和最近项目地址按账户记录；账户页不改写它们。返回时重验访问权，失效则进入全部项目。项目功能从账户导航进入时使用最近可访问项目；无项目显示创建/联系管理员空态。切换账户不沿用另一账户项目。

内部导航使用统一地址生成函数。现有根路径业务入口由同一解析函数读取，不另建一套路由。浏览器刷新、前进、后退与当前范围、页签及侧栏同步。

## 3. 导航和选择器

项目工作区下半部分为“项目：项目概览、项目配置”；政企另有“账户：企业管理”。六个配置页只高亮项目配置。概览没有页签。账户页隐藏项目选择器和项目配置分组，显示返回项目及账户范围入口；上半四组保留。

项目选择器复用Popover和Command：项目搜索、可访问项目列表、当前项勾选。列表底部独立“查看全部项目”按钮，不作为项目选项；名称截断时提供完整名称。选择和离开均经过草稿保护。全部项目仅负责查找、创建、进入；退出/交接/删除统一到基本信息。创建后进入模型权限，列表可返回上次项目。无项目时不阻断账户功能。

## 4. 项目概览

删除项目管理包装和概览页签，只留“项目概览”主标题。统计时间和创建API Key放在标题操作区。创建Key先进入API Key页签，再打开现有创建窗口；该次动作关闭后刷新不重复弹窗。

顺序：标题、预算状态、核心指标、调用与费用趋势、模型/Key费用排行、配置摘要。保留缺失费用提示和原统计口径。时间写入地址，切项目及配置跳转保留已选时间。摘要可直达模型权限、API Key、成员权限、预算与日志、原智能路由；不复制完整表单。

## 5. 项目配置

一个“项目配置”主标题，下方Tabs手动激活。面板不重复渲染h1；保留说明、工具栏和动作。

| 页签 | 标识 | 内容及写入 |
| --- | --- | --- |
| 基本信息 | settings | ID可复制、名称、说明、负责人。profile操作只保存名称/说明 |
| 模型权限 | models | 账户授权、项目开通、有效RPM/TPM，复用原弹窗 |
| API Key | keys | 原筛选、创建、编辑、启停、轮换、预算/套餐和一次明文 |
| 成员权限 | members | 从账户成员添加、角色修改、移除；移出项目不等于移出企业 |
| 预算与日志 | budget | 金额、周期、阈值、超额动作、正文开关。budget操作只保存这组字段 |
| 操作记录 | audit | 当前项目审计及变更详情，与调用日志分开 |

删除整份settings写入路径；调用者和测试改用profile/budget。领域层分别验证，前台不把未显示字段拼回提交。验证双向保存互不覆盖、0预算、空预算及无权写入。切项目按ID重挂载面板，清理旧行和编辑目标；失败保留输入。

基本信息底部设独立生命周期区域：退出项目仅实际项目成员可操作且负责人须先交接；交接只向负责人或账户管理员开放；删除仅账户管理员并确认完整名称。成员页移除重复交接。保存普通信息不触发生命周期操作。

## 6. 账户页面及跨页入口

企业管理保留“组织与成员 / 操作记录”两个页签，不带项目名称、角色和ID。组织事务显式传null项目；账户审计按原账户/人员权限过滤，项目审计保持项目过滤。

广场和订购复用原页面。广场为账户目录，不用最近项目的开通状态表达目录归属。模型详情开通和体验需明确选择目标项目；该选择仅为本次动作目标，不改变账户页范围。顶部账号认证进入账户地址；智能路由的Key跳转调用工作区navigate，不依赖隐式项目回落。

个人不显示及不渲染企业管理、账户操作记录、调用日志。无项目仍可访问账户广场、订购、认证等已有能力。

## 7. 状态与保护

页签、项目、全部项目、企业管理、顶部认证/后台/账户切换、前后退统一保留未保存保护。继续编辑后地址、项目、页签、输入及Key明文不变；放弃才清理。保存中防重复提交和离开。跨标签revision冲突保留输入并提示重载。切换账户清理旧对象；权限在渲染和事务提交时重新判断。

无项目、项目不可访问、无模型/Key、筛选无结果、只读、失败、冲突均保留明确反馈和返回路径。

## 8. 触点与验收

ProjectConsole调整范围外框、概览、选择器及配置；project-navigation集中范围/地址/激活，供App和AuthExperience使用；project-domain拆分字段写入。只改5.13局部样式，后台继续读取原store，不另建状态适配层。

自动化覆盖：上半导航不变；账户地址无项目ID；无权项目不回落；返回项目校验；六页签；清除旧详情标识；profile/budget互不覆盖及权限校验。运行5.13专项、lint、完整build、diff和版本隔离检查。

浏览器逐页：概览、六个配置页、全部项目、企业两页、认证；上半广场/详情、路由、四类体验、订购、用量、调用观测、调用日志。检查表单/按钮/筛选/抽屉/返回、项目切换、刷新、前后退及草稿保护。在1280×800、1440×900、1920×1080检查受影响页、长名称、独立表格滚动和弹窗。

前后台联动：分别保存基本信息、预算、日志策略，后台核对同一项目；Key状态及归属核对；项目成员/企业成员范围核对；审计核对相同项目ID和字段变更。可逆临时设置恢复，审计保留。删除/退出/交接用隔离测试状态验证领域规则，浏览器检查确认和校验；不删除既有数据。不声称完成真实调用、支付或生产鉴权。
