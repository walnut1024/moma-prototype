## 现有开放范围

客户范围仍为模型级 `openScope: all | selected` 与 `tenantIds`，由 `serviceScope` 校验客户有效性，通过 `commercialPublish(kind: scope)` 独立提交。统一服务和分供应商服务共用该模型级客户范围；不声称具有供应商级客户权限。后台角色继续由现有 HttpOnly 会话与 `canMutate` 判断。用户会话、成员及调用 Key 均不在本轮改造内。

## 变更清单与唯一写入来源

| 范围 | 页面或组件 | 领域命令／数据 | 持久化与校验 |
| --- | --- | --- | --- |
| 服务用途 | 新建服务、服务概览 | `createServiceModel`、`servicePurpose`；统一服务 `model.purpose`，分供应商 `serviceProviders[].purpose`，新关联继承模型用途 | 现有模型运营 D1 命令；旧记录缺字段按经营服务检查，不补免费状态；切换先停服和停售，检查依赖与修订 |
| 技术启停 | 服务操作、启用检查 | `enableService`、`disableService`；`callsEnabled`、`status` | 启用校验技术配置、现有客户范围和真实保存的模拟验证回执；不改变销售状态 |
| 停售 | 服务操作 | `stopSales`；`listingStatus` | 不改变技术开关、客户范围、订单及历史 |
| 管理端验证 | 平台试调用 | 现有 `/simulation/services` 的技术候选、试调用与发布；受后台权限保护 | 缺价格保留未知；不绕过连接、映射、路由及证据；复用原操作 ID 与回执 |
| 成本与售价 | 现有编辑器，独立页待 P3/P4 | `channelProcurementPublish`、`commercialPublish(kind: price)` | 沿用现有原子事务与价格版本；技术指纹不包含价格；经营调用仍执行其既有价格检查 |
| 页面归位 | 服务概览、后续五模块页面 | 唯一模型资料主档；路由及映射复用现有组件 | 本增量保留售价编辑可达，独立新页面未完成前不新增导航空壳 |

`purpose` 由具体服务设置。分供应商未单独设置时继承模型用途；只有明确记录为 `internal` 才是内部服务。已经营服务如无法核对客户权益，阻断转内部用途。管理端记录仍由现有 `record_json` 投影保留，未新增租户数据表或跨端写入。

## 具名验收

1. 技术候选无采购／销售价格仍可模拟验证，缺成本记为待核算，销售费用不适用。
2. 重放同操作 ID 不重复生成模拟用量或价格版本。
3. 停售保留技术启用，停用保留销售状态和价格历史；用途切换拒绝在线服务、活动依赖及过期修订。
4. 成本和售价修改不清除技术证据，连接／路由变更仍使证据失效；经营调用缺有效价格仍被拒绝。
5. HTTP/D1 管理命令保存后刷新一致，拒绝过期修订；既有后台权限和事务失败边界继续通过回归。
6. 本地隔离数据库检查用途确认、刷新回读、技术启用缺项、取消及截图风格；视口与证据见进度记录。
