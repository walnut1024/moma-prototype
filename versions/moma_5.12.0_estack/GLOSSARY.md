# MoMA 5.12.0 模型运营术语

本术语表描述模型资料、上游供应和平台对外服务。五模块按渠道接入、模型服务、模型成本、模型售价、模型资料组织。统一模型服务模式与渠道直选模式是当前服务模式；采购和销售分别定价。

## 模型身份与资料

**模型资料**：描述一款模型身份、类型、任务和能力的主档。同款模型可关联多个服务商，模型服务可引用该资料并维护对外展示内容。
_Avoid_：把服务商接入记录当作新的模型资料，或把服务展示内容当作另一款模型身份。

**资料 ID**：系统识别同一份模型资料的稳定关联标识，与可读名称及调用参数分开。
_Avoid_：模型编码、上游模型标识、对外调用标识。

**规范模型标识**（`canonical_slug`）：模型资料的稳定身份，用于跨服务商关联同一款模型。模型变体可以关联同一规范身份；不作为客户或上游的调用参数。
_Avoid_：仅写“模型 ID”而不区分资料标识、业务编码和调用标识。

**模型展示名**（`name`）：面向运营或客户阅读的展示名称，不要求等于调用标识。
_Avoid_：模型名称、模型显示名、以展示名代替稳定关联标识。

**模型作者**：模型的研发者或发布团队，不必等于平台直接采购服务的服务商。
_Avoid_：服务商、固定的对外服务发布主体。

**模型类型**：按模型用途划分的类别；任务类型描述具体执行的工作，例如图像理解或语音识别。

**输入／输出模态**：模型接收和生成的内容形态，如文本、图片或音频。结果类型描述向量、相关性分数、排序结果等返回形式。
_Avoid_：把声明的模态、任务或能力视为已经完成真实验证。

## 供应与调用

**服务商**：直接向平台提供模型服务并形成采购成本的一方，其上游推理、中转或转售方式不改变该直接采购关系。
_Avoid_：仅凭模型作者、研发厂商或对外发布标识认定服务商。

**服务商编码**：标识服务商主体的业务编码；渠道直选模式服务关联中使用同一服务商编码表达来源。
_Avoid_：不解释含义的 Provider 标识、上游模型标识。

**供应模型**：某个服务商与一款模型资料的供应关系。关系登记不等于已配置可用渠道。

**服务商能力声明**：该服务商对模型支持参数、上限和能力差异的说明；不改写统一主档，也不代表渠道已经通过验证。

**渠道**：平台访问服务商的一组接口、地址和认证配置，一个渠道可关联多个模型。
_Avoid_：服务商主体、单把 API 密钥、一个销售服务。

**渠道模型映射**：平台模型资料与某个渠道内上游模型标识 的对应关系。

**上游模型标识**（`upstream_model_id`）：平台向服务商发起请求时使用的模型标识，可因渠道不同而不同。
_Avoid_：资料 ID、模型编码、对外调用标识。

**服务根地址／请求地址**：服务根地址是标准接口的基础地址，请求地址是包含任务路径的完整调用地址。自定义任务直接配置完整任务地址。

**服务商 API 密钥／密钥组**：用于上游鉴权的 API Key 及其资产分组，保留 API 密钥名称。当前绑定渠道数表示配置关系，不表示调用量。
_Avoid_：客户调用平台时使用的 API 密钥、把资产分组顺序视为所有渠道的调度策略。

**渠道密钥池**：一个渠道绑定的多条服务商 API 密钥及其启用状态、优先级。旧专属、默认及共享组引用在明确修改前保持原值；优先级配置不证明已实现真实网关多 Key 配额调度。

## 价格与对外服务

**刊例价**：服务商对某模型的参考报价，具有独立来源和有效期。只在服务商模型详情维护；不自动作为实际采购价或客户售价。

**采购报价／采购价**：服务商提供给平台的计费规则、单价及适用条件；渠道接入及管理端技术验证、启用可以先不配置；经营调用按既有有效采购条件校验，缺价保持待核算。
_Avoid_：服务商售价、渠道售价、平台售价。

**采购参考价／折扣系数**：采购参考价是服务商报价的计算基准，折扣系数参与计算实际采购单价；明确的手工采购价可覆盖该计算结果。
_Avoid_：将参考价直接当作实际成本或客户售价。

**Token 成本**：实际供应消耗按适用采购报价形成的平台成本，不是客户收费。

**计费项／计价单位／币种**：计费项确定费用对象，计价单位确定单价对应的数量，币种确定金额货币；三者共同限定价格含义。

**模型服务**：平台提供的一款模型技术服务，维护对外调用标识、用途、允许供给、路由及现有客户开放范围；经营服务另配置售价和销售状态。
_Avoid_：以模型资料、供应关系或单个渠道代替对外服务。

**对外调用标识**（`id`）：客户在平台 API 请求中填写的模型标识，由服务模式及服务配置确定。支持斜杠、点、连字符及变体后缀，唯一性检查保留；不等于内部关联用的 `record_id`。
_Avoid_：上游模型标识、固定的“发布方/模型名”格式。

**统一模型服务模式**（Provider-Agnostic Routing）：用户只选择模型，平台在后台完成服务商选择、负载均衡及故障转移。使用模型级对外调用标识与售价，实际服务商切换不自动改变客户单价。

**渠道直选模式**（Provider-Explicit Routing）：用户能够感知并指定模型服务商或服务渠道。平台仅在指定范围内调度，不跨越用户选择；同一服务商的多个渠道共用该服务商的对外售价。
_Avoid_：已被替代的逐渠道独立零售价“渠道转售模式”。

**平台售价**：平台向客户销售模型服务的计费规则与单价，在模型售价独立于采购报价维护；内部服务可无售价。
_Avoid_：服务商售价、平台目录价、采购价格。

**关联渠道／渠道路由**：关联确定服务可选的供给集合，路由确定请求在允许供给中的选择、分配或回退规则。关联成功不表示路由已经生效。

## 接入任务与配置

**接入任务**：围绕一款模型完成首次上架、准备备用供应或投入已有服务的工作。完成条件由任务目标决定，不以另一项服务已经上架替代。
_Avoid_：把接入任务当作第二份模型身份。

**未提交输入**：仅在当前编辑页面保留的内容；预览不写业务数据，确认提交后一次保存。后台不提供草稿保存与恢复。

**生效配置**：已经明确发布或应用、供相应业务使用的配置版本。
_Avoid_：最新编辑内容、未发布候选。

**备用供应**：已具备必要采购条件和有效连接检查、尚未投入当前服务路由的供给。
_Avoid_：把未分配流量的备用供应称为未完成接入或运行异常。

## 验证与状态

**测试通过**：本次选定范围的验证成功，不等于所有能力通过或服务已对外开放。

**启用模型**：让验证有效的渠道模型映射具备技术供给资格；不替代正式服务的价格、能力及发布条件。

**应用配置**：明确将已验证的候选连接或密钥切换为当前配置；测试候选不自动覆盖当前配置。

**发布配置**：明确使检查通过的服务配置或路由版本生效，预览不写入，确认后一次提交。

**上架销售**：管理员确认技术已启用、经营服务成本／售价有效及销售对象后开放销售状态；不自动启用技术服务，不代表用户端已贯通。

**停用技术服务／停止销售**：当前服务操作的两个独立动作，分别维护技术开关和销售状态，保留价格、配置及历史。销售操作在模型售价维护，技术启停在模型服务维护。
_Avoid_：仅隐藏模型、仅停止新增订购、删除服务。

**放弃本次修改**：撤销尚未保存的编辑，回到最近一次保存内容。
_Avoid_：删除已保存的资源或历史。

**销售对象**：模型内经营服务共用的 `salesScope`，与原模型级调用授权分别保存；未配置时只读引用原调用范围，不扩大授权。

**成本待核算**：没有可确认的适用价格或计量事实，不以零代替；后台技术验证可继续，历史不会因后补价格自动重算。
