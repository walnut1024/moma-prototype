# MoMA 5.12.0 模型运营术语

本术语表描述模型资料、上游供应和平台对外服务。模型运营分为模型接入、模型服务、模型广场、模型销售和基础资料。采购和销售分别定价。

## 模型身份与资料

**模型资料**：基础资料维护的参考档案，可复制所需字段到上游模型或模型卡片。模型广场维护用户看到的展示内容。
_Avoid_：把服务商接入记录当作新的模型资料，或把服务展示内容当作另一款模型身份。

**模型档案 ID**（model.id／引用 model_id）：系统识别同一份模型资料的永久编号。
_Avoid_：模型编码、上游模型调用标识、模型 ID。

**模型编码**（`canonical_slug`）：用于跨服务商识别同一确定型号与版本的可读编码，如 glm-5.3；与模型内部永久 ID 分开。
_Avoid_：用模型 ID 或模型档案 ID 代替模型编码。

**模型展示名称**（`name`）：模型广场维护的用户可见名称，其他运营模块读取；不要求等于模型 ID。
_Avoid_：模型名称、模型显示名、以展示名代替稳定关联标识。

**模型作者**：模型的研发者或发布团队，不必等于平台直接采购服务的服务商。
_Avoid_：服务商、固定的对外服务发布主体。

**模型类型**：按模型用途划分为语言模型、多模态理解、视觉模型、语音模型、向量模型、重排序模型和其他专用模型。任务类型描述具体执行的工作，例如图像理解或语音识别。

**输入／输出模态**：模型接收和生成的内容形态，如文本、图片或音频。结果类型描述向量、相关性分数、排序结果等返回形式。
_Avoid_：把声明的模态、任务或能力视为已经完成真实验证。

## 供应与调用

**服务商**：直接向平台提供模型服务并形成采购成本的一方，其上游推理、中转或转售方式不改变该直接采购关系。
_Avoid_：仅凭模型作者、研发厂商或对外发布标识认定服务商。

**服务商资料**：记录供应主体、展示信息与运营联系方式的主档，供连接和供应模型引用。

**服务商编码**：标识服务商主体的业务编码。
_Avoid_：不解释含义的 Provider 标识、上游模型调用标识。

**供应模型**：某个服务商与一款模型资料的供应关系。关系登记供「当前服务商模型」选择。连接内上游模型及其配置独立保存。删除接入记录后供应登记仍可在基础资料维护，删除供应登记后已接入记录继续使用原配置。

**服务商能力声明**：该服务商对模型支持参数、上限和能力差异的说明；不改写统一主档，也不代表连接已经通过验证。

**模型连接**：平台访问上游的一套配置，由服务商、服务地址、接口格式、接口端点和上游 API 密钥共同决定。一个连接对应一种接口格式和一个接口端点，可以接入多个上游模型。

**上游模型**：某款模型在一个模型连接上的接入记录，例如甲云（自营）或甲云（转售）。复用连接时仍分别维护来源名称、上游模型调用标识、检测与采购价。
_Avoid_：服务商主体、单把 API 密钥、一个销售服务。

**上游模型映射**：平台模型资料与某个连接内上游模型调用标识 的对应关系。

**上游模型调用标识**（`upstream_model_id`）：平台向服务商发起请求时使用的模型标识，可因连接不同而不同。
_Avoid_：模型档案 ID、模型编码、模型 ID。

**服务根地址／请求地址**：服务根地址是标准接口的基础地址，请求地址是包含任务路径的完整调用地址。自定义任务直接配置完整任务地址。

**上游 API 密钥／密钥组**：用于上游鉴权的 API Key 及其资产分组。单把密钥以密钥 ID 标识。当前绑定连接数表示配置关系。
_Avoid_：客户调用平台时使用的 API 密钥、把资产分组顺序视为所有连接的调度策略。

**连接密钥池**：一个连接绑定的多条上游 API 密钥配置。历史专属、默认及共享组引用用于还原存量配置。连接详情的「上游 API 密钥池」提供服务商共享资产的添加和删除。

**上游 API 密钥池**：服务商的共享上游 API 密钥集合。每个服务商最多 5 把，连接专属密钥单独计数。

## 价格与对外服务

**刊例价**：服务商对某模型的参考报价，具有独立来源和有效期。只在服务商模型详情维护；不自动作为实际采购价或客户售价。

**采购报价／采购价**：服务商提供给平台的计费规则、单价及适用条件；连接接入及管理端技术验证、启用可以先不配置；经营调用按既有有效采购条件校验，缺价保持待核算。
_Avoid_：服务商售价、连接售价、平台售价。

**采购参考价／折扣系数**：采购参考价是服务商报价的计算基准，折扣系数参与计算实际采购单价；明确的手工采购价可覆盖该计算结果。
_Avoid_：将参考价直接当作实际成本或客户售价。

**Token 成本**：实际供应消耗按适用采购报价形成的平台成本，不是客户收费。

**计费项／计费单位／币种**：计费项确定费用对象，计费单位确定单价对应的数量，币种确定金额货币；三者共同限定价格含义。

**模型服务**（model_service）：具有永久模型服务 ID 和对外模型 ID 的调用入口。只关联已登记的上游模型，独立维护启停和路由配置。

**模型服务 ID**（model_service.id／引用 model_service_id）：创建后不变的具体入口编号。名称、调用值及价格变化不改变其身份。

**模型 ID**（`call_id`）：客户在平台 API 请求中填写的调用标识，在新建模型服务时设置，创建后只读。各对象字段见[字段与身份规范](MODEL_OPERATIONS_IDENTITIES.md)。
_Avoid_：上游模型调用标识、固定的“发布方/模型名”格式。

**上游模型分组**：模型服务按组优先级选择可用上游模型。同组按当前路由策略选择，连接切换不改变客户订购的服务。

**模型卡片**：模型广场用于展示一款模型的记录。卡片保存自身展示资料，运营人员从模型服务列表选择同款服务并确认保存。

**模型售卖**：商业版按模型服务 ID 保存的销售记录，包含刊例价版本、销售对象和售卖状态。每个模型服务最多一条售卖。

**模型刊例价**：平台向客户销售模型服务的计费规则与单价，在模型销售独立于采购报价维护。内部服务可无售价。
_Avoid_：服务商售价、平台目录价、采购价格。

**关联上游模型／连接路由**：关联确定服务可选的供给集合，路由确定请求在允许供给中的选择、分配或回退规则。关联成功不表示路由已经生效。

## 接入任务与配置

**接入任务**：围绕一款模型完成首次上架、准备备用供应或投入已有服务的工作。完成条件由任务目标决定，不以另一项服务已经上架替代。
_Avoid_：把接入任务当作第二份模型身份。

**未提交输入**：仅在当前编辑页面保留的内容；预览不写业务数据，确认提交后一次保存。后台不提供草稿保存与恢复。

**生效配置**：已经明确发布或应用、供相应业务使用的配置版本。
_Avoid_：最新编辑内容、未发布候选。

**备用供应**：已具备必要采购条件和有效连接检查、尚未投入当前服务路由的供给。
_Avoid_：把未分配流量的备用供应称为未完成接入或运行异常。

## 验证与状态

**测试通过**：本次选定范围的验证成功，不等于所有能力通过或服务已对外开放。

**启用模型**：让验证有效的上游模型映射具备技术供给资格；不替代正式服务的价格、能力及发布条件。

**应用配置**：明确将已验证的候选连接或密钥切换为当前配置；测试候选不自动覆盖当前配置。

**发布配置**：明确使检查通过的服务配置或路由版本生效，预览不写入，确认后一次提交。

**上架销售**：管理员确认技术已启用、经营服务成本／售价有效及销售对象后开放销售状态；不自动启用技术服务，不代表用户端已贯通。

**停用技术服务／停止销售**：在模型服务停用技术服务，停止处理新请求。在模型广场下架，停止客户新订购和新调用。
_Avoid_：仅隐藏模型、仅停止新增订购、删除服务。

**放弃本次修改**：撤销尚未保存的编辑，回到最近一次保存内容。
_Avoid_：删除已保存的资源或历史。

**销售对象**：模型内经营服务共用的 `salesScope`，经营上架前须配置。

**成本待核算**：没有可确认的适用价格或计量事实，不以零代替；后台技术验证可继续，历史不会因后补价格自动重算。

## 客户与登录身份

**客户** 是订购或使用模型服务的业务主体，分为政企客户和个人客户。**租户** 是系统承载客户项目、密钥和用量的隔离范围。业务界面用「客户」，接口和技术文档用「租户」。

**登录账号** 标识一个可登录前台的人。此人加入政企客户后，在该客户下是**企业成员**，其成员角色和状态由该客户管理。

**调用用户** 是一笔请求中记录到的具体用户。应用用 API 密钥发请求时，客户可以有明确归属，调用用户可能未采集。

**后台账号** 是平台人员登录运营运维后台的身份。


**使用空间** 是用户进入某一客户租户业务的环境，分企业空间和个人空间。一个账号可以进入本人已开通的个人空间和已加入的企业空间。

**项目** 属于一个客户租户，承载模型权限、API Key、预算与调用记录。企业空间支持多个项目；个人空间固定一个默认项目，由本人使用并继承个人空间的有效模型使用资格。

**主责部门** 是企业项目的组织归属与成本归集依据。项目可以由多个部门的成员共同参与。

**访问控制**：租户、登录用户及租户内组织成员与项目权限的管理入口。权限治理界面用「租户」，经营分析仍用「客户」。
