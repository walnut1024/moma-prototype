# MoMA 5.12.0 模型供给与销售术语

本术语表描述平台采购 Token、接入模型服务及对外销售的业务概念。

## 模型与供给

**模型**：平台统一识别和维护资料的模型对象，例如 K3。同一个模型可以由多个供应商提供。
_Avoid_：将不同供应商的接入记录当作不同的模型资料主档。

**供应商**：直接向平台提供模型 Token，并按采购价格形成平台 Token 成本的一方。供应商自行推理、中转或转售，不改变平台与该供应商的直接采购关系。
_Avoid_：以模型研发厂商或供应商背后的服务方替代平台的直接供应商。

**渠道**：平台访问某个供应商模型服务的一组接入配置，包含接入地址、凭证和协议。渠道是技术接入对象。
_Avoid_：以渠道名称代替供应商主体；将渠道等同于单个 API Key。

**渠道模型映射**：平台模型与某个渠道中的上游模型标识之间的对应关系。

**采购报价**：供应商针对模型及采购条件提供的一组计费规则和价格。同一供应商、同一模型在相同采购条件下可由多个渠道共用报价。
_Avoid_：将采购报价称为平台销售价格。

**Token 成本**：平台按实际供应消耗和适用采购报价计算的成本。
_Avoid_：客户收费、销售收入。

## 对外销售

**销售服务**：平台针对某个模型，按确定的供应范围和销售价格向客户提供的服务。同一个模型可以同时提供指定供应商服务和平台统一服务。
_Avoid_：用供应商、渠道或模型资料记录代替可独立定价的销售对象。

**模型发布方**：销售服务对外使用的发布主体。按供应商分别售卖时使用对应供应商的标识，平台统一售卖时使用平台标识；采购成本仍归实际提供 Token 的供应商。
_Avoid_：将模型发布方固定解释为模型研发厂商，或仅凭发布方标识确定采购成本。

**对外模型标识（Model ID）**：客户在统一的平台 API 地址中选择模型服务时使用的标识，格式为 `模型发布方/模型名`。
_Avoid_：将对外模型标识等同于渠道中的上游模型标识。

**按供应商分别售卖**：平台分别销售各供应商提供的同一个模型，并分别设置销售价格；客户选择具体供应商对应的服务。

**平台统一售卖**：平台通过一个对外地址和模型标识提供服务，并按策略在允许的供应商之间分配请求。实际供应商切换不自动改变客户适用的销售单价。

**销售价格**：平台向客户提供某项销售服务时采用的计费规则和价格。
_Avoid_：采购价格、供应商成本。
