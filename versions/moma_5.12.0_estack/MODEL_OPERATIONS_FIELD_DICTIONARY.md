# 模型运营字段命名与归属

范围：渠道接入、模型服务、模型广场、模型成本、模型售价、模型资料及计量字典。术语定义以 [GLOSSARY](GLOSSARY.md) 为准；本表记录界面旧称、标准名称与当前字段归属，不重命名既有数据键或历史快照。

| 标准字段 | 发现的旧称／混用 | 含义与归属 | 当前取值依据 |
| --- | --- | --- | --- |
| 模型展示名 | 模型、模型名称、模型显示名 | 主档的人类可读名称，可重复；列表合并按主档稳定引用，不能按名称去重 | 主档 `name`、服务引用主档名称 |
| 资料 ID | 模型 ID、内部模型标识 | 主档内部关联键，不是调用参数 | 主档 `id`、服务 `templateId` |
| 规范模型标识 | 模型编码、规范 ID | 模型资料的稳定业务标识，不是服务商请求参数或对外调用参数 | 模型资料的 `modelId`；与服务记录中同名键的含义区分 |
| 对外调用标识 | 对外调用标识、调用 Model ID、平台 Model ID、调用 ID | 客户向平台请求时填写的 `model` | 统一模型服务模式 `model.modelId`；渠道直选模式 `serviceProviders[].callId`；由 `routingServices` 投影 |
| 上游模型标识 | 上游模型 ID、上游 Model ID、上游请求标识 | 平台请求服务商时填写的模型参数 | 渠道关联／供给 `upstreamModelId`；目录登记的 `modelId` 不直接替代它 |
| 模型作者 | 厂商、发布方、服务商 | 模型研发或发布团队，与提供接入的服务商区分 | 主档 `profile.author`／`maker` |
| 服务商 | 供应商、Provider、服务提供方 | 平台直接采购或接入的服务主体。统一模型服务模式的提供方是平台内置服务商，不代表每个上游来源 | `providers[].id/name`；统一模型服务模式使用 `provider-moma` 的当前名称 |
| 服务商编码 | 供应商编码、Provider 编码 | 服务商主体的业务编码；内部 ID 不以中文名称替代 | `providerCode`／服务商 `code` |
| 连接 | API 资源、接口 | 服务商的接口、地址与认证配置；供多个模型来源复用 | `endpointId` |
| 渠道 | 连接、服务商 | 某款模型的独立供给来源 | 渠道模型关联 ID、来源名称 |
| 服务根地址 | Base URL、API 地址 | 标准接口的根地址，与完整任务请求地址区分 | 连接 `baseUrl` 与接口类型配置 |
| 上游 API 地址 | 请求地址、完整 API 地址 | 已解析的实际模型任务地址；不再用模糊的“接口”指代 URL | 渠道地址解析函数与当前关联 |
| 计费项名称 | 名称、英文名称混排、场景 | 人类可读的费用对象；本页不维护底层计量指标 | 计费项字典 `name`；价格项保留调用时名称快照 |
| 计费单位 | 单位、计价单位、计量单位 | 单价对应的数量，例如百万 Token、秒、次；与数量和货币分开 | 价格条目 `unit`、单位字典；历史包含“元/”的旧单位暂不改写 |
| 货币 | 币种、金额前缀中的币种 | 价格的货币代码，与计费单位分开 | 价格条目 `currency`、货币字典 ISO 代码 |
| 采购价 | 成本、渠道售价、服务商售价 | 平台采购单价，与计算所得成本总额区分 | 生效采购版本或历史采购快照 |
| 售价 | 平台售价、客户单价、销售价格 | 客户对外计费单价；不能从采购价推断 | 生效销售版本 `items[].amount`，缺值与零分开 |
| 服务状态 | 技术状态、销售状态混用 | 顶部概括当前上架阶段，正式上架／已下架／灰度上架 | `listingStatus`、`releaseStage`；不等同技术开关 |
| 可见性 | 展示、市场可见、销售展示 | 展示配置及灰度范围，独立于上下架和调用授权 | `marketVisible`、`releaseStage` |
| 技术状态 | 运行中、调用开关、服务启用 | 技术服务是否允许新调用；保留原事务和校验，不能从“已上架”伪造 | `callsEnabled` 及当前技术验证 |
| 销售状态 | 售价状态、价格状态 | 售价列表已有的经营可用性判定，不等于“已配置售价” | `salesStatus` |

## 模式与策略对照

| 界面名称 | 定义 | 稳定内部值 |
| --- | --- | --- |
| 统一模型服务模式 | Provider-Agnostic Routing，用户只选模型，平台选择服务商、负载均衡和故障转移 | standard |
| 渠道直选模式 | Provider-Explicit Routing，用户选择具有独立售价和调用标识的渠道服务，平台不切换到其他渠道服务 | provider |

路由策略名称与配置标识以共用 routing-policy 字典为准；模型展示名、对外调用标识、上游模型标识、服务商、上游渠道各有归属，不混用内部记录 ID。旧称统一服务、分服务商、分供应商不再用于当前界面和帮助；历史审计原文保留。

## 本轮处理

- 模型运营源界面和校验文案统一“服务商”，服务模式显示“渠道直选模式”；仅替换显示词，`providerId`、`supplierId`、`provider` 模式值、URL 参数与内部字段不改名。
- 成本／售价／服务主界面的名称与调用标识按以上口径展示。成本与售价按模型稳定引用合并单元格，售价按计费项逐行展开金额、计费单位、货币。
- 不批量改写用户已有服务商名称、模型资料、导入文件、审计、价格快照或请求历史。历史记录中的旧称作为原始证据保留。
- “模型 ID”“API 地址”“状态”等模糊旧字段须按所在对象核对，不能全局替换成同一个概念。旧导入表头与现有协议键不因页面文案变更被静默重命名。
