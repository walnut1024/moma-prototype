# 模型运营 Mock 数据

全站初始数据、用户配置和双面运行数据的总合同见 [MOCK_DATA.md](MOCK_DATA.md)；本文说明模型域的引用与案例。

## 配置与运行数据

模型运营初始数据集中在本版本的 [src/mock/](src/mock/)；页面不各自创建一套样例。配置随 Vite 静态构建进入产物，可用于现有 Cloudflare Pages 发布流程，无需本地文件接口或额外后端。本轮不部署。

| 文件 | 职责 |
| --- | --- |
| [system-model-catalogue.json](src/mock/system-model-catalogue.json) | 系统内置基础目录，保留分析、部署、计费等模块所引用的历史稳定 ID |
| [initial-workspace.json](src/mock/initial-workspace.json) | 旧评审资源的初始配置差异；按 ID 覆盖基础目录，仅用于创建新工作区，不在读取存档时执行生成器 |
| [model-operations.json](src/mock/model-operations.json) | 当前模型运营场景：模型资料、供应商、共享渠道、模型映射、采购价、售价及生效路由 |
| [model-data.js](src/mock/model-data.js) | 配置校验、一次性初始化、来源标记和各页面共用的目录范围 |

初始数据与用户配置分开管理：JSON 是只读初始资源；浏览器版本独立存储中的业务状态是运行数据。modelData.builtinIds 标记初始资源身份，userIds 记录用户新增、修改或删除的资源 ID；修改内置资源后，其内置身份保留，用户修改也单独登记。datasetVersion 仅记录创建时采用的配置版本，不触发升级覆盖。

首次没有存档时，创建内置资源并应用当前运营场景。已有存档的模型运营集合原样恢复；缺少集合保持空，不补回已删除模型、供应商、渠道、关联、草稿或历史。不带来源标记的旧存档按用户已有数据保留，不凭名称猜测哪些可以删除。配置更新不会重置浏览器，手工数据也不会反写仓库 JSON。

## 身份与页面关系

模型资料以稳定主档 ID 关联模型服务；供应商目录通过 libraryId 指向同一主档。供应渠道是可复用资源，模型映射单独引用渠道及实际上游 ID。服务引用自身的供应映射，售价与路由引用明确的服务 ID。

基础资料、供应管理、模型服务共用当前目录范围。默认展示当前场景和用户新增、修改的资源；历史系统案例保留在“全部模型”范围，旧服务深链仍可进入。未知来源的旧存档不被静默过滤。新增服务选择器读取同一范围内的基础资料，已有服务标记依据完整稳定引用；不能用显示名称推断身份。

前台不保存第二份可编辑模型目录。模型广场及详情读取后台运行状态，公开资料来自生效主档；报价、请求模型名称、API 指南与在线体验按所选服务生成。未发布的售价草稿不会进入客户接口，采购价、凭证和内部指纹不对客户暴露。

## 当前对比案例

型号、日期、能力与报价均为演示数据，不作为外部核验结论。

| 模型 | 主档 / 服务 | 模式 | 供应与路由 |
| --- | --- | --- | --- |
| GLM-5.3 | template-glm-5.3 / model-glm53 | 分供应商 | MoMA 自营/转售 70%/30%；智谱原厂单渠道 |
| DeepSeek-V4-Flash-0731 | supplier-template-DeepSeek-V4-Flash-0731 / mock-service-deepseek-v4-flash-0731 | 统一服务 | MoMA 自营/转售、DeepSeek 原厂 50%/30%/20% |

## 准备与验证

1. 新工作区创建配置完整但下架、未开放调用的案例，不伪造平台发布回执。已有存档不在刷新时加载案例。
2. 已有工作区可在“研发人员注意 → 前台与服务”显式准备两个案例。同 ID 已编辑、同编码不同 ID 或未发布草稿等冲突会阻断整批准备；原数据不变。准备成功后重放不覆盖后续修改。
3. “验证并上架两个案例”通过现有本地 API 执行渠道测试、平台试调用、发布与明确上架；失败保留已完成进度，不跳过校验。也可用业务页面逐项完成。地址为 example.invalid，凭证只有 Mock 掩码及指纹，不请求真实上游。
4. 前台登录相应 Mock 用户后，核对两张模型卡片、三个服务报价、调用 ID、API 指南与在线体验。GLM 切换 MoMA/智谱，DeepSeek 保持平台统一服务，不展示供应商选择。

配置结构、唯一 ID、主档引用、供应映射、售价单位及路由权重在构建时校验。自动化入口为 [model-data-config.test.mjs](tests/model-data-config.test.mjs) 与 [service-showcase.test.mjs](tests/service-showcase.test.mjs)，涵盖保留性、冲突及前后台闭环。

## 存储与发布边界

本地和 Cloudflare 使用相同静态配置；用户编辑保存在当前浏览器、当前域名的版本独立存储中。localhost、127.0.0.1 与 Cloudflare 域名的数据互不同步；部署新代码也不会自动更新旧浏览器的业务配置。跨用户共享数据、云端保存、配置升级合并与重置入口不在本轮范围。
