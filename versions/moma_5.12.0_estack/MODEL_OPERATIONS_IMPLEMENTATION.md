# 模型运营实施入口

当前实施范围、阶段和验收采用[五模块执行计划](MODEL_OPERATIONS_REORGANIZATION_PLAN.md)；实际验证及本地提交见[实施台账](MODEL_ONBOARDING_PROGRESS.md)。

- 内部管理流程：模型资料 → 渠道接入 → 模型服务配置、调用授权与模拟验证 → 技术启用。成本可并行或后补，缺价待核算，不要求销售。
- 经营管理流程：模型成本 → 模型售价发布 → 销售对象与展示设置 → 检查后上架／停售。销售动作不替代技术启停或扩大调用授权。
- 页面、状态、数据保护采用[页面规格](PAGE-SPEC.md)；具名验收采用[管理端矩阵](MODEL_ONBOARDING_ACCEPTANCE.md#五模块管理端验收2026-11-06)。
- 本地检查通过后仍不自动推送或部署；用户端身份、用户 Key、购买、实际调用与结算不属于本轮。
