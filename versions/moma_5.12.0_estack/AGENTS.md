本文件补充[项目规则](../../AGENTS.md)，仅适用于此独立版本。

## 版本边界

- 本版本源码和资源在本目录 `src/`、`public/`；别名 `@` 指向本版本 `src/`，CSS 扫描保持在本版本内。
- 版本独立存储包括管理数据、角色、认证、组织、对话、筛选和图表布局；不隐式迁移 5.11.0 浏览器记录。

## 关键业务约束

- 模型资料是统一身份和基础资料主档；供应管理维护真实供应关系、渠道、密钥和采购价；服务管理维护销售模式、对外调用 ID、平台售价、客户范围及服务内路由。复用稳定 ID/明确关联，不按名称相似合并、不复制第二套可编辑主档。
- 统一服务使用模型级统一售价；渠道直选模式按选定的渠道服务维护对外 ID、售价、路由和上架阶段；同服务商可有多条，按服务商分组操作。销售对象在同一模型内共享。每个模型只选一种模式；切换须明确确认并通过既有原子重置/下架事务，资源与不可变历史保留。
- 供应商、渠道、模型关联的检查/启用，以及路由生效、配置发布、服务上架各有条件；技术接入完成不等于客户可用。新增资源不自动参加服务/路由、不自动上架，完成状态必须来自当前资源及校验。
- 关联/删除检查活动资源和草稿引用，保留影响确认，不能因入口简化绕过校验。仅影响调用的配置变更使相关验证失效；名称或成本变更不清除验证。
- 供应密钥仅持久化脱敏元数据和指纹，明文不进入草稿、审计或产物；轮换/撤销按实际共享范围处理。主体/模型/Key 的接入保存保持原子性，失败保留当前配置。
- 采购和销售独立定价及版本化；按调用时价格/快照核算，不用当前价追算历史，缺价或条件不明保留待核算。客户接口成功与失败均不得返回内部采购价格快照。
- 参考目录、派生用量和评审案例保留各自来源与边界，不补造报价、凭证、身份或指标。
- 运营完整自然日口径与租户/运维时间口径分开；请求、用户、客户、实际渠道及重试归属使用明确事实，不从其他身份或摘要推断。

## 验证与维护

以下命令从 `prototype/` 根目录执行，按改动范围选择；根 `npm run lint` 和 `npm test` 不覆盖本版本完整源码和业务测试。

| 改动范围 | 检查命令 |
| --- | --- |
| 模型运营逻辑（其他模块选择其既有测试） | `node --test versions/moma_5.12.0_estack/tests/model-operations.test.mjs` |
| JavaScript/JSX 或测试变更 | `./node_modules/.bin/oxlint versions/moma_5.12.0_estack/src versions/moma_5.12.0_estack/tests` |
| 源码、样式或资源变更 | `npm run build:5.12.0` |
| 跨模块领域逻辑或版本发布回归 | `node --test versions/moma_5.12.0_estack/tests/*.test.mjs` |
| 构建、路由、版本隔离或发布 | `npm run build && node --test tests/version-copy.test.mjs tests/version-retirement.test.mjs`；Sites 检查遵守项目规则 |

- 仅文档变更时检查链接、锚点、规则一致性和范围；不因本表运行应用构建或业务测试。
- 页面规则修改同步对应规格、帮助/研发说明与相关验收要求；实际执行结果记录在适用 PROGRESS，不在本文件累积页面细节、部署 ID、测试数量或历史任务范围。
- 项目与版本规格只保留有效要求；被替代条款留历史归档，修正旧引用，避免用历史材料恢复已删除入口或旧定价方式。
