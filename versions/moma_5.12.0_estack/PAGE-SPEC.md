# 5.12.0 页面当前约束

- 个人、企业和后台统一使用 `#/auth/login`。验证成功后按账号身份及角色进入空间或后台工作区，只有原地址在当前权限范围内时才恢复；后台所有模块共用服务端会话，不保留模块登录页或登录弹窗。401 返回统一登录并保留原路径，403 显示权限拒绝；退出及账号切换撤销旧会话。

本文件汇总本版本有效页面与业务约束。模型运营以本页导航和各模块规则为准；实际本地验证及发布边界见[实施台账](MODEL_ONBOARDING_PROGRESS.md)。历史 UX 文档不恢复已移除的入口或旧前置条件。

后台操作入口按用途命名。创建独立记录用「新建」，提交时用「创建」；向当前配置增加条目用「添加」，建立已有对象的关系用「关联」。入口、标题、面包屑及指引使用相同的对象名称。

## 全站 Mock 数据与双面联动

- 5.12.0 初始资源、参考目录和模拟响应统一在 `src/mock/` 配置维护，私有化发布使用 Workers + D1 保存模型运营、模型目录、订购、项目配置与调用记录。本地演示使用版本内浏览器业务存储；详见 [Mock 数据合同](MOCK_DATA.md)。本节替代共享页面中“组织及成员仅保存在独立前台样例”的旧约束，仅适用于本版本。
- 系统初始数据与用户配置分开标记；恢复存档不重放初始生成器、不补回删除资源。手工记录、草稿、订单、历史与未知来源数据保留，旧无归属记录不自动认领。
- 前台 Key、订购、客户智能路由、在线体验和后台组织成员记录落到共享业务集合；客户作用域、所有者、修订冲突及存储错误在写入边界校验。后台修改相同记录后，前台经事件、同源标签页更新或聚焦复查读取新值。
- 「智能路由」提供「智能匹配」「模型预设」两个项目级页签。智能匹配首页只展示 Auto Router，企业管理员、当前项目管理员或个人本人从「路由设置」独立配置、保存和生效 `moma/auto`、`moma/performance`、`moma/cost`。「项目分流」从「智能路由」打开，绑定当前项目。预设有独立详情、编辑、API 调用和版本历史，切换历史版本须重新校验当前资格，调用 ID 保持稳定。启用的 Auto Router 和预设可从详情进入文本生成试用。智能匹配、模型预设的保存、版本、停用、试用、API 示例及调用均绑定同一项目；企业切项目切换配置并退出原项目的预设详情或编辑，个人固定唯一默认项目。各项目可独立使用相同调用 ID，API 按 Bearer 密钥所属项目解析，不接受客户端覆盖项目。项目管理员维护项目智能匹配；普通成员可查看已生效智能匹配及自己的模型预设，保留自有预设维护权，不能访问未加入项目。候选范围同时受项目模型权限、空间授权、订购及 Key 权限限制。后台读取与调用模拟使用同一项目归属和权限，路由审计记录项目 ID；保留稳定 ID、草稿、版本及调用历史。
- 从「智能路由 → 项目分流」进入。项目管理员或企业管理员可编辑，已分配项目的普通成员可查看。API Key 条件引用同项目的有效 Key ID，用户标签条件匹配 `metadata._user`。按规则顺序选取目标服务，未命中使用默认服务，备用模型服务按保存顺序尝试，最多五个。私有化发布的调用示例保留 `project@策略标识`，配置与模拟调用使用客户工作区。
- 调用日志、租户用量、平台概览及用户统计从同一请求和显式身份事件派生。未采集 Tokens、费用或时延显示未知；本地回复不构成真实上游或计费证据。图表样例继续使用静态 JSON 配置和原有派生逻辑；不写入 D1。用户侧未迁移模块仍使用浏览器存储，不与 D1 自动双写。
- 前台编辑在打开时冻结修订号，跨标签页更新不得静默覆盖当前输入；冲突保留输入并要求刷新。账号/客户切换清除旧临时表单及明文 Key，已保存筛选视图按身份隔离。关闭 Key 额度后保存/刷新保持不限，相同额度与周期重新启用保留原用量；TPM/QPM 按实际值保存和模拟校验，不豁免客户额度与权限。
- 用户面项目选择、项目管理和项目分流复用 Semi Design 的页签、操作控件、表单与浮层。窄屏表格在当前面板内滚动，关闭分流编辑前确认未保存的修改。
- 模型广场筛选、搜索、详情操作和订购确认使用 Semi Design。窄屏筛选在抽屉打开，关闭时保留筛选条件并将焦点还给入口。
- 文本生成的输入、参数与新建确认，以及体验共用的模型选择弹窗使用 Semi Design。模型选择保留供应商、类型、计费方式和可体验条件，并沿用项目调用权限。客户账单使用 Semi 表格，用户面共用分页保留原有页容量。
- 文本、图片及视频体验的推荐提示沿用 Semi 填充与文本色；文本推荐在中等宽度显示三列、窄屏显示两列，保留完整提示词填入。新建对话与账号认证的主要入口使用实色按钮。体验参数使用业务名称与必要范围，不重复展示接口字段名。用户面弹窗限制在视口内，项目名称的必填错误在表单内中文提示。订购费用与确认区排在协议之后，不遮挡表单。
- 账号菜单、登录空间选择、密码找回、邀请与个人或企业认证使用 Semi Design。认证保持字段校验、协议链接和分步提交，错误保留在原表单中。
- 密码找回与修改复用登录页的品牌区和表单容器，保留验证码、密码校验与返回路径。
- 空间总览、用量统计、调用观测与调用日志共用 Semi 筛选和视图保存。调用日志使用 Semi 表格和请求详情抽屉，保留筛选导出、详情 JSON 和既有脱敏规则。
- 用户面空列表保留记录数，零条时隐藏分页操作。订购表格按服务、订单及订阅的原始 ID 标识行，刷新不重复。项目表格铺满当前面板并在窄屏局部滚动，日志长服务标识在列表中限两行并提供完整悬停值。组织操作时间按北京时间显示。
- 图片生成、视频生成、语音识别和模型对比使用 Semi 操作控件、参数弹窗与输入框。窄屏时对比列在当前面板内横向滚动，保留同步输入、独立参数和会话权限。
- 组织及成员、批量添加和 API Key 使用 Semi 表格、筛选、表单及浮层。批量添加保留校验和结果步骤，明文 Key 仅在创建或重置成功时交接。
- 统计分类匹配实际模型类型，基础模型筛选纳入其服务商服务调用；请求保留发送时调用 ID，未知计量不填零，音频秒数/字符与 Token 分开。不使用固定样例数作为当前套餐权益或剩余额度。
- 动态历史样例只绑定固定初始资源且保留有效归属，不能因新增/编辑 Key、模型或成员而重分配历史；用户真实动作产生的请求独立保留。重复 Request ID 校验 Key、客户、模型及服务归属，冲突不返回原记录，已撤权 Key 不能重放成功。

## 前台项目管理

- 账号是登录身份，客户/租户是资源和结算主体，空间是进入该主体的控制台视图，项目固定归属一个空间。组织部门和企业成员属于企业空间；项目只引用本企业的部门及成员。同一账号可加入多个企业，也可拥有一个个人空间。多空间从账号菜单切换，单空间不显示切换入口。
- 用户控制台顶部入口为首页和模型广场。功能导航提供「账户管理」，用于查看账号资料与认证。「系统管理 → 项目管理」仅企业空间提供，「当前项目」从该入口下方切换。项目管理默认呈现「我的项目」页签，按企业列出当前账号实际加入的项目，并展示本人在每个项目里的成员角色。仅租户管理员可使用「全部项目」页签，查看当前租户的全部项目及既有部门分组。页签下方左侧是可搜索的项目树，右侧是项目详情。进入页签优先展示当前范围内的当前项目，其次展示本空间第一个可访问的正常项目。窄屏上下排列。
- 个人侧栏从首页进入默认项目概览，直接在默认项目执行体验、接入与调用及调用观测，通过使用设置维护默认项目。企业普通成员可查看授权项目，密钥维护需项目管理权。「系统管理 → 组织及成员」显示登录企业的组织树、成员及操作记录。租户管理员管理本企业，部门管理员管理授权部门内的普通成员。
- 文本、图片、视频、语音体验以及用量统计、调用观测、调用日志均为独立页面入口；模型订购与订购及账单分别进入。保留页面原有业务分类页签；模型订购的按Token用量计费、Token Plan订阅、Coding Plan订阅页签仅将展示名称改为「按量计费」「套餐订阅」「资源包」，内部计费标识、订单记录及过滤逻辑保持不变。账号认证可从「账户管理」或右上角账号菜单进入。空间切换和退出登录从右上角账号菜单进入；模型广场、模型详情和模型订购页面不再显示独立账号/退出广场状态条。
- 私有化站点依据部署授权和已保存的空间策略区分对内使用与对外运营。内用提供本企业空间及授权模型，后台入口为「本组织」，前台按项目使用模型。工厂外营开放多个政企客户及个人客户，政企开户容量与部署方式分别校验。企业内外共用组织与项目权限，部门用于项目归属及成员查找。
- 工厂工作区由企业管理员或个人客户本人按当前空间订购有效按量服务。企业订购生效后在本空间项目分配相应模型；个人默认项目直接继承已开通模型。订单归属空间，调用费用按请求归属项目，通过前后台同一组记录查询订单及用量账单。企业内用在后台按调用时项目主责部门归集成本。
- 个人注册及后台开户原子创建一个默认项目并记录 defaultProjectId，前台命令和后台事务均拒绝增加、替换、重命名、转移或独立改变默认项目状态。历史单项目记录保留原始名称及 ID，以「默认项目」显示；异常记录明确报错，不自动合并或删除。租户管理员可新建和删除本租户项目。创建人获得项目管理员角色。租户管理员和该项目的项目管理员可添加、移除和查看项目成员，并可把新增或已有成员设为「项目管理员」或「普通成员」。项目管理员退出、被移除或降级前须保留另一位有效项目管理员。普通成员在项目管理中可查看已加入项目和成员，并可切换到其他已加入项目；个人项目由本人管理。
- 企业项目详情在标题区展示项目信息，下方默认打开「项目成员」。租户管理员和该项目的项目管理员可编辑项目信息，并使用「项目预算」和「模型限流」页签。新建与编辑仅填写项目名称和描述，既有部门归属保留。具备相应权限时，详情标题区直接提供「编辑项目」「删除项目」或「退出项目」，已停用的企业项目可通过「启用项目」恢复。删除后保留项目 ID、调用、Key 关联及审计。API Key、项目分流及日志留存按当前项目使用。个人「使用设置」保留默认项目的预算、日志、限流和分流。
- 企业新项目逐个开通模型。已有项目缺少项目级配置时继承当前空间授权。项目管理员在空间授权范围内开通模型和配置每模型 RPM／TPM，限制跨项目内全部 Key 与在线体验。空间撤权即时阻断项目调用。项目路由按规则匹配或选择默认模型，备用模型也需通过项目与 Key 权限检查。
- 企业「项目预算 → 设置额度」以百万 Tokens 配置项目预算和每日批处理 Token 限额。预算周期可选永不重置、每小时、每天、每周和每月，按北京时间自然周期统计，周一开始。项目预算统计项目已成功调用的输入和输出 Token，在线体验和 API Key 共用额度，超额拒绝调用。项目 TPM 与 RPM 按最近 60 秒限制项目总量，并与模型和 Key 各自的限流同时生效。每日批处理限额可保存，待批量调用接入后执行。
- 企业首次保存 Token 额度后，项目预算按 Token 规则执行，既有人民币预算记录保留。个人使用设置沿用既有预算。按量 Key 支持独立累计人民币预算，Token Plan Key 支持独立套餐抵扣 Token 预算。所有手工 Key 可设置到期时间。未确认费用单列；无法核算受人民币硬预算约束的新调用时返回错误。套餐购买费用归订购空间。
- Key 在指定项目创建、编辑、启用、停用、重置和删除。用户控制台「API 密钥 → 订阅套餐」按项目 ID 与订阅 ID 独立管理每份订阅的密钥，同名套餐不合并；模型选项取项目和本套餐允许范围的交集。编辑、重置、删除不得改变其他订阅的密钥，不得把已有密钥转入另一订阅或按量范围。创建与重置的密钥只在一次性交接弹窗显示，关闭即清除。列表显示掩码，历史和操作记录保留稳定 Key ID。托管体验 Key 按项目自动使用，隐藏明文和维护操作。
- 模型广场详情点「在线体验」先校验当前空间订购或授权，再使用当前可访问项目；唯一项目自动进入，多项目未选择时弹窗选择。企业空间未订购时管理员可订购，普通成员提示联系企业管理员；内用缺少授权提示管理员。项目未分配模型时项目管理员通过「配置模型权限」授权，普通成员提示联系项目管理员。个人绑定默认项目。模型详情、文本、图片、视频、语音及模型对比发送时绑定项目。配置、调用资格、订单及会话由各自写入边界校验。留存开关默认仅保存日志元数据，开启后新请求可保存脱敏输入输出，仅项目管理员查看，CSV 不含正文。对话历史沿用账号访问规则。
- 个人默认项目概览按北京时间展示请求数、Token、费用和成功率及上期同进度对比。单日按 10 分钟、多日按天显示请求与费用趋势；模型与 API Key 按调用费用或请求数展示 Top 5。配置摘要直达预算、模型权限、项目分流及 Key；用量、日志及请求详情保留项目范围。

## 前台用量统计

- 从「调用观测 → 用量统计」进入，默认打开「概览」。项目入口的热力图、用量分析及导出使用同一项目范围。顶部提供语言、多模态理解、视觉、语音、向量、排序六类模型页签。概览在筛选上方展示近 365 个北京时间自然日的 Token 用量活动。按日每格一天，按周每格一周（周一为起点，首尾按区间截取），累计每格为从区间起点至当天的累计。零值和无计量分别标识。
- 下方「用量分析」首层显示时间、计费方式和项目，筛选仅影响用量分析区。「更多筛选」的调用方组包括 API Key 和调用用户，模型页签增加模型范围组。已选条件持续显示实际日期和生效的细筛条件。项目和计费方式约束 Key，项目、计费方式及 Key 约束已记录的调用用户。政企管理员可筛选调用用户，未记录调用人归入「未识别用户」。变更上级条件会清除失效的下级条件，切换日期保留查询对象。保存视图保留页签和有效筛选。
- 概览指标包括调用次数、调用模型数、调用成功次数及成功率、调用失败次数、已计量 Token、平均每次 Token 和调用费用。桌面宽度允许时排成一行，数量达到 1 万或 1 亿时按对应中文单位缩写，悬停显示原值。Token Plan 显示已记录的套餐抵扣。平均每次 Token 仅以有 Token 计量的调用为分母。订购模型数取当前空间有效订单中关联的模型，按模型去重，说明中展示模型类别分布。
- 概览的用量分析并列展示 Token 构成和已订购模型用量占比，下一行展示单模型用量趋势。模型占比及趋势只统计当前有效订购模型在所选范围的已计量 Token，前五单列、其余合并。趋势单日按小时、多日按天，自定义日期最多 31 天。
- 概览底部展示模型、项目、API Key 三个榜单。三榜共用排序指标，默认按调用次数排序，费用按同一币种比较，各用量榜仅统计有相应计量的调用。切换排序只更新榜单。点模型进入对应页签并选中该模型，点项目或 Key 在概览收窄范围。类别未知的调用仍计入概览调用次数。
- 模型页签保留汇总条、双列趋势和右侧图表导航。选定模型 ID 后展示适用的 Token 构成，采集到上游缓存命中量时展示 Prompt 缓存分析。命中率以同一批请求的输入 Token 为分母，命中 Token 计入输入。语言和多模态理解统计输入、输出及适用的缓存分项，向量和排序只展示有计量的输入 Token。视觉分开显示图片张数、视频时长及已计量 Token，语音识别时长与合成字符数分别统计。
- 年度活动和用量分析复用同一请求去重和 Token 计量规则，分别按各自范围统计。用量分析基础时间桶为北京时间单日 10 分钟、多日按天，含今日时统计至快照时间。CSV 导出当前页签的筛选范围，概览导出按各模型的实际类别标记。仅在本地开发链接 `?page=usage-statistics&usageDemo=1` 使用独立模拟请求。

## 模型运营云端持久化

「模型服务」的列表、详情和变更共用现网 D1。平台管理员和运营人员可逐条导入当前浏览器保存的记录，沿用服务 ID、配置、创建人和创建时间。同一 ID 重复导入不会覆盖现有配置，调用标识冲突时提示核对。

- 连接列表（`providers-reference`）、模型服务（`listing-new`）、模型广场、模型销售及基础资料通过版本 API 读写 D1。模型服务列表和维护使用 `/model-services-new`；连接、资料、采购及售价沿用模型运营工作区。浏览器保留页面筛选和未提交的输入。
- 后端以 HttpOnly 会话确认账号及权限，复用 5.12.0 领域规则；前端提交预期修订和操作 ID。业务变更、模拟状态、回执和审计一次原子保存，成功后才关闭编辑；失败保留输入，未知提交结果先核对原操作，冲突要求载入最新数据。断网不回退为本地保存成功。
- 新 D1 初始化计费字典和参考模型主档。演示环境的研发说明提供独立演示包入口。导入复用稳定主档，冲突时整包拒绝。日常登录与刷新读取已有工作区。
- 私有化发布的客户身份、连接订单、项目 Key 和各在线体验的项目调用由 D1 校验及保存。项目配置与统计按「前台项目管理」执行。原型调用使用模拟上游。

- 租户空间、账号认证、调用日志、API Key、客户与后台账号沿用[对应共享页面章节](../../docs/PAGE-SPEC.md)；用户管理、账号管理、Token 生产等模块的保留与入口以本版本规格为准。「组织及成员」及其操作记录从用户控制台的「系统管理」进入。个人空间从项目详情查看该项目的调用日志。

## 私有化站点配置

- 运营侧栏的「访问控制」提供「租户管理」和系统管理员使用的「项目管理」。工厂外营展示企业和个人租户列表，项目列表可筛选租户。企业对内的租户管理直接打开配置的默认企业，项目列表限定在该企业。商业运营侧栏提供模型销售和套餐管理。项目详情提供项目用量查询。

- 「平台管理 → 路由设置（全局）」仅系统管理员可访问。默认打开「全局故障转移策略」，最短重试间隔位于最大重试次数下方，仅在全局配置。保存写入原有字段，取消放弃草稿。
- 全局路由设置包含「全局故障转移策略」「全局路由策略」。重试使用 num_retries 与按异常类型覆盖的 retry_policy，留空与零分别表示未指定和禁用该类重试。max_fallbacks 限制降级尝试次数。旧配置打开时保留已有重试选择。全局算法默认加权随机。
- 模型服务统一继承全局路由算法，在「上游模型」页只读展示“路由策略：算法名（继承全局）”。「故障转移策略」在当前页切换继承全局与自定义，支持页内保存或取消。
- 「平台管理 → License 管理」以一张卡片展示授权范围和状态，运营模式、有效期与已有授权信息在下方对齐展示。页面不列功能清单。商业版显示「政企标准版 + 商业化增强」，内用版显示「政企标准版」。平台管理员通过弹窗粘贴并校验 License，缩小授权范围时需二次确认。内用版展示商业运营分组并标记未授权，禁用商业入口并拒绝商业路由和写入。商业版到期后保留历史查看，写入端拒绝新增订单、开售、售价与销售对象变更及套餐命令。已有订单以原调用权限核验。
- 商业运营侧栏展示「模型销售」「套餐管理」。按具体模型服务维护模型刊例价。经营分析按账期汇总后台已记账的出账与实收金额。

- 私有化构建通过 `VITE_MOMA_PRIVATE_SITE=1` 开启「平台管理 → 站点配置」，仅平台管理员可访问。公开部署的常规构建默认关闭。
- 「基础配置」分别维护「用户控制台展示名称」与「管理工作台展示名称」。前者用于用户控制台顶栏和共用登录品牌区，默认「模型服务平台 MoMA 政企版」。后者用于后台顶栏和概览欢迎卡，默认「Token 管理工作台」。两个名称独立保存，留空使用各自默认值。已有单一平台名称带入用户控制台展示名称。Logo、浏览器标题、Favicon 和认证插图分别配置。图片支持本地上传（单张 512 KB）、HTTP/HTTPS 链接、预览和恢复默认。
- 「协议管理」通过「用户协议」「隐私政策」切换文档，每次展示一个宽版编辑区，支持正文、HTTP/HTTPS 外部链接、草稿预览和分别恢复默认。两份协议通过「保存协议」一起发布。每份协议有可复制、无需登录的站点地址，认证及邀请沿用同一地址。公开阅读只读取已保存的服务端配置，未配置正文或链接时读取对应内置模板。
- 基础配置使用版本专属的浏览器本地存储。协议发布由系统管理员经同源接口写入原型数据存储，比较修订号，保存失败保留草稿。首次发布前可在编辑器带入当前浏览器已有的自定义协议，保存后对外生效。两类配置都以站点为范围。

## 平台审计日志

- 「平台管理 → 审计日志」仅向系统管理员开放。列表和详情使用当前后台账号的服务端会话，未登录统一跳转 `#/auth/login`，登录后按权限返回原页面。通过 `/api/v1/audit-logs` 读取已有 D1 审计事件，覆盖发布服务路由、轮换共享密钥、替换 API 密钥、批量停用所选上游模型供给、项目管理和个人空间开关。
- 列表依次展示事件 ID、时间、操作人、操作类型、模块、IP 地址、客户端、租户、项目、结果和操作对象。按时间与事件 ID 倒序，按游标翻页。支持按时间范围、完整事件 ID、操作人、操作类型和客户端类型查询；「更多筛选」提供对象或记录 ID 搜索、操作结果、对象类型、客户和项目。默认近 7 天，自定义日期按北京时间查询。「刷新」保留已应用筛选并回到第一页。
- 列表中的操作人名称和账号 ID 各占一行，超出列宽时省略。悬停或打开审计详情可查看完整内容。
- 点击事件 ID 打开审计详情。详情保留列表中的身份与来源字段，补充原始操作 Code、操作 ID、阶段和关联验证标识。「请求证据」展示操作 ID、命令和已采集的安全参数，历史记录仅展示留存的内容。「响应证据」展示操作 ID、记录的 HTTP 状态、操作结果及可用的工作区修订号。「变更证据」展示前后值、目标、关联对象和逐项结果。「原始详情」展示接口返回的脱敏审计 JSON。各 JSON 页签支持展开、收起、复制和全屏。
- 新事件在同一业务事务的审计行保存字段摘要、安全参数和可识别的 Web 来源。租户和项目按已记录的归属展示。客户端未知时显示「未记录」，IP 地址、租户和项目缺失时显示占位。密钥明文、掩码、指纹、完整配置、内部配置地址以及完整请求和响应体排除在返回字段外。配置提交属于原型证据，网关实际生效须由独立执行回执确认。

## 流量运营

- 限流配置页使用 Semi Design 卡片、页签、表格、表单、弹窗、抽屉和反馈组件。运营区「流量运营」下提供「用户限流」「模型限流」两个页签，默认进入用户限流。平台管理员和运营人员可访问。
- 用户列表显示账号名称、用户 ID、所属租户、默认值、生效值、规则来源、一客一策条数和操作。默认值取用户全局默认，生效值取账号通用额度。两个值均包含 RPM 和 TPM。每个用户只显示一行，列出所属租户的名称和类型。支持按账号名称、用户 ID 或租户名称搜索，按所属租户类型筛选。通用额度可单独或批量修改、恢复全局默认，已有一客一策仍按模型匹配。筛选、切换页签和批量操作成功时清空选择。
- 全局默认在 D1 初始化为 60 请求/分钟和 300 万 Tokens/分钟，放在用户列表搜索行，Tooltip 说明继承规则。新账号和没有自定义通用额度的账号使用当前值。
- 点击账号行的一客一策条数打开右侧宽抽屉，显示账号名称和 ID，支持搜索并添加模型、修改额度和移除，统一保存。一个账号的同一模型只能配置一条额度。账号规则优先级依次为一客一策、账号自定义、全局默认。
- 账号行的「限流可视化」打开只读宽抽屉，展示通用额度以及各模型的账号侧额度、命中规则、模型共享上限和最终上限。RPM 和 TPM 分别取两侧较小的值，账号侧额度无法读取时最终上限显示「—」。
- RPM 使用请求/分钟。TPM 固定以百万 Tokens/分钟展示和输入，最多 6 位小数。组合额度在数值旁直接标注 RPM 和百万 TPM。保存时 RPM、TPM 均为正整数。
- 模型限流搜索行沿用用户限流布局，右侧维护「模型默认」，D1 初始值为 600 请求/分钟和 3,000 万 Tokens/分钟。列表展示 D1 模型资料主档的名称、标识、默认值、生效值和规则来源。模型共享上限按主档关联，由调用该模型的账号共用。单模型可覆盖默认或恢复为继承当前默认。
- 页头「变更历史」打开只读抽屉，按时间倒序展示变更时间（北京时间）、变更对象、操作、变更前、变更后和操作人。D1 记录两类默认、账号通用额度、一客一策及单模型覆盖。批量操作按实际改动的账号列出，一客一策按模型列出增改删，恢复默认显示继承关系。旧审计缺失的字段显示「未记录」。
- 两个页签使用同一个后台登录会话读写 D1 限流配置。用户列表复用稳定的登录账号 ID，模型关联复用 D1 资料主档 ID。读取失败提示登录或重试，缺失额度显示「—」。保存同时提交配置与审计，校验角色、修订号与幂等标识，失败保留输入。浏览器旧存档保留，当前生效配置以 D1 为准。当前原型范围为配置及规则解析。

## 套餐制作

- 套餐制作和套餐数据复用后台 Semi 页头、卡片、筛选和小尺寸表格。套餐制作包含「套餐列表」和「模型抵扣系数」两个页签，默认进入套餐列表。套餐在独立表单编辑，右侧为购买页预览。抵扣规则按模型分组，在弹窗编辑。离开未保存的表单时可继续编辑或放弃本次修改。
- 运营区「套餐运营」下提供「套餐制作」，平台管理员和运营人员可访问。列表以名称或套餐编号搜索，按套餐形式和状态筛选，统一分页。套餐形式为按周期订阅或一次性资源包，首次保存后只读。套餐类型可选个人版、团队版或平台管理员添加的共享类型。新建、编辑和查看为独立表单，返回保留筛选和页码，离开时保护未保存输入。
- 订阅套餐配置每周期 Token 额度、周期售价、订阅周期、总周期数和余量结转规则。资源包配置每份 Token 总额度、单价和生效后的有效天数。两类共用套餐名称、购买页展示名称、简介、顺序及每位用户累计限购份数。支持订购的用户类型可多选政企用户、个人用户，新建默认全选，发布和上架至少选一项。展示顺序可填 0 至 200 的整数，数值越小越靠前，留空排在最后。购买页预览在大号套餐名称下方显示一行简介，并展示有效期限。
- 按月、季度、年订阅分别按原生效日期加 1、3、12 个日历月推算周期边界，目标月缺少对应日期时取月末，后续仍以原生效日推算。当前套餐制作展示规则，实际订购到期时间由权益系统计算。
- 状态为草稿、待上架、已上架、已下架。新增和编辑表单的「保存」将套餐存为草稿，允许缺少发布必填项。发布从列表发起，校验通过后进入待上架，操作为编辑和上架。仅从未发布的草稿可在列表确认删除，移除后保留审计且编号不复用。上架与下架需确认。已上架套餐只读，修改下架或待上架套餐后需重新发布。下架只停止新订购，已购权益用尽或到期后结束。
- 平台管理员可删除未被套餐引用的自定义类型，删除需确认。内置类型和被任意状态套餐引用的类型不可删除，删除成功后从选项中移除并保留审计。
- 「模型抵扣系数」列表展示已添加的模型，新增选项来自「模型服务」中尚未添加的未归档模型。每个模型默认不允许加入套餐。平台管理员和运营人员可配置「允许加入套餐」、全平台共用的抵扣规则和修改说明。添加及编辑只保存草稿，发布后切换生效版本，待发布期间继续使用当前生效规则。修改历史记录发布版本、时间、操作人、变更前后规则和修改说明。
- 先选择模型，再按该模型当前生效售价中的计费项分别配置抵扣规则。没有生效计费项时提示先配置并发布模型售价。留空的计费项不生成规则，新增模型至少配置一条。切换模型时保护未保存输入。保存和发布均校验计费项归属，已有生效规则保留至新版本发布。规则使用模型主档 ID。同一计费项可不分档，或配置互不重叠的输入 Token 档位。下限不含、上限含，允许留空一端。下限留空从 0 开始，上限留空代表无上限。按单次请求的输入 Token 数判档，整笔使用命中系数。各计费项的实际用量乘以对应系数，再相加得到套餐扣减额度。系数须大于 0、最多两位小数。
- 套餐制作的「支持模型」支持搜索和多选已发布、允许加入套餐且有生效规则的模型。选中后展示当前计费项、档位和系数，套餐只保存模型关联。暂无可选模型时提供模型抵扣系数页签入口。发布和上架至少选一个符合条件的模型。模型仍被套餐引用时，发布规则须保留允许状态和至少一条规则，服务不可归档。被草稿或生效规则引用的计费项不可删除。原模型级系数作为历史值保留。
- 使用说明和使用范围是独立的可选文本，各最多 500 字符。套餐配置、共享类型、操作回执及审计通过 5.12.0 的 D1 接口保存。原浏览器套餐记录保留在原存档。

## 套餐数据

- 「商业运营 → 套餐管理 → 套餐数据」读取同一版本的 D1 套餐和订单。汇总按套餐、类型及北京时间范围筛选。新增销售数统计期间下单的份数，累计到期数统计截至结束日的到期权益。结束日为当天时，额度消耗率对有有效额度及累计用量的权益逐份计算并取算术平均；历史结束日和缺少事实时显示「—」。
- 点击套餐名称进入单款统计，沿用概览时间范围。权益表每份已购权益一行，展示订购日期、套餐及权益 ID、用户 ID、账号名、账号类型、套餐档位和额度、有效期、状态、已消耗 Tokens、剩余额度及成本。截至结束日已下单且有效期与窗口重叠的权益进入明细。历史消耗和剩余额度缺少当日快照时显示「—」，成本缺失显示「待核算」。返回汇总保留筛选和列表位置。

## 模型身份与资料

- 「基础资料」下的「模型作者」与「模型系列」均和「模型」同级。模型作者维护标准名称和别名，列表展示关联模型数，操作列提供编辑。已有作者均可用于模型筛选、系列归属和模型导入。模型系列维护系列名称、所属作者及别名，所有已登记系列均可用于新建和导入。存量文本按作者与系列的现有取值初始化，同名或已登记别名精确归类，无法匹配的原值保留为待核对。改名沿用原引用。字典变更沿用模型运营工作区的角色、修订和审计。
- 模型资料表格在作者后展示模型系列、模型版本，支持按作者和系列筛选。「批量导入模型资料」在「模型」页签的筛选区右侧。资料表单选择作者后再选其系列，系列可留空。从资料表单可在新页签打开作者或系列维护，载入最新数据后保留当前表单输入。批量导入沿用模型编码及原表头，预览展示已匹配的标准分类，未匹配或系列归属错误按行标明。服务商接入选择现有模型资料时可核对模型编码和版本，连接分别记录各自的上游模型调用标识。用户侧模型广场按同一分类筛选已可见模型。

- 术语由 [GLOSSARY](GLOSSARY.md)定义：模型资料、供应关系和销售服务各有职责，模型档案 ID、模型编码、上游模型调用标识和模型 ID 不混用，模型作者不等于服务商；采购参考价、采购价和平台售价分开。完整 URL 称请求地址，Key 按当前绑定连接表达。
- 后台模型广场的卡片和列表操作提供「编辑信息」「关联模型服务」「设置可见性」「删除」。已关联数量也可打开关联抽屉。「已关联模型服务」支持逐条移除，「添加模型服务」支持搜索和勾选同一模型档案下的多个服务，点击「保存关联」一次提交。正在展示的服务需先在「设置可见性」中取消展示。关联使用稳定的模型服务 ID，展示服务按其可用的广场配置选择。
- 删除只允许「不可见」卡片，确认后移除卡片信息及其服务关联并记录审计。保留关联服务、基础资料、售价和订单。删除的卡片刷新后也不再显示，仍可新建卡片并重新关联对应服务。
- 模型广场页头的「模拟数据」进入独立演示模式，提供卡片、可多选的模型服务和租户样例。操作仅在当前页面会话生效，退出恢复真实视图和筛选。
- 新建与编辑卡片均可手填或从「基础资料 → 模型」选取资料。图标选填，支持上传 1 MB 以内的 PNG、JPEG 或 WebP，可预览、更换和移除。导入后可修改带入字段，保存时保留原卡片身份和服务关联。上下文长度使用 K 或 M 输入，切换单位保持实际 Token 数。
- 卡片可见性为「不可见」「预告可见」「灰度可见」「全部可见」，新建默认为不可见。灰度可见支持按租户名称或 ID 搜索并多选。调整卡片可见性只改变广场展示。关联服务的售卖状态由模型销售维护，停售只暂停新订购，已有订单与调用权限继续有效。
- 模型资料提供参考内容，最终展示信息由模型广场维护。按稳定 ID、显式关联或精确编码识别模型，不按名称近似合并版本。四模块的永久 ID 展示、字段归属及批量导入导出遵守[身份与导入契约](MODEL_OPERATIONS_IDENTITIES.md)，复用存量 ID，不改写已有引用。
- 模型类型及任务范围见[模型服务与调用路由](#模型服务与调用路由)。输入／输出模态与向量、相关性等结果类型分开，未知能力和规格保留空值。
- 资料库保留表格、查看、编辑及删除入口；长内容提供完整值的可访问查看方式，宽度不足时在表格区域滚动。资料列表名称/编码、作者、正式发布日期、类型、适用场景、模态及上下文各有语义；日期来自可核对官方首次发布记录，场景不替换为支持任务。维护分页 20/50/100、默认 20，选择流程保留自己的容量；切换容量只提交一次容量和第一页。
- 广场公共展示内容按模型管理。基础资料可用于带入字段，已保存的卡片内容由广场维护。客户请求使用模型服务的「模型 ID」，销售价格和销售对象在「模型销售」维护。
- 前台卡片和详情读取同一份已生效资料：Logo 缺失或存储内容不合法时使用默认图标，图片加载失败时名称仍可读；详情复用卡片公共信息，并显示已填写的长介绍、模型编码、版本/发布日期、能力规格、技术接口属性及资料链接。未知属性不补零或“支持”，正式发布日期与卡片的资料更新时间分开；不把采购价、供应密钥、内部请求地址和资料核对记录投影给客户。点击卡片进入独立详情页，按面包屑、模型介绍与三项参数、服务商报价、API 调用、详细资料组织；返回广场保留当前筛选并恢复原卡片焦点。URL 保留稳定模型与服务 ID，支持刷新和浏览器前进/后退；失效或无权访问时显示不可用，不自动替换为其他服务。
- 详情按当前客户可见的模型服务展示报价。选择服务后，调用名、价格、订购操作和调用入口同步切换。
- 前台模型广场按稳定模型 ID 聚合 D1 的有效上架服务，一款模型一张卡片。按发布日期排序，服务商筛选按服务商 ID 去重并匹配卡片内各服务。客户按服务的永久 ID 订购并使用该服务的调用名。当前路由缺少有效采购价或售价时，对应服务暂不出现在广场，D1 拒绝新订购并保留上架配置及历史。售价仅取平台已发布销售快照，明确币种/计量单位，未提交输入、采购价和内部连接不对客展示。每条调用记录保留当时的连接、路由和售价引用。
- 基础资料、模型服务和广场各自保存对应字段。参考资料修改保留引用身份，不覆盖已保存的服务或卡片字段。删除资料前检查活动引用。
- 模型运营初始数据见[全站 Mock 数据](MOCK_DATA.md)。服务商、资料、连接和服务使用明确的稳定关联。初始化沿用已保存记录、删除标记、凭证、草稿及历史。
- 删除主档须没有供应、服务或活动配置引用，界面禁用与事务校验一致。添加供应模型从主档选择，可原地新增主档并返回选中，不自动登记供应关系或连接。批量只接受匹配主档的模型，不接受任意未匹配上游 ID，不生成空连接。
- 对外使用按当前服务、发布与订购条件校验。资料登记及导入遵守对应表单与模板规则，未知事实保持未填写。

## 模型接入

- 新增和编辑连接时按服务商文档填写服务地址，保留路径及版本前缀。表单实时显示完整请求地址，忽略服务地址末尾斜杠，再追加接口端点。服务地址已包含所选端点时禁止保存。OpenAI Chat 默认端点为 `/chat/completions`，Anthropic Messages 为 `/v1/messages`。标准模型列表在同一服务地址下请求 `/models`。

「模型运营 → 模型接入」包含「连接列表」（`providers-reference`）及「连接健康」（`providers-health`）。总表按连接名称搜索，逐条连接展示「连接名称/ID」「服务商」「连接类型」「状态」「服务地址（Base URL）」「操作」，支持分页。名称和 ID 都可进入连接详情。类型按当前配置显示 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、OpenAI Embeddings、火山方舟 Video Generation、DashScope Video Generation 或 MiniMax Video Generation，其他已有接口保留其类型。列表状态为「已启用」或「已停用」。行操作为「测试连接」、当前状态对应的「停用」或「启用」，以及「删除」。测试连接须先接入模型。 在测试连接弹窗中选择「模型调用测试」后，按所选模型的默认任务执行。连接详情的「基本信息」显示类型、连接名称、API 地址、API 密钥数量、状态、简介及创建人／创建时间，并提供「编辑信息」。「模型列表」按模型标识和展示名称搜索，提供批量测试、获取模型列表后勾选接入、添加上游模型，以及单模型编辑、测试和删除。「添加上游模型」在当前连接打开宽抽屉，顶部单列目标连接、已绑定服务商、接口格式和 Base URL。默认显示「当前服务商模型」，可切换到「全部模型」。「当前服务商模型」读取「基础资料 → 服务商 → 模型列表」的已登记模型及其协议地址和上游标识；「全部模型」读取「基础资料 → 模型」。未登记的官方参考只在「全部模型」使用。「维护模型」按当前页签在新页签打开对应资料列表，当前抽屉保留筛选和勾选。可按名称、编码或上游模型调用标识搜索，也可按来源接口格式和 Base URL 筛选。默认筛选当前连接的接口格式和地址，保留无来源记录的候选供补填。仅在当前服务商、接口及地址唯一匹配时带入上游标识。已添加和不兼容行不可勾选。翻页和筛选保留勾选，每批最多 50 款。确认采购范围后原子添加本批可提交项，缺标识或存在冲突的所选行留在抽屉补填，失败保留当前输入。全部提交后返回当前模型列表，新模型进入待验证状态。保留手动录入和粘贴入口。「获取模型列表」抽屉先说明上游接口要求与手动添加方式，并展示模型列表协议、服务地址（Base URL）和可复制的完整请求地址。上游模型列表提供搜索、多选和全选，表中展示上游模型调用标识。列表右上角提供「模拟数据」和获取按钮，首次显示「获取模型列表」，已有结果时显示「更新模型列表」。模拟预览独立于连接数据，退出后恢复原列表、搜索和勾选。底部提供关闭和配置所选模型，模型资料及采购范围在配置时核对。添加连接的首项为「连接类型」，可选第三方模型服务或自有模型推理服务。「上游接口」依次展示服务商、接口格式、接口端点与服务地址。服务商列表在基础资料中维护。接口格式选项附带端点，列表按同一格式名称和实际路径分列展示。「连接信息」依次填写连接名称、服务商 API 密钥和简介。服务商和接口格式选定后，连接名称默认按「服务商 - 接口格式」生成。手动改名后保留用户输入。每行一把密钥，提交只创建一条连接。保存时自动生成连接 ID，新连接显示「已停用」。简介与连接配置一同保存。「编辑信息」维护连接名称、连接类型、接口格式、接口端点、服务地址和简介。基本信息的「API 密钥」显示当前连接已绑定的数量，点击在当前详情切换到「服务商 API 密钥池」页签。待验证的密钥配置从「服务商 API 密钥池」继续处理。返回总表保留搜索、分页和滚动位置，测试、凭证、采购范围及删除校验沿用现有规则。

「模型接入」的「新建连接」弹窗最大宽度为 720 px，窄屏按视口收窄。单条创建成功后可在当前页签查看新连接。批量创建完成后可逐条在新页签打开连接。进入所选模型配置后返回，恢复原连接和已选模型。「添加 API 密钥」复用该弹窗布局，只填写当前服务商的 API 密钥。每行一把，可粘贴多行并一次保存。

「模型接入」详情的「服务商 API 密钥池」按当前连接所属服务商读取密钥。工具栏提供「添加 API 密钥」，操作列依次为「测试连接」「替换」「删除」。选择「当前绑定连接」可打开对应连接。密钥保存后仅展示脱敏值。「替换」打开所选密钥的表单，已有连接密钥池绑定时在对应连接验证并应用候选。「删除」沿用引用检查和影响确认。连接已有候选可从「基本信息 → 编辑信息 → 核对待验证配置」继续。

- 连接详情的「基本信息」维护共享连接，「模型列表」维护上游模型关联并提供测试，「模型成本」维护采购价，「服务商 API 密钥池」维护接入凭证。容量从模型列表的行操作进入。连接名称、连接 ID 和上游模型 ID 各自定位对应对象。
- 创建连接与添加上游模型分开保存。新增连接保持停用；添加上游模型可使用服务商候选、基础资料、上游发现或手工录入。保存后进入待验证状态，测试通过后由有权限的人员按实际范围启用。
- 连接的地址、接口或凭证变更使用候选验证并明确应用。查看影响时按实际共享引用计算，保留未涉及的连接、价格及历史；失败后继续使用原有效配置。
- 删除连接、上游模型及服务商前核对实际依赖，按弹窗处置关联及确认。稳定引用、主档、审计和历史价格按现有事务保留。
- 请求地址使用完整 HTTP/HTTPS URL，保留当前第三方 HTTPS/自有 HTTP(S)、禁止嵌入凭证及不允许的查询/片段校验；不将裸域名或基础 `/v1` 冒充模型接口，不重复拼接路径。已配置的多协议地址保持独立测试结果，次协议通过不能替代主地址健康。
- 相同接口、凭证与上游 ID 不能靠不同名称/来源标签重复创建。旧无 ID 关联稳定读取，不回填/丢弃记录；编辑某连接不能误删其他连接。调用配置变化使相关验证失效，单纯名称/成本变更不误清验证；共享影响须确认。
- 停用、删除或解除先检查服务及已发布路由引用，提示真实影响；全局停用与当前路由摘除分开。保存连接不自动改服务映射、售价、路由或上架。旧报价、密钥、价格历史和审计保留。
- 默认样例与官方参考资料不证明真实供应关系、可用性或价格。已有记录不为凑数量重置；显式加载参考目录只补缺失记录，保留自定义资料与已关联模型。一次性案例删除/修改后不自动复活，历史本地授权不能再次用于改写用户浏览器。

### 基础资料与供应登记

- 「基础资料 → 服务商」管理主体。服务商详情在「模型列表」登记现有主档、批量导入并登记及维护供应配置，在「基础资料」编辑主体。仅登记供给不创建连接或启用模型，旧存档保留各自的配置与历史。
- 模型资料的名称与编辑入口共用同一个详情抽屉，查看态默认显示模型资料，可切换「供应服务商」反查服务商及连接数并登记供给，宽度最多 1200px，并适配窄屏。以入口中心位置判断方向：左半屏入口从右侧展开，右半屏入口从左侧展开；切换查看/编辑保留抽屉方向。两态的字段、分组、顺序及单元格位置一致，查看用文本，编辑用控件；视觉任务类型、资料来源两态均展示，模型编码保持只读，内部资料 ID 不占业务界面。查看态右上角为编辑，编辑态底部固定取消和保存；取消未保存修改需确认，保存沿用资料影响核对，成功后回到当前资料查看态。表格筛选及滚动保留，关闭后焦点回入口。
- 从模型详情的「供应服务商」可进入对应服务商资料。服务商资料列表使用 Semi 原生筛选、列表和分页，列出名称、编码、Logo、供给类型、已登记模型数及操作。点击名称或模型数进入独立详情页，默认显示「模型列表」，第二个页签为「基础资料」。基础资料统一在模型资料新增和编辑，维护主体字段、Logo、简介、官网、文档链接、联系人、联系方式和备注。
- 服务商详情列出供应模型名称、规范标识、类型和连接数。模型详情反向列出服务商名称、编码、Logo、供给类型和当前模型的连接数。两侧按稳定主档 ID 读取同一供给登记，已登记但无连接时显示 0，查看连接携带当前服务商及模型。资料页发起登记时复用模型接入的供应登记命令。
- 批量导入支持单独建模型或服务商主档、带入当前服务商批量导入并登记、用服务商编码和模型编码导入供给关系。逐行预览有效、已有、重复和问题记录，确认跳过问题后分批提交，结果支持下载问题行和单独重试提交失败的行。主档先保存，关系随后登记；关联失败保留主档。重试核对当前资料及关系，已有记录不覆盖。
- 模型资料查看和编辑按基本信息、模态与任务、能力与限制、调用参数、技术与来源组织；名称、模型编码、模型类型必填，未知能力保持缺失，不能补成不支持或零。支持参数与默认参数分别保存；默认参数须为 JSON 对象且仅包含已声明支持的参数。原厂发布日期与平台收录时间分开，月精度日期保留。服务模型卡片继续仅展示八个字段。前端使用中文标签及说明，数据库模型文档使用 `name`、`canonical_slug`、`description`、`context_length`、`architecture`、`supported_parameters`、`default_parameters`、`supported_voices`、`knowledge_cutoff`、`expiration_date`、`hugging_face_id` 等英文属性。模型调用标识、模型编码、上游模型调用标识、内部记录 ID 各司其职，不按名称猜测关联。
- 批量导入模型资料只提供表格上传，支持 XLSX、UTF-8 CSV，单文件最多 10 MB、每批最多 500 条；不提供粘贴入口。下载模板为 XLSX，前三列必填项使用红色表头并注明“必填”，第四列视觉任务类型使用橙色表头并注明“视觉模型必填”，其余为选填；冻结首行和前三列，附“填写说明”工作表，表头文字标记可直接导入。模板与资料表单共用字段描述，覆盖基本信息、模态与任务、调用能力、支持参数、技术与来源及各类型专属规格。必填名称、模型编码、模型类型；视觉类型另填图像或视频，其他未知资料留空。可删去可选列或调整顺序，重复/未知表头拒绝；空行不改变原文件行号。填写提示常驻展开，使用清晰分行和 14px 正文。读取后进入校验预览，支持逐行查看全部已填字段、下载完整校验清单、筛选与明确跳过问题行、重新上传。校验与资料保存复用类型、日期、数值、默认参数依赖及重复身份规则；不适用字段拒绝而非丢弃。常规模型导入仅创建模型资料，不覆盖已有标识。服务商下钻页的「批量导入并登记」使用同一模板和当前服务商，按模型编码复用一致的主档，资料冲突标为待修正，分步保存主档和供给。
- 模型资料列表首列表头为「模型资料名称」，按名称搜索与打开详情。Logo 列标题为「模型 Logo」，以 28px 等比展示档案的图标，不再展示资料状态。未填写或图片加载失败显示“—”，不补造图标；底层资料状态和其他资料保留。其余字段、排序、分页和编辑/删除保护保持。
- 内置目录由 src/data/builtin-model-catalogue.json 定义本次指定的 17 个国产模型。新工作区初始化；已有 D1 通过明确的管理员命令增量安装，每批最多 5 个。仅新增缺失主档，或更新与旧初始配置业务字段完全一致的默认名称、类型和日期；忽略初始化时间差异，任何其他修改和草稿均保留。明确 existingId 或唯一完整编码匹配，不按相似名称合并。安装记录与用户修改分开，重复安装不恢复已删除记录；已有库通过管理员显式清理命令原子保存目录归档 ID，不替换模型、服务商、连接、密钥或价格集合；不补造能力、采购价、凭证或上游标识。
- 供应模型详情维护服务商声明的参数、默认值、范围、必填及组合限制，能力明确支持、不支持或未确认；声明不替代统一主档或连接验证。复制创建须选择目标服务商与主档，只复制声明，不复制连接、密钥、测试、服务或路由；不能覆盖已有供应关系，重新登记保留该关系原有历史。
- 刊例价独立属于服务商×模型×连接，维护计费项、适用条件、单位、币种、生效/到期时间及不可变发布版本。零价与缺价分开，已发布版本保留；新版本到期不恢复被替代旧价。刊例价发布不修改连接采购价、客户售价和历史成本，也不修改其他连接刊例价。旧模型级刊例价历史保留查阅，不自动复制到连接。

## 密钥与维护

- 密钥库与租户 API Key 独立。只保存掩码、SHA-256 去重指纹及引用元数据，明文不进入草稿、存储、审计、日志或产物；不宣称已接服务端凭证库。
- 产品继续使用 API 密钥，不改名 API 凭证。服务商密钥页维护密钥资产和分组；连接的密钥池维护多条绑定、启用状态和 1–100 优先级，数值小者优先，同级按列表顺序。旧专属、默认及共享组引用不自动转换；移除“设为主要”入口，已有组顺序保留。
- 连接列表和上游模型展示健康状态；健康与启用分开。在连接列表停用连接时，核对受影响的模型服务后即可确认。进行中的检测可继续回写结果，手动停用状态保持。重新启用时校验检测任务和当前配置的有效结果。逐上游模型、逐密钥检测，结果展示时间、HTTP 状态、耗时和失败原因，支持确认、取消和重试。结果有效期为 24 小时；地址、模型映射、密钥版本变化要求复测；单 Key 通过不代表整个密钥池正常。检测只写诊断历史，不修改启用、映射、路由或价格；本地结果标识“模拟检测”。
- 密钥池变更走候选配置→逐条测试全部启用密钥→明确应用，校验全部必要模型及服务影响；单 Key 通过不能替代其他 Key，失败、过期、待完成及不匹配回执均不放行。未关联模型须先接入模型再验证。本批不新增自动轮询、额度调度或熔断冷却。
- 密钥按实际连接引用聚合，长 ID 可换行；没有密钥不伪造占位记录，不把未关联旧连接作为整个模型目录的错误。添加/替换不回显原文，沿用可见 ASCII、长度、重复和数量校验，保存只提交脱敏信息。
- 上游 API 密钥通过替换或删除停止使用。替换、删除按实际引用范围确认影响并处理验证失效，正常轮换保留旧密钥资产。连接密钥池的「全部停用」只作用于当前连接。历史撤销标记及审计保留，已撤销的密钥不可选用或通过回滚恢复。详见[现行接入与维护规格](MODEL_ONBOARDING_SPEC.md#当前接入与维护)。
- 连接配置只选择服务商密钥组并显示可用数量、主要密钥脱敏值及状态。「管理密钥池」进入服务商 API 密钥池并定位所选组，离开前沿用未保存保护，已有连接可返回配置。连接专属密钥随连接提交。连接配置与测试不再内联添加共享密钥。测试切换密钥组仅作用本次检查，明确修改连接配置才持久化；测试结果单一呈现，接口不匹配优先于旧通过记录。测试/调用明确提示用量确认，保留取消、重试和失败恢复。
- 地址和 Key 维护先保存候选并测试，通过后仍需明确应用；失败保留当前配置。历史恢复入口共用固定范围和有效性校验，不保留绕过检查的旧结果直达路径；不因测试成功自动启用、改路由或上架。
- 成功、超时等模拟场景选择只在地址参数 `devtools=1` 的研发视图显示，普通业务页面隐藏；测试结果保留实际来源，不将本地 Mock 记为真实上游证据。

## 模型服务与调用路由

- 「模型运营 → 模型链路」位于「模型服务」之后。页面展示协议、网关、模型服务、路由策略、协议转换、连接、上游模型。连接展示接口格式、请求端点和启停状态。上游模型展示上游标识、优先级、权重和启停状态。权重仅在加权随机时生效。模拟请求回放依次展示候选校验、优先级选组、组内选路、协议转发和响应。视频生成回放以任务受理结束。画布使用只读模拟配置，浅色点阵背景，七列默认完整展示所有分支；请求结果和图例置于画布下方。

- 「模型运营」侧栏显示「模型服务」。旧模型服务、旧模型接入和旧连接别名已退出导航，原地址回到当前工作区概览。
- 当前模型服务列表按顺序展示模型服务名称/ID、模型 ID、接口端点、模型类型、服务状态、创建人/时间、备注、操作。名称、模型服务 ID、模型 ID 和已配置的接口端点分别可复制。点击服务名称进入详情。
- 悬停或聚焦列表的「模型 ID」表头文字时，在上方显示定义，说明该值填写在调用 MoMA API 的 `model` 字段中。
- 模型服务详情的「基本信息」展示模型服务名称、模型服务 ID、模型 ID、服务地址、接口端点、模型编码、服务状态、标签、备注、服务描述、创建人和创建时间。此处的服务地址是 MoMA 网关的基础地址，接口端点是 MoMA 对外接口的请求路径。「编辑信息」提供模型服务名称、模型 ID、备注和服务描述。未关联模型资料时，还可通过「模型编码」选择基础资料并带入。
- 模型类型统一使用语言模型、多模态理解、视觉模型、语音模型、向量模型、重排序模型、其他专用模型。基础资料的新建、编辑和筛选，以及模型广场筛选均提供七类。类型说明分别展示以下任务范围。
  - 语言模型：普通对话、文本生成、推理、代码生成。
  - 多模态理解：图片理解、视频理解、文档理解、视觉问答。
  - 视觉模型：文生图、图生图、图像编辑、文生视频、图生视频、视频编辑。
  - 语音模型：语音识别、语音合成、语音对话、语音转语音、音乐生成、音频理解。
  - 向量模型：文本向量化、图像向量化、多模态向量化。
  - 重排序模型：文本相关性重排、多模态重排。
  - 其他专用模型：文本分类、内容审核、翻译、3D生成。
- 服务状态为「已启用」或「已停止」。启用要求有效的已登记连接。停止前检查广场关联及上架状态，已上架的关联模型需先下架。停止后，在模型广场、项目授权和原型调用中按服务标识排除对应调用入口。列表的「编辑」只修改模型服务名称。
- 「删除」仅在已停止时可点击。点击后检查广场关联、上架状态和租户授权，解除广场关联并移除现有租户授权后方可确认。已删除服务保留审计和原有调用历史。
- 「关联上游模型」顶部只读展示继承的全局路由策略。平台管理员在「平台管理 → 路由设置（全局） → 全局路由策略」选择加权随机、最少并发、低延迟优先或按用量分流。默认加权随机，切回后沿用已保存的组内权重。已保存的成本优先策略继续显示为当前值，直到管理员切换并保存。「故障转移策略」页签独立配置继承或自定义的故障转移参数。
- 「关联上游模型」按优先级从小到大分组。组头显示成员数和权重合计，通过「配置优先级与权重」整组调整，权重不满足条件时显示差额并禁用保存。正常连接行提供启停与移除，上游配置变化时提供「核对连接配置」。新增组只设置优先级，空组保存后可重新载入。组内添加使用宽弹窗，接口格式下拉框完整列出模型接入支持的格式，并补充实际连接使用的其他格式。先选择一个或多个格式，再从匹配任一所选格式的连接中选择，最后批量勾选所选连接下的上游模型。移除格式时只清除该格式对应的连接及勾选项，整批保存并按比例分配组内权重。组内配置权重为正整数且合计 100，增删成员按比例重分配。非加权随机策略禁用权重编辑，仍可调整组优先级。
- 已开启上下文长度路由的存量配置继续参与连接检查，保留已保存的 Tokenizer 和连接上下文长度。
- 「模型服务 → 新建模型服务」提供模型服务名称、模型 ID、模型类型、备注和服务描述。名称和模型 ID 必填，描述最多 300 字。创建后进入「关联上游模型」，默认提供优先级 0。先选接口格式、再选连接，最后勾选该连接下已登记的上游模型。模型资料仅用于参考，选填模型编码不会限制关联范围。
- 模型服务、服务状态、路由策略和连接配置保存在 5.12.0 共享工作区。模型资料和已登记连接用于只读引用。没有通过检查的登记连接时，添加弹窗提供三条标明「模拟连接」的同模型选项，用于演练优先级、权重及启停。场景数据由用户选择后随服务保存，已有模拟关联可继续维护。已有配置随记录保留，真实服务地址及调度需网关集成。

已保存的路由、映射、价格、销售范围及审计继续保留。旧模型服务与旧模型接入页面已下线。

## 接入模型与模型运营指南

- 「入门指导 → 模型运营」提供[关键概念和字段](MODEL_OPERATIONS_GUIDE_FIELDS.md#关键概念和字段)。接入、模型服务、广场和销售操作以各模块规格为准。
- 模型接入从连接详情的「模型列表」开始。模型服务可先保存基本信息，随后按接口格式筛选连接并关联已登记的上游模型，再按校验启用。展示由模型广场维护，售卖由模型销售维护。
- 模型资料默认按原厂发布日期从新到旧排列，同日期保持原顺序；缺失日期置末，仅到月份的原值不补造具体日期。不更改持久化记录顺序。
- 售价编辑从共用计费项字典和已启用的货币、计费单位字典选择，保留原价格快照及旧手工计量。单位或货币停用后不再新增选用；已被价格、历史或草稿引用的名称、计量单位与货币代码不能修改或删除，货币展示名称及说明可维护。

- 模型服务启用时校验当前服务与连接关联。广场展示、开售、订购和使用分别按现行页面及接口校验；连接或能力变化时复核受影响的技术配置。
- 模型服务列表呈现当前模型 ID、API 路径、协议及完整端点，不提供后台调用指南页签；操作记录沿用同源审计。模型订购、项目 API Key 和在线体验按当前空间及项目校验。项目调用记录用于项目用量、日志和概览。

## 保存、发布与恢复

- 后台不提供草稿保存、恢复或丢弃入口。编辑输入仅在当前页面保留；测试验证连接配置，不自动启用或上架。预览展示本任务差异、范围和阻塞项；明确发布或应用后才切换对应有效版本。
- 售价发布成功后立即作用于后续新请求，含已有订购客户；已开始请求及历史保留原价格快照，内部重试不换新售价。客户展示、后台及客户调用使用同一有效版本，不提供预约调价和专属协议价。
- 地址、密钥、路由、资料、售价和客户范围按相关任务独立提交；任何发布不得顺带应用其他任务输入。保存或发布失败保留当前输入和旧有效配置。
- 离开未提交页面只提供放弃本次修改／继续编辑；刷新不恢复未提交输入。历史未发布记录原样保留，不自动应用或作为新编辑的起点；报价历史可沿用后明确提交新版本。
- 超时或结果未知先核对同一操作结果再重试；冲突显示差异并保留输入，不自动覆盖。刷新恢复已保存安全内容并重查依赖，不承诺恢复未保存输入或明文 Key。
- 操作成功后持续显示真实对象、版本和生效时间，不只使用短暂通知。不可执行时说明具体缺项或权限原因，原型不伪造成功。

- 历史目录报价及其手动采购值保留于领域记录和历史，不恢复被移除的目录折扣/平台成本 UI。金额使用既有整数百万分位与六位小数精度；采购/销售价格各自版本化，币种分别汇总，不自动汇率换算，缺价不当零。具体历史报价及核验数量归发布/来源记录，不作为永久价格事实。

- 客户请求每行一个 Request ID，模型名称和调用标识、API Key 名称和 ID 分别在同一单元格分行展示。上游请求每行一次实际派发，搜索同时匹配客户及上游 Request ID。点击客户 Request ID 或右侧「详情」可定位此上游尝试。Session ID 使用明确采集值，缺失时显示「未采集」。前置错误以首次派发前的失败证据筛选，按时段和错误类别绘制趋势，点击柱形查看对应的留存样本。
- 项目候选随租户缩小。调用用户按请求记录的用户 ID 筛选，未采集是独立条件。调用用户和 API 密钥按租户内名称或完整 ID 搜索，未选租户时只支持完整 ID，候选最多显示 20 项。切换租户清除范围外的项目、调用用户和密钥条件并提示。
- 请求详情分摘要日志、请求链路和完整日志。客户请求与前置错误默认打开摘要，上游请求打开请求链路并选中对应尝试。摘要支持复制请求 ID、复制及下载摘要 JSON。链路显示项目路由、连接选路及已记录的派发和关键时点。耗时图使用请求内相对时间，起点缺失或区间冲突时省略条形。确认未派发才显示零次，尝试覆盖未知时展示已记录的条数。完整日志仅平台管理员可见，按实际留存证据分段查看和复制。
- 「模拟数据」入口使用同一批独立工作台内存样例。「查看重试与备用模型回退」打开组内重试、跨组切换及备用模型响应链路。「模拟日志设置」仅在模拟模式中向平台管理员开放。正文默认关闭，开启后按选择的项目留存新模拟请求正文。前置错误默认按 25% 采样，留存 30 天、最多 5,000 条，达到上限时保留最新样本。模拟前置错误趋势统计全部已生成事件，样本列表及导出读取已留存记录。设置随模拟会话结束，样例和策略不写入共享数据。
- 三个日志视图各自保存显示列，Request ID 固定在左侧，「详情」固定在右侧。列设置位于表格右上角，保存后生效，取消丢弃草稿，恢复默认回到该视图的默认列。默认按时间从新到旧，可在适用的时间、状态码、时延和 Token 列切换升降序，未采集值排在末尾。每页可选 10、20、50 或 100 条，默认 20 条。导出为 XLSX，包含当前视图全部筛选结果和可配置字段，沿用当前排序及脱敏，正文按权限单独查看。
- 连接健康位于「模型运营 → 模型接入」页签，只读接口沿用该页签的访问权限。连接健康独立于服务监控，默认按上游模型展示近 24 小时。页面直接显示列表，时间、服务商 / 连接、上游模型、状态与健康状态在一组筛选中，客户、项目、调用类型与模型调用标识收进「更多筛选」。重置清空筛选并恢复默认时段与分组。上游模型按实际服务商、连接与上游模型标识归属。列表合并接入清单和实际尝试，保留无流量和已停用的上游模型。
- 上游模型表头按顺序为「上游模型/服务商」「连接」「服务地址（Base URL）」「状态」「健康状态」「可用率」「TTFT (P50)」「吞吐量 (P50)」「缓存命中率」「采购价」。服务地址（Base URL） 读取连接当前配置，有权限的用户查看采购价。状态按配置显示已启用或已停用，无配置事实显示横线。健康状态沿用最近三个 UTC 日期的有效分钟判定。排除上游 4xx、明确限流、取消和未知结果。每分钟至少 10 次有效尝试才纳入，成功率达 80% 为达标。全部达标为健康，存在未达标分钟为异常，有记录但无合格分钟为样本不足，无记录为暂无观测。
- 可用率 Tooltip 使用「最近3天内服务成功响应请求的平均比例。」。以最近 72 小时内成功的上游尝试数除以已知成功或失败的尝试数，折线按三个 24 小时区间计算。TTFT (P50) 与吞吐量 (P50) 分别取所选时段有效首 Token 时延与单次成功尝试输出速率的中位数。缓存命中率按可计量上游尝试的缓存读取 Token 总数除以输入 Token 总数。指标用左侧折线和右侧数值展示。无有效样本留空。上游模型名在列表中以文本展示。有模型接入权限时可点连接，在新页签打开对应连接配置。其他对比分组可按连接、服务商、端点与项目聚合，并保留原有数据下钻。
- 连接健康点击「模拟数据」后，默认按上游模型展示最近 72 小时的示例供给。可对比同一模型的不同连接、启停、模拟采购价及四种健康状态。有有效观测的示例分布在三个时段，暂无观测的示例指标显示横线。退出模拟恢复进入前的筛选，模拟数据仅用于当前浏览器会话。
- 服务监控「模型实时性能」沿用同一筛选，显示 P95 首 Token 时延、输出 Token 速率、超时率及 RPM / TPM。首 Token 指标取上游尝试的有效样本。输出速率以成功样本的输出 Token 总量除以相应生成时间之和。两项同时显示样本数。超时率以有独立时间的实际派发次数为分母。按分钟统计容量峰值，缺失显示未采集或横线。旧尝试缺少独立时间时仍可从父请求详情查看。

## 模型性能

- 「运维 → 运行分析 → 模型性能」与「调用数据」并列，平台管理员和运维人员可访问。内容区采用 MoMA-XA V2.2 的筛选栏、指标卡、页签、图表布局与配色，控件使用 Semi Design，图表复用 ECharts 配置。桌面图表双列，窄屏单列。
- 默认查询最近 60 分钟，按北京时间选择开始和结束分钟。显示粒度随时段自动切换，短于 48 小时按小时，其余按天。可组合筛选模型服务与实际上游模型，同名上游按服务商及连接区分。查询同时更新总览和三个页签，重置重新查询默认时段。
- 计数按实际派发的上游调用及其派发时间。重试与回退逐次统计。区间成功率以已知成功和失败为分母。缓存命中率按有有效缓存记录的输入 Token 加权。耗时、分位数和每 Token 生成间隔取各自有效样本，缺少采集值用「—」。
- 总览展示平均 TPM、RPM、TTFT、TPOT、调用成功率和缓存命中率。页签包括「调用与 Token 汇总」「上下文与 Token 分布」「延迟与耗时」。图表支持放大。调用结果可查看同范围内按调用用户汇总的错误明细。Token 长度分布可按次数或 Token 量展示，并切换输入、输出系列。
- 初次打开且默认时段无调用观测时，显示标记为「模拟数据」的演示视图。演示与工作台调用记录分开统计，退出模拟可查询工作台记录。模拟样本仅保存在当前页面会话。

## Token 生产

- 保留集群纳管、模型部署、制品镜像、生产观测；制品镜像是独立入口，内部模型制品/基础镜像/运行时镜像分类保持，部署不再重复模块切换栏。
- 部署为列表、全页三步编辑与详情；模型权重/挂载路径和运行时镜像分别校验，不能把基础镜像或权重当运行时。目标/就绪副本独立，缺少历史观测显示未知，不编造监控、日志、自动扩缩容或滚动发布。
- 生命周期通过部署事务原子同步集群分配、部署状态和端点；停止/失败只释放一次，重启复用端点。失败/停止可修复重建，待处理任务不能更新；扩缩容不增加配置版本。回滚保留完整旧配置，当前及回滚权重/镜像引用受保护。
- 部署不自动发布销售服务或改供应/价格；仍为本地生命周期模拟。详细规格见[模型部署设计](../../docs/admin-v2/MODEL-DEPLOYMENT-DESIGN-5120.md)，布局与验收沿用[后台通用约束](../../docs/PAGE-SPEC.md#后台视觉实施与验收)。

路由及映射不提供“查看调用示例”，模型服务不提供“调用指南”入口。普通服务在「路由及映射」表内选择合格连接，经核对和确认后建立映射并发布路由。

路由策略、参与连接及权重默认只读。编辑态提供「取消」和「核对配置」，核对态提供「返回修改」和「确认保存并生效」。取消放弃本次草稿。保存经现有权限、并发和策略校验后生效并返回只读，失败保留输入。

模型服务在「上游模型」中维护组优先级和组内权重。组间按优先级选取，组内按服务路由策略选择。

模型服务售价在“模型售价 → 服务售价详情 → 售价配置”展示及编辑，复用同一价格表；完整显示全部计费项，金额、币种和单位清晰对应。展示态提供“编辑售价”，编辑态提供添加、移除、取消和预览变更；取消恢复当前生效售价，未保存修改仍需确认。价格表合并重复服务商和模型调用标识，字段顺序为服务商名称、模型调用标识、计费项、售价、货币、计费单位，查看态不显示空操作列，编辑态提供移除操作。模型调用标识读取当前服务的模型 ID，提示为“调用 API 时，在 model 参数中填写此值”，在售价页只读，仍在模型服务信息区维护。金额与币种分别维护，编辑态展示当前路由的采购成本参照，不自动推算不可比的利润；不展示适用条件输入列；历史在独立变更记录页签展示。保留既有条件数据、历史版本及发布校验。

工作区不显示配置检查提示块；页头保留既有配置状态，接入任务继续入口保留。既有客户范围保留，调用验证从启用或上架检查进入。连接列表不常驻“可用”标签；供给检查结果及原因放入连接详情。连接详情提供明确的打开入口并保留当前对象上下文；保留详情字段、权限及原有操作确认，Esc/关闭后焦点回到对应按钮。连接表展示上游模型调用标识，模型调用标识由对应服务统一展示。Radix 表单代理控件不重复绘制。

模型服务列表提供实际模型 ID、API 路径、协议与完整端点的核对和复制，不再提供后台调用示例编辑页签。

点击「模型服务」先进入列表。以一个模型服务永久 ID 为一行，同一模型不同服务独立显示，不再合并名称或操作。列顺序：模型服务名称 / ID、模型 ID、API 路径、API 协议、关联的连接、模型编码、模型服务状态、API 端点、操作（路由及映射｜故障转移配置｜更多）。名称与永久 ID 同列，ID 不因名称或调用值变更而变化，支持完整复制及悬停查看；未关联上游模型、尚未形成具体服务的配置项显示待配置，不补造服务 ID。关联上游模型按实际模型映射定位，展示服务商名称（连接名称）和完整连接 ID，不用连接 ID 替代。连接或端点有多项时首项加数量，点击查看全部。API 路径含方法与路径，协议逐项对应，端点为平台对外完整地址；仅展示真实开放的接口，不把上游地址或仅声明的接口当成已开放平台端点。模型服务状态为已启动／已停止，与销售上架独立。第一列和操作列固定，窄屏只固定操作列，表格局部横向滚动；每批展示 20 条服务，计数以服务为单位，待配置项单列计数。搜索覆盖服务名、永久 ID、调用标识、模型编码及关联上游模型名称/ID，筛选命中具体服务行。详情定位所选服务的路由及连接上下文，面包屑返回恢复筛选、已展示数量和滚动位置。删除以所选模型服务永久 ID 定位，只处理该调用入口；校验启停、上架、路由/草稿、订单/调用及套餐引用，确认后移出列表，其他服务、模型资料和历史记录保留。列表、详情和 JSON 页均不提供模型服务批量维护；详情页签为路由及映射、故障转移、操作记录，不提供调用指南。

列表和详情页头均可打开「批量新增模型服务」弹窗。模型通过可搜索多选下拉选择已登记的上游模型，每批最多 5 个；触发器只显示首个标签和剩余数量，剩余项可展开查看，另显示已选数量，不因多选撑高或截断整个控件。名称、类型从所选模型读取。服务原子创建且不自动关联上游模型、启用或上架；失败保留选择，取消保留未保存保护。具体规则见本章模型服务批量创建条款。

从连接检测或接入任务进入服务管理时，按明确的主档引用打开已有服务；若需新建，沿用该主档与类型。主档缺项时显示「维护模型资料」入口。服务端核对供应登记和重复服务，保留已有稳定 ID、资料、供应、价格和路由历史。

## 模型运营维护交互

- 模型资料基础字段默认展开，高级模态任务、能力、参数和来源分组收起；查看编辑用同一类型名称与上下文单位。编辑共享卡片前提示影响服务。
- 从连接详情批量添加模型时，保存只新增所选上游模型关联，保留共享地址、密钥及其他模型成本。
- 连接或映射被生效路由、草稿引用时禁止解除关联。引用检查继续使用原业务数据。
- 「编辑信息」在现行依赖校验允许时维护模型 ID；保留永久服务 ID 和审计历史。删除服务使用[模型服务与调用路由](#模型服务与调用路由)的检查流程。
- 字典中文名和单位优先，英文与内部标识为辅助。操作记录支持搜索、类型筛选和安全的旧新值摘要；旧记录无快照时明确缺失，不回填虚构值，不展示凭证。

## 连接成本与模型售价

- 模型销售支持按模型展示名称和售卖状态组合筛选。模型选项按稳定 ID 去重。筛选和分页写入 URL，详情面包屑返回时沿用原条件。

- 连接详情的「模型成本」按模型行展示采购价，提供单条「成本设置」和批量设置。计费项、适用条件、金额、币种、单位和生效时间分别保存，保留采购版本。显式零价与缺价分开，改价不追算历史请求。失败保留输入，提交前复核权限、范围及共用工作区修订。
- 成本、售价、连接和资料通过同一 D1 读写边界；直接 URL、刷新、权限、冲突及失败输入保护与原模块一致。新增对象不因缺价落入另一套本地存储。
- 连接详情的「模型列表」按模型行展示容量，并通过「容量设置」维护。容量只展示已配置指标：零项显示「未配置」，一至两项直接显示数值和单位，超过两项显示前两项及「更多 N 项」，浮层只列剩余指标。「容量设置」独立放在连接操作中。缺失值不代表零或无限。容量设置使用 960 px 抽屉，分别维护 RPM、TPM，并按需添加并发上限、RPD、TPD、RPS、输入 TPM、输出 TPM、IPM；TPM、输入 TPM 和输出 TPM 以百万 Token/分钟展示和填写，最多 6 位小数，保存时精确换算为 Token/分钟正整数；其他指标须为正整数。容量按连接稳定关联 ID 独立保存到当前连接的 `capacityLimits`，不从同模型、同服务商或共享连接继承或联动。保存沿用 D1 事务、权限、修订冲突、失败保留输入和未保存保护；查看及取消不写入，容量变化不清除连接测试、报价或路由。这里记录上游额定限额，不代表实时剩余额度或网关限流执行。
- 模型售价按模型服务的稳定 ID 定位；详情仅保留售价配置、变更记录；不提供销售设置、查看关联成本或查看服务与路由入口，售价金额下不展示采购成本提示。变更记录仅展示当前服务的计费项与售价版本，含价格版本 ID、版本号、生效时间、计费项、金额、单位和币种，不混入上架、可见性、连接、路由或销售范围操作。完整审计记录保留在原存储与模型服务操作记录中。既有销售范围及经营校验不变；失效价格不作为生效价，历史价格按原服务及代际查阅。
- 内部服务不要求售价且不销售；变更用途必须停服、停售并核对商业依赖。无法核对时阻断，不自动收费、退费或重写权益。
- 管理端模拟记录保留调用时来源、成本版本及计量依据；无成本待核算，内部验证无订单／订阅／销售费用；同操作 ID 重放不重复写版本、请求或费用。

- 管理端模型字段按实际归属命名：主档业务身份为「模型编码」，模型服务中客户调用参数为「模型 ID」，连接上游调用参数为「上游模型调用标识」，内部主档键为「模型档案 ID」。主档/服务/目录别名的可读名称用「模型展示名」，名称取值和归属保留；模型服务名称独立。广场与部署展示实际模型服务 callId，不使用父模型的 modelId 替代。限流模型目录读取主档 canonical_slug，使用「模型编码」。新操作差异按对象命名；既有审计原文、导入文件表头和数据库字段不重写。

模型运营字段、永久 ID、JSON 批量维护及模块归属统一遵守[字段与身份规范](MODEL_OPERATIONS_IDENTITIES.md)。新建及存量对象均须符合规定前缀与 UUID v4 格式。具体模型服务统一使用 model_service-UUID；旧前缀须通过专用事务同步迁移全库主键与引用，不保留公开旧号或别名。


模型销售保留批量维护入口，沿用当前页面对象范围、校验和原子保存规则。

## 后台访问控制

- 「租户管理」集中办理个人及企业开户和资料状态维护。企业详情提供「基本资料」「租户管理员」「组织及成员」「模型授权」和页头「查看项目」。系统管理员在后台企业详情查看或维护组织及成员，复用成员规则和操作记录。指定管理员及停用、启用操作从「租户管理员」页签办理。选择已有登录账号时默认列出本企业可被指定为管理员的正常成员，可按姓名或登录账号搜索全站正常账号。个人详情提供「基本资料」「模型授权」和「查看默认项目」。
- 「模型授权」列出当前租户已授权的模型服务，可按名称或调用标识搜索。系统管理员从未授权且符合上架与销售范围的模型中新增开通，并对单个模型设置 RPM、TPM 或确认移除。限流在当前租户的项目间共享，同一模型的各调用标识共用限流。TPM 仅适用于按 Token 计量的模型。开通仍受订购等调用条件约束，移除只撤销本租户授权。
- 「项目管理」与「租户管理」并列。系统管理员可直接打开项目列表，按租户及项目名称或 ID 查找，列表显示所属租户。企业详情的「查看项目」带入当前租户，个人详情直达默认项目。运营人员从租户详情进入当前租户的项目只读视图。新建项目选择企业租户和首位项目管理员，企业内用固定默认企业。
- 项目详情默认展示「项目概览」，提供「预算与限流」和当前项目的「API 密钥」，企业项目另有「项目成员」。系统管理员在对应页签配置预算与限流、管理成员及指定项目管理员，候选为本企业已启用的成员。项目用量（内部空间为项目成本归集）、调用日志和审计日志按权限在新浏览器页签打开，绑定当前租户及项目。项目变更接口验证管理员会话、租户和项目归属，审计保留实际操作者。
- 租户基本信息提供 L0 至 L5 的服务等级选择，列表可查看等级。资料只展示业务字段和已填写的扩展信息。租户项目清单显示已配置模型数；项目详情显示已记录的创建人。

管理工作台中英文切换同时作用于导航、表头、字段标签和组件语言。模型运营字段采用术语表英文列，语言切换保留标识、输入值和资源名称。
