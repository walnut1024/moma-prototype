# 5.12.0 页面当前约束

- 个人、企业和后台统一使用 `#/auth/login`。验证成功后按账号身份及角色进入空间或后台工作区，只有原地址在当前权限范围内时才恢复；后台所有模块共用服务端会话，不保留模块登录页或登录弹窗。401 返回统一登录并保留原路径，403 显示权限拒绝；退出及账号切换撤销旧会话。

本文件汇总本版本有效页面与业务约束。模型运营以本页导航和各模块规则为准；实际本地验证及发布边界见[实施台账](MODEL_ONBOARDING_PROGRESS.md)。历史 UX 文档不恢复已移除的入口或旧前置条件。

后台操作入口按用途命名。创建独立记录用「新建」，提交时用「创建」；向当前配置增加条目用「添加」，建立已有对象的关系用「关联」。入口、标题、面包屑及指引使用相同的对象名称。

## 全站 Mock 数据与双面联动

- 5.12.0 初始资源、参考目录和模拟响应统一在 `src/mock/` 配置维护，私有化发布使用 Workers + D1 保存模型运营、模型目录、订购、项目配置与调用记录。本地演示使用版本内浏览器业务存储；详见 [Mock 数据合同](MOCK_DATA.md)。本节替代共享页面中“组织及成员仅保存在独立前台样例”的旧约束，仅适用于本版本。
- 系统初始数据与用户配置分开标记；恢复存档不重放初始生成器、不补回删除资源。手工记录、草稿、订单、历史与未知来源数据保留，旧无归属记录不自动认领。
- 前台 Key、订购、客户智能路由、在线体验和后台组织成员记录落到共享业务集合；客户作用域、所有者、修订冲突及存储错误在写入边界校验。后台修改相同记录后，前台经事件、同源标签页更新或聚焦复查读取新值。
- 「智能路由」提供「智能匹配」「模型预设」两个项目级页签。智能匹配首页只展示 Auto Router，企业管理员、当前项目管理员或个人本人从「路由设置」独立配置、保存和生效 `moma/auto`、`moma/performance`、`moma/cost`。「项目分流」从「智能路由」打开，绑定当前项目。预设有独立详情、编辑、API 调用和版本历史，切换历史版本须重新校验当前资格，调用 ID 保持稳定。启用的 Auto Router 和预设可从详情进入文本生成试用。智能匹配、模型预设的保存、版本、停用、试用、API 示例及调用均绑定同一项目；企业切项目切换配置并退出原项目的预设详情或编辑，个人固定唯一默认项目。各项目可独立使用相同调用 ID，API 按 Bearer 密钥所属项目解析，不接受客户端覆盖项目。项目管理员维护项目智能匹配；普通成员可查看已生效智能匹配及自己的模型预设，保留自有预设维护权，不能访问未加入项目。候选范围同时受项目模型权限、空间授权、订购及 Key 权限限制。后台读取与调用模拟使用同一项目归属和权限，路由审计记录项目 ID；保留稳定 ID、草稿、版本及调用历史。
- 从「智能路由 → 项目分流」进入。项目管理员或企业管理员可编辑，已分配项目的普通成员可查看。API Key 条件引用同项目的有效 Key ID，用户标签条件匹配 `metadata._user`。按规则顺序选取目标服务，未命中使用默认服务，备用模型服务按保存顺序尝试，最多五个。私有化发布的调用示例保留 `project@策略标识`，配置与模拟调用使用客户工作区。
- 调用日志、租户用量、平台概览及用户统计从同一请求和显式身份事件派生。未采集 Tokens、费用或时延显示未知；本地回复不构成真实上游或计费证据。图表样例继续使用静态 JSON 配置和原有派生逻辑；不写入 D1。用户侧未迁移模块仍使用浏览器存储，不与 D1 自动双写。
- 前台编辑在打开时冻结修订号，跨标签页更新不得静默覆盖当前输入；冲突保留输入并要求刷新。账号/客户切换清除旧临时表单及明文 Key，已保存筛选视图按身份隔离。关闭 Key 额度后保存/刷新保持不限，相同额度与周期重新启用保留原用量；TPM/QPM 按实际值保存和模拟校验，不豁免客户额度与权限。
- 用户面项目选择、项目管理和项目分流复用 Semi Design 的页签、操作控件、表单与浮层。窄屏表格在当前面板内滚动，关闭分流编辑前确认未保存的修改。
- 模型广场筛选、搜索、详情操作和订购确认使用 Semi Design。窄屏筛选在抽屉打开，关闭时保留筛选条件并将焦点还给入口。
- 文本生成的输入、参数与新建确认，以及体验共用的模型选择弹窗使用 Semi Design。模型选择保留供应商、类型、计费方式和可体验条件，并沿用项目调用权限。客户账单使用 Semi 表格，用户面共用分页保留原有页容量。
- 文本、图片及视频体验的推荐提示沿用 Semi 填充与文本色；文本推荐在中等宽度显示三列、窄屏显示两列，保留完整提示词填入。新建对话与账号认证的主要入口使用实色按钮。体验参数使用业务名称与必要范围，不重复展示接口字段名。用户面弹窗限制在视口内，项目名称的必填错误在表单内中文提示。订购费用与确认区排在协议之后，不遮挡表单。
- 账号菜单、登录空间选择、密码找回、邀请与个人或企业认证使用 Semi Design。认证保持字段校验、协议链接和分步提交，错误保留在原表单中。
- 密码找回与修改复用登录页的品牌区和表单容器，保留验证码、密码校验与返回路径。
- 空间总览、用量统计、调用观测与调用日志共用 Semi 筛选和视图保存。调用日志使用 Semi 表格和请求详情抽屉，保留筛选导出、详情 JSON 和既有脱敏规则。
- 用户面空列表保留记录数，零条时隐藏分页操作。订购表格按服务、订单及订阅的原始 ID 标识行，刷新不重复。项目表格铺满当前面板并在窄屏局部滚动，日志长服务标识在列表中限两行并提供完整悬停值。组织操作时间按北京时间显示。
- 图片生成、视频生成、语音识别和模型对比使用 Semi 操作控件、参数弹窗与输入框。窄屏时对比列在当前面板内横向滚动，保留同步输入、独立参数和会话权限。
- 组织及成员、批量添加和 API Key 使用 Semi 表格、筛选、表单及浮层。批量添加保留校验和结果步骤，明文 Key 仅在创建或重置成功时交接。
- 统计分类匹配实际模型类型，基础模型筛选纳入其服务商服务调用；请求保留发送时调用 ID，未知计量不填零，音频秒数/字符与 Token 分开。不使用固定样例数作为当前套餐权益或剩余额度。
- 动态历史样例只绑定固定初始资源且保留有效归属，不能因新增/编辑 Key、模型或成员而重分配历史；用户真实动作产生的请求独立保留。重复 Request ID 校验 Key、客户、模型及服务归属，冲突不返回原记录，已撤权 Key 不能重放成功。

## 前台项目管理

- 账号是登录身份，客户/租户是资源和结算主体，空间是进入该主体的控制台视图，项目固定归属一个空间。组织部门和企业成员属于企业空间；项目只引用本企业的部门及成员。同一账号可加入多个企业，也可拥有一个个人空间。多空间从账号菜单切换，单空间不显示切换入口。
- 用户控制台侧栏顶部依次提供「首页」「模型广场」，企业空间还提供「项目管理」和「当前项目」切换。功能导航提供「账户管理」，用于查看账号资料与认证。项目管理默认呈现「我的项目」页签，按企业列出当前账号实际加入的项目，并展示本人在每个项目里的成员角色。仅租户管理员可使用「全部项目」页签，查看当前租户的全部项目及既有部门分组。页签下方左侧是可搜索的项目树，右侧是项目详情。进入页签优先展示当前范围内的当前项目，其次展示本空间第一个可访问的正常项目。窄屏上下排列。
- 个人侧栏从首页进入默认项目概览，直接在默认项目执行体验、接入与调用及调用观测，通过使用设置维护默认项目。企业普通成员可查看授权项目，密钥维护需项目管理权。「系统管理 → 组织及成员」显示登录企业的组织树、成员及操作记录。租户管理员管理本企业，部门管理员管理授权部门内的普通成员。
- 文本、图片、视频、语音体验以及用量统计、调用观测、调用日志均为独立页面入口；模型订购与订购及账单分别进入。保留页面原有业务分类页签；模型订购的按Token用量计费、Token Plan订阅、Coding Plan订阅页签仅将展示名称改为「按量计费」「套餐订阅」「资源包」，内部计费标识、订单记录及过滤逻辑保持不变。账号认证可从「账户管理」或右上角账号菜单进入。空间切换和退出登录从右上角账号菜单进入；模型广场、模型详情和模型订购页面不再显示独立账号/退出广场状态条。
- 私有化站点依据部署授权和已保存的空间策略区分对内使用与对外运营。内用提供本企业空间及授权模型，后台入口为「本组织」，前台按项目使用模型。工厂外营开放多个政企客户及个人客户，政企开户容量与部署方式分别校验。企业内外共用组织与项目权限，部门用于项目归属及成员查找。
- 工厂工作区由企业管理员或个人客户本人按当前空间订购有效按量服务。企业订购生效后在本空间项目分配相应模型；个人默认项目直接继承已开通模型。订单归属空间，调用费用按请求归属项目，通过前后台同一组记录查询订单及用量账单。企业内用在后台按调用时项目主责部门归集成本。
- 个人注册及后台开户原子创建一个默认项目并记录 defaultProjectId，前台命令和后台事务均拒绝增加、替换、重命名、转移或独立改变默认项目状态。历史单项目记录保留原始名称及 ID，以「默认项目」显示；异常记录明确报错，不自动合并或删除。租户管理员可新建和删除本租户项目。创建人获得项目管理员角色。租户管理员和该项目的项目管理员可添加、移除和查看项目成员，并可把新增或已有成员设为「项目管理员」或「普通成员」。项目管理员退出、被移除或降级前须保留另一位有效项目管理员。普通成员在项目管理中可查看已加入项目和成员，并可切换到其他已加入项目；个人项目由本人管理。
- 企业项目详情在标题区展示项目信息，下方默认打开「项目成员」。租户管理员和该项目的项目管理员可编辑项目信息，并使用「项目预算」和「模型限流」页签。新建与编辑仅填写项目名称和描述，既有部门归属保留。具备相应权限时，详情标题区直接提供「编辑项目」「删除项目」或「退出项目」，已停用的企业项目可通过「启用项目」恢复。删除后保留项目 ID、调用、Key 关联及审计。API Key、项目分流及日志留存按当前项目使用。个人「使用设置」保留默认项目的预算、日志、限流和分流。
- 企业新项目逐个开通模型。已有项目缺少项目级配置时沿用原空间授权的继承规则。内用的独立模型服务须按服务 ID 为项目逐个开通，包括缺少项目级配置的存量项目。项目管理员在空间授权范围内开通模型和配置每模型 RPM／TPM，同一项目的 API 密钥和在线体验共用权限与限额。撤销租户授权即时阻断项目调用。项目路由按规则匹配或选择默认模型，备用模型也需通过项目与 Key 权限检查。
- 企业「项目预算 → 设置额度」以百万 Tokens 配置项目预算和每日批处理 Token 限额。预算周期可选永不重置、每小时、每天、每周和每月，按北京时间自然周期统计，周一开始。项目预算统计项目已成功调用的输入和输出 Token，在线体验和 API Key 共用额度，超额拒绝调用。项目 TPM 与 RPM 按最近 60 秒限制项目总量，并与模型和 Key 各自的限流同时生效。每日批处理限额可保存，待批量调用接入后执行。
- 企业首次保存 Token 额度后，项目预算按 Token 规则执行，既有人民币预算记录保留。个人使用设置沿用既有预算。按量 Key 支持独立累计人民币预算，Token Plan Key 支持独立套餐抵扣 Token 预算。所有手工 Key 可设置到期时间。未确认费用单列；无法核算受人民币硬预算约束的新调用时返回错误。套餐购买费用归订购空间。
- Key 在指定项目创建、编辑、启用、停用、重置和删除。用户控制台「API 密钥 → 订阅套餐」按项目 ID 与订阅 ID 独立管理每份订阅的密钥，同名套餐不合并；模型选项取项目和本套餐允许范围的交集。编辑、重置、删除不得改变其他订阅的密钥，不得把已有密钥转入另一订阅或按量范围。创建与重置的密钥只在一次性交接弹窗显示，关闭即清除。列表显示掩码，历史和操作记录保留稳定 Key ID。托管体验 Key 按项目自动使用，隐藏明文和维护操作。
- 模型广场详情点「在线体验」先校验当前空间订购或授权，再使用当前可访问项目；唯一项目自动进入，多项目未选择时弹窗选择。企业空间未订购时管理员可订购，普通成员提示联系企业管理员；内用缺少授权提示管理员。项目未分配模型时项目管理员通过「配置模型权限」授权，普通成员提示联系项目管理员。个人绑定默认项目。模型详情、文本、图片、视频、语音及模型对比发送时绑定项目。配置、调用资格、订单及会话由各自写入边界校验。留存开关默认仅保存日志元数据，开启后新请求可保存脱敏输入输出，仅项目管理员查看，CSV 不含正文。对话历史沿用账号访问规则。
- 个人默认项目概览按北京时间展示请求数、Token、费用和成功率及上期同进度对比。单日按 10 分钟、多日按天显示请求与费用趋势；模型与 API Key 按调用费用或请求数展示 Top 5。配置摘要直达预算、模型权限、项目分流及 Key；用量、日志及请求详情保留项目范围。

## 前台用量统计

- 从「调用观测 → 用量统计」进入，默认打开「概览」。项目入口的热力图、用量分析及导出使用同一项目范围。顶部提供语言、多模态理解、视觉、语音、向量、排序六类模型页签。概览在筛选上方展示近 365 个北京时间自然日的 Token 用量活动。按日每格一天，按周每格一周（周一为起点，首尾按区间截取），累计每格为从区间起点至当天的累计。零值和无计量分别标识。
- 下方「用量分析」首层显示时间、计费方式和项目，筛选仅影响用量分析区。「更多筛选」的调用方组包括 API Key 和调用用户，模型页签增加模型范围组。已选条件持续显示实际日期和生效的细筛条件。项目和计费方式约束 Key，项目、计费方式及 Key 约束已记录的调用用户。政企管理员可筛选调用用户，未记录调用人归入「未识别用户」。变更上级条件会清除失效的下级条件，切换日期保留查询对象。保存视图保留页签和有效筛选。
- 概览指标包括调用次数、调用模型数、调用成功次数及成功率、调用失败次数、已计量 Token、平均每次 Token 和调用费用。桌面宽度允许时排成一行，数量达到 1 万或 1 亿时按对应中文单位缩写，悬停显示原值。Token Plan 显示已记录的套餐抵扣。平均每次 Token 仅以有 Token 计量的调用为分母。订购模型数取当前空间有效订单中关联的模型，按模型去重，说明中展示模型类别分布。
- 概览的用量分析并列展示 Token 构成和已订购模型用量占比，下一行展示单模型用量趋势。模型占比及趋势只统计当前有效订购模型在所选范围的已计量 Token，前五单列、其余合并。趋势单日按小时、多日按天，自定义日期最多 31 天。
- 概览底部展示模型、项目、API Key 三个榜单。三榜共用排序指标，默认按调用次数排序，费用按同一币种比较，各用量榜仅统计有相应计量的调用。切换排序只更新榜单。点模型进入对应页签并选中该模型，点项目或 Key 在概览收窄范围。类别未知的调用仍计入概览调用次数。
- 模型页签保留汇总条、双列趋势和右侧图表导航。选定模型 ID 后展示适用的 Token 构成，采集到上游缓存命中量时展示 Prompt 缓存分析。命中率以同一批请求的输入 Token 为分母，命中 Token 计入输入。语言和多模态理解统计输入、输出及适用的缓存分项，向量和排序只展示有计量的输入 Token。视觉分开显示图片张数、视频时长及已计量 Token，语音识别时长与合成字符数分别统计。
- 年度活动和用量分析复用同一请求去重和 Token 计量规则，分别按各自范围统计。用量分析基础时间桶为北京时间单日 10 分钟、多日按天，含今日时统计至快照时间。CSV 导出当前页签的筛选范围，概览导出按各模型的实际类别标记。仅在本地开发链接 `?page=usage-statistics&usageDemo=1` 使用独立模拟请求。

## 模型运营云端持久化

「模型服务」的列表、详情和变更共用现网 D1。平台管理员和运营人员可逐条导入当前浏览器保存的记录，沿用服务 ID、配置、创建人和创建时间。同一 ID 重复导入不会覆盖现有配置，调用标识冲突时提示核对。

- 新 D1 初始化计费字典和参考模型主档。演示环境的研发说明提供独立演示包入口。导入复用稳定主档，冲突时整包拒绝。日常登录与刷新读取已有工作区。
- 私有化发布的客户身份、连接订单、项目 Key 和各在线体验的项目调用由 D1 校验及保存。项目配置与统计按「前台项目管理」执行。原型调用使用模拟上游。

## 私有化站点配置

- 「租户管理」和「项目管理」保留原有直达地址和权限。工厂外营展示企业和个人租户列表，项目列表可筛选租户。企业对内的租户管理直接打开配置的默认企业，项目列表限定在该企业。项目详情提供项目用量查询。

- 「网关管理 → 路由设置（全局）」仅系统管理员可访问。默认打开「全局故障转移策略」，最短重试间隔位于最大重试次数下方，仅在全局配置。保存写入原有字段，取消放弃草稿。
- 全局路由算法初始为加权随机。故障转移表单以已复测的 LiteLLM 1.110.2 Router 构造值为参考。未配置时，最大重试次数、重试间隔、超时、故障判定阈值、冷却时间和最大降级次数分别显示默认 2 次、0 秒、6000 秒、3 次、5 秒、5 次，异常重试均显示「未指定」。编辑时未配置字段以默认值占位，D1 仅保存显式配置。清空后保存会移除该项配置，填写 0 原样保存和回显。保留已保存的数值及异常配置。历史记录中的重试条件和故障转移开关继续按已保存值回显。
- 服务继承时读取已保存的全局配置。首次自定义复制全局显式配置中适用的服务级字段。自定义缺项显示参考默认值。切回继承并保存后保留自定义配置，再次选择自定义时恢复。最短重试间隔仅全局维护，在编辑态始终可改。本期核对界面、保存、刷新读回及服务继承，模拟调用保持既有行为。
- 模型服务统一继承全局路由算法，在「上游模型」页只读展示“路由策略：算法名（继承全局）”。「故障转移策略」在当前页切换继承全局与自定义，支持页内保存或取消。
- 「授权管理」（`#/admin-2/license`）以一张卡片展示授权范围和状态，运营模式、有效期与已有授权信息在下方对齐展示。页面不列功能清单。商业版显示「政企标准版 + 商业化增强」，内用版显示「政企标准版」。平台管理员通过弹窗粘贴并校验 License，缩小授权范围时需二次确认。内用版禁用商业运营分组中需要商业授权的入口及其路由和写入。商业版到期后保留历史查看，写入端拒绝新增订单、开售、售价与销售对象变更及套餐命令。已有订单以原调用权限核验。
- 平台管理员通过管理工作台顶栏的「菜单模拟」下拉框，在「对内企业运营」和「对外商业运营」之间预览侧栏。默认使用实际授权对应的菜单，切换页面保留选择，刷新或重新进入工作台后恢复默认。授权卡片、页面准入和业务写入读取实际授权。点击当前授权不可访问的预览入口时保留当前页并提示所需授权。
- 「模型售卖」按具体模型服务维护模型刊例价。经营分析按账期汇总后台已记账的出账与实收金额。

- 私有化构建通过 `VITE_MOMA_PRIVATE_SITE=1` 开放站点配置和协议管理页面，两项均仅供平台管理员访问。站点配置适用于内用版和商业版。协议管理需要商业运营授权，内用版拦截直达和保存，商业授权到期后可查看已发布的协议。公开部署的常规构建默认关闭这两个后台页面。
- 「站点配置」分别维护「用户控制台展示名称」与「管理工作台展示名称」。前者用于用户控制台顶栏和共用登录品牌区，默认「模型服务平台 MoMA 政企版」。后者用于后台顶栏和首页欢迎卡，默认「Token 管理工作台」。两个名称独立保存，留空使用各自默认值。已有单一平台名称带入用户控制台展示名称。Logo、浏览器标题、Favicon 和认证插图分别配置。图片支持本地上传（单张 512 KB）、HTTP/HTTPS 链接、预览和恢复默认。
- 「协议管理」（`#/admin-2/site-agreements`）是商业运营的独立页面，通过「用户协议」「隐私政策」切换文档，每次展示一个宽版编辑区，支持正文、HTTP/HTTPS 外部链接、草稿预览和分别恢复默认。两份协议通过「保存协议」一起发布。每份协议有可复制、无需登录的站点地址，认证及邀请沿用同一地址。公开阅读只读取已保存的服务端配置，未配置正文或链接时读取对应内置模板。
- 基础配置使用版本专属的浏览器本地存储。协议发布由系统管理员经同源接口写入原型数据存储，比较修订号，保存失败保留草稿。首次发布前可在编辑器带入当前浏览器已有的自定义协议，保存后对外生效。两类配置都以站点为范围。

## 公告管理

- 「公告管理」沿用 `#/admin-2/announcements`。平台管理员可在内用版和商业版管理公告。列表展示标题、发布范围、状态、展示时间和发布人，支持按标题和状态筛选。
- 新建或编辑草稿时填写标题和纯文本正文。发布范围固定为「全部用户」。编辑弹窗提供较大的正文输入区，窄屏可滚动表单并保留底部操作。默认立即生效，可指定生效时间，发布须设置到期时间。界面以北京时间展示，确认发布前预览正文、范围和有效期。
- 草稿可继续编辑。待生效或生效中的公告可撤回，已到期和已撤回的记录可查看。发布和撤回写入审计日志。此前已定向发布的公告保留原记录及 ID，仅供后台查看。
- 用户登录并进入用户控制台后，一个弹窗内显示当前账号可见的有效公告，每条只展示后台发布的标题和正文。直接关闭后，本次登录的当前标签页不会重复展示。勾选「不再展示」再关闭，为当前登录账号保存本次弹窗内所有公告的展示偏好。其他账号独立设置，切换租户空间或项目沿用当前账号的展示记录。

## 平台审计日志

- 「审计日志」保留原直达地址，仅向系统管理员开放。列表和详情使用当前后台账号的服务端会话，未登录统一跳转 `#/auth/login`，登录后按权限返回原页面。通过 `/api/v1/audit-logs` 读取已有 D1 审计事件，覆盖发布服务路由、轮换共享密钥、替换 API 密钥、批量停用上游模型、关联上游模型变更、模型服务启停、因停服自动停售、项目管理和个人空间开关。
- 列表依次展示事件 ID、时间、操作人、操作类型、模块、IP 地址、客户端、租户、项目、结果和操作对象。按时间与事件 ID 倒序，按游标翻页。支持按时间范围、完整事件 ID、操作人、操作类型和客户端类型查询；「更多筛选」提供对象或记录 ID 搜索、操作结果、对象类型、客户和项目。对象类型可按「上游模型状态」「关联上游模型状态」筛选实际发生的状态变化。默认近 7 天，自定义日期按北京时间查询。「刷新」保留已应用筛选并回到第一页。
- 列表中的操作人名称和账号 ID 各占一行，超出列宽时省略。悬停或打开审计详情可查看完整内容。
- 点击事件 ID 打开审计详情。详情保留列表中的身份与来源字段，补充原始操作 Code、操作 ID、阶段和关联验证标识。「请求证据」展示操作 ID、命令和已采集的安全参数，历史记录仅展示留存的内容。「响应证据」展示操作 ID、记录的 HTTP 状态、操作结果及可用的工作区修订号。「变更证据」展示前后值、目标、关联对象和逐项结果。「原始详情」展示接口返回的脱敏审计 JSON。各 JSON 页签支持展开、收起、复制和全屏。
- 新事件在同一业务事务的审计行保存字段摘要、安全参数和可识别的 Web 来源。租户和项目按已记录的归属展示。客户端未知时显示「未记录」，IP 地址、租户和项目缺失时显示占位。密钥明文、掩码、指纹、完整配置、内部配置地址以及完整请求和响应体排除在返回字段外。配置提交属于原型证据，网关实际生效须由独立执行回执确认。

## 流量运营

- 限流配置页使用 XA 2.4 卡片、页签、表格、表单、弹窗、抽屉和反馈。运营区「流量运营」下提供「用户限流」「模型限流」两个页签，默认进入用户限流。平台管理员和运营人员可访问。
- 用户列表显示账号名称、用户 ID、所属租户、默认值、生效值、规则来源、一客一策条数和操作。默认值取用户全局默认，生效值取账号通用额度。两个值均包含 RPM 和 TPM。每个用户只显示一行，列出所属租户的名称和类型。支持按账号名称、用户 ID 或租户名称搜索，按所属租户类型筛选。通用额度可单独或批量修改、恢复全局默认，已有一客一策仍按模型服务匹配。筛选、切换页签和批量操作成功时清空选择。
- 全局默认在 D1 初始化为 60 请求/分钟和 300 万 Tokens/分钟，放在用户列表搜索行，Tooltip 说明继承规则。新账号和没有自定义通用额度的账号使用当前值。
- 点击账号行的一客一策条数打开右侧宽抽屉，显示账号名称和 ID，按模型服务名称或模型 ID 搜索，支持添加服务、修改额度和移除，统一保存。一个账号的同一模型服务只能配置一条额度。账号规则优先级依次为一客一策、账号自定义、全局默认。
- 账号行的「限流可视化」打开只读宽抽屉，展示通用额度以及各模型服务的账号侧额度、命中规则、模型共享上限和最终上限。RPM 和 TPM 分别取两侧较小的值，账号侧额度无法读取时最终上限显示「—」。
- RPM 使用请求/分钟。TPM 固定以百万 Tokens/分钟展示和输入，最多 6 位小数。组合额度在数值旁直接标注 RPM 和百万 TPM。保存时 RPM、TPM 均为正整数。
- 模型限流搜索行沿用用户限流布局，右侧维护「模型默认」，D1 初始值为 600 请求/分钟和 3,000 万 Tokens/分钟。列表读取 D1 模型服务，展示模型服务名称、模型 ID、默认值、生效值和规则来源。共享上限按具体模型服务保存，由调用同一服务的账号共用。同款模型的不同服务独立计算。单个服务可覆盖默认或恢复为继承。
- 页头「变更历史」打开只读抽屉，按时间倒序展示变更时间（北京时间）、变更对象、操作、变更前、变更后和操作人。D1 记录两类默认、账号通用额度、一客一策及单模型覆盖。批量操作按实际改动的账号列出，一客一策按模型服务列出增改删。记录当时的模型服务名称及模型 ID，恢复默认显示继承关系。旧审计缺失的字段显示「未记录」。
- 两个页签使用同一个后台登录会话读写 D1 限流配置。用户额度使用用户 ID，服务额度使用模型服务的稳定 ID。读取失败提示登录或重试，缺失额度显示「—」。保存同时提交配置与审计，校验角色、修订号与幂等标识，失败保留输入。浏览器旧存档与 D1 资料级限流规则保留，资料级规则的迁移口径待确认。已接入调用链的服务按最近 60 秒统计，网页和 API 调用共用计数，同一用户的各租户、项目及密钥按用户 ID 汇总。

## 套餐制作

- 「套餐管理」包含「套餐列表」和「模型抵扣系数」两个页签，默认进入套餐列表。套餐在独立表单编辑，右侧为购买页预览。抵扣规则按模型分组，在弹窗编辑。离开未保存的表单时可继续编辑或放弃本次修改。
- 「套餐管理」（`#/admin-2/package-production`）供平台管理员和运营人员访问。列表以名称或套餐编号搜索，按套餐形式和状态筛选，统一分页。套餐形式为按周期订阅或一次性资源包，首次保存后只读。套餐类型可选个人版、团队版或平台管理员添加的共享类型。新建、编辑和查看为独立表单，返回保留筛选和页码，离开时保护未保存输入。
- 订阅套餐配置每周期 Token 额度、周期售价、订阅周期、总周期数和余量结转规则。资源包配置每份 Token 总额度、单价和生效后的有效天数。两类共用套餐名称、购买页展示名称、简介、顺序及每位用户累计限购份数。支持订购的用户类型可多选政企用户、个人用户，新建默认全选，发布和上架至少选一项。展示顺序可填 0 至 200 的整数，数值越小越靠前，留空排在最后。购买页预览在大号套餐名称下方显示一行简介，并展示有效期限。
- 按月、季度、年订阅分别按原生效日期加 1、3、12 个日历月推算周期边界，目标月缺少对应日期时取月末，后续仍以原生效日推算。当前套餐制作展示规则，实际订购到期时间由权益系统计算。
- 状态为草稿、待上架、已上架、已下架。新增和编辑表单的「保存」将套餐存为草稿，允许缺少发布必填项。发布从列表发起，校验通过后进入待上架，操作为编辑和上架。仅从未发布的草稿可在列表确认删除，移除后保留审计且编号不复用。上架与下架需确认。已上架套餐只读，修改下架或待上架套餐后需重新发布。下架只停止新订购，已购权益用尽或到期后结束。
- 平台管理员可删除未被套餐引用的自定义类型，删除需确认。内置类型和被任意状态套餐引用的类型不可删除，删除成功后从选项中移除并保留审计。
- 「模型抵扣系数」列表展示已添加的模型，新增选项来自「模型服务」中尚未添加的未归档模型。每个模型默认不允许加入套餐。平台管理员和运营人员可配置「允许加入套餐」、全平台共用的抵扣规则和修改说明。添加及编辑只保存草稿，发布后切换生效版本，待发布期间继续使用当前生效规则。修改历史记录发布版本、时间、操作人、变更前后规则和修改说明。
- 先选择模型，再按该模型当前生效售价中的计费项分别配置抵扣规则。没有生效计费项时提示先配置并发布模型售价。留空的计费项不生成规则，新增模型至少配置一条。切换模型时保护未保存输入。保存和发布均校验计费项归属，已有生效规则保留至新版本发布。规则使用模型主档 ID。同一计费项可不分档，或配置互不重叠的输入 Token 档位。下限不含、上限含，允许留空一端。下限留空从 0 开始，上限留空代表无上限。按单次请求的输入 Token 数判档，整笔使用命中系数。各计费项的实际用量乘以对应系数，再相加得到套餐扣减额度。系数须大于 0、最多两位小数。
- 套餐制作的「支持模型」支持搜索和多选已发布、允许加入套餐且有生效规则的模型。选中后展示当前计费项、档位和系数，套餐只保存模型关联。暂无可选模型时提供模型抵扣系数页签入口。发布和上架至少选一个符合条件的模型。模型仍被套餐引用时，发布规则须保留允许状态和至少一条规则，服务不可删除。被草稿或生效规则引用的计费项不可删除。原模型级系数作为历史值保留。
- 使用说明和使用范围是独立的可选文本，各最多 500 字符。套餐配置、共享类型、操作回执及审计通过 5.12.0 的 D1 接口保存。原浏览器套餐记录保留在原存档。

## 套餐数据

- 「运营 → 商业运营 → 套餐数据」是独立入口，沿用商业授权和角色权限。内容区按 [MoMA-XA 2.5 套餐申领统计](https://moma-admin-610.pages.dev/v2.5/#/manage/packageClaimStatistics) 组织渐变页头、时间筛选、三张统计卡、双栏图表和明细表。日期按北京时间计算，默认今日，近 7 天和近 30 天含今天。单日按小时展示，多日按自然日展示。搜索和用户类型筛选只作用于明细。
- 工作台数据读取同一版本的 D1 套餐及已发放的订购权益，统计选定日期内的个人与企业订购份数、发放额度和按套餐分布。明细每份权益一行，分列显示套餐 ID 与实例 ID，并提供用户名或租户名称搜索、用户类型筛选、分页、成本单价及消耗详情。缺少到期日、历史用量快照、采购单价或实例消耗证据时按对应字段显示缺失，累计成本缺少核算依据时显示「待核算」。保留按指定套餐直达统计的能力。
- 「模拟数据」展示隔离的个人与企业领取样例、按档位分布、模型消耗和成本。工作台没有已有订购权益时默认展示标记后的模拟场景，可随时退出。模拟领取与真实订购属于不同来源，切换或查询均不写入业务记录。

## 模型身份与资料

- 「基础资料」下的「模型作者」与「模型系列」均和「模型」同级。模型作者列表仅展示「作者名称」和「操作」，通过新建和编辑表单维护标准名称和别名。已有作者均可用于模型筛选、系列归属和模型导入。模型系列列表仅展示「系列名称」「所属作者」和「操作」，通过新建和编辑表单维护系列名称和别名，所属作者在新建时选定。所有已登记系列均可用于新建和导入。存量文本按作者与系列的现有取值初始化，同名或已登记别名精确归类，无法匹配的原值保留为待核对。改名沿用原引用。字典变更沿用模型运营工作区的角色、修订和审计。
- 模型资料表格在作者后展示模型系列、模型版本，支持按作者和系列筛选。「批量导入模型资料」在「模型」页签的筛选区右侧。模型资料表单由管理员手动选择作者及其所属系列，改选作者时清除不匹配的系列。模型资料和卡片表单统一使用七大类型，模型资料的视觉类型另选图像或视频任务。从资料表单可在新页签打开作者或系列维护，载入最新数据后保留当前表单输入。批量导入沿用模型编码及原表头，预览展示已匹配的标准分类，未匹配或系列归属错误按行标明。服务商接入选择现有模型资料时可核对模型编码和版本，连接分别记录各自的上游模型调用标识。用户侧模型广场按同一分类筛选已可见模型。

- 术语由 [GLOSSARY](GLOSSARY.md)定义：模型资料、供应关系和销售服务各有职责，模型档案 ID、模型编码、上游模型调用标识和模型 ID 不混用，模型作者不等于服务商；采购参考价、采购价和平台售价分开。完整 URL 称请求地址，Key 按当前绑定连接表达。
- 后台模型广场的卡片和列表操作提供「编辑信息」「关联模型服务」「设置可见性」「删除」。已关联数量也可打开关联抽屉。「已关联模型服务」支持逐条移除，「添加模型服务」支持搜索和勾选同一模型档案下的多个服务，点击「保存关联」一次提交。正在展示的服务需先在「设置可见性」中取消展示。关联使用稳定的模型服务 ID，展示服务按其可用的广场配置选择。
- 删除只允许「不可见」卡片，确认后移除卡片信息及其服务关联并记录审计。保留关联服务、基础资料、售价和订单。删除的卡片刷新后也不再显示，仍可新建卡片并重新关联对应服务。
- 模型广场页头的「模拟数据」进入独立演示模式，提供卡片、可多选的模型服务和租户样例。操作仅在当前页面会话生效，退出恢复真实视图和筛选。
- 新建与编辑卡片均可手填或从「基础资料 → 模型」选取资料。图标选填，支持上传 1 MB 以内的 PNG、JPEG 或 WebP，可预览、更换和移除。导入后可修改带入字段，保存时保留原卡片身份和服务关联。上下文长度使用 K 或 M 输入，切换单位保持实际 Token 数。
- 卡片可见性为「不可见」「预告可见」「灰度可见」「全部可见」，新建默认为不可见。灰度可见支持按租户名称或 ID 搜索并多选。调整卡片可见性只改变广场展示。关联服务的售卖状态由模型售卖维护，停售只暂停新订购，已有订单与调用权限继续有效。
- 模型资料提供参考内容，最终展示信息由模型广场维护。按稳定 ID、显式关联或精确编码识别模型，不按名称近似合并版本。四模块的永久 ID 展示、字段归属及批量导入导出遵守[身份与导入契约](MODEL_OPERATIONS_IDENTITIES.md)，复用存量 ID，不改写已有引用。
- 模型类型及任务范围见[模型服务与调用路由](#模型服务与调用路由)。输入／输出模态与向量、相关性等结果类型分开，未知能力和规格保留空值。
- 资料库保留表格、查看、编辑及删除入口；长内容提供完整值的可访问查看方式，宽度不足时在表格区域滚动。资料列表名称/编码、作者、正式发布日期、类型、适用场景、模态及上下文各有语义；日期来自可核对官方首次发布记录，场景不替换为支持任务。维护分页 20/50/100、默认 20，选择流程保留自己的容量；切换容量只提交一次容量和第一页。
- 广场公共展示内容按模型管理。基础资料可用于带入字段，已保存的卡片内容由广场维护。客户请求使用模型服务的「模型 ID」，销售价格和销售对象在「模型售卖」维护。
- 前台卡片和详情读取同一份已生效资料：Logo 缺失或存储内容不合法时使用默认图标，图片加载失败时名称仍可读；详情复用卡片公共信息，并显示已填写的长介绍、模型作者、版本/发布日期、能力规格、技术接口属性及资料链接。未知属性不补零或“支持”，正式发布日期与卡片的资料更新时间分开；不把采购价、供应密钥、内部请求地址和资料核对记录投影给客户。点击卡片进入独立详情页，按面包屑、模型介绍与三项参数、服务商报价、API 调用、详细资料组织；返回广场保留当前筛选并恢复原卡片焦点。URL 保留稳定模型与服务 ID，支持刷新和浏览器前进/后退；失效或无权访问时显示不可用，不自动替换为其他服务。
- 详情按当前客户可见的模型服务展示报价。选择服务后，调用名、价格、订购操作和调用入口同步切换。
- 前台模型广场按稳定模型 ID 聚合 D1 的有效上架服务，一款模型一张卡片。新订购校验该租户可进入相应卡片详情且该服务正在展示。已有有效订单仍可查询及按调用条件使用。按发布日期排序，服务商筛选按服务商 ID 去重并匹配卡片内各服务。客户按服务的永久 ID 订购并使用该服务的调用名。当前路由缺少有效采购价或售价时，对应服务暂不出现在广场，D1 拒绝新订购并保留上架配置及历史。售价仅取平台已发布销售快照，明确币种/计量单位，未提交输入、采购价和内部连接不对客展示。每条调用记录保留当时的连接、路由和售价引用。
- 基础资料、模型服务和广场各自保存对应字段。修改或删除参考资料时，已保存的服务、上游模型和卡片保留各自的字段及稳定引用。
- 模型运营初始数据见[全站 Mock 数据](MOCK_DATA.md)。服务商、资料、连接和服务使用明确的稳定关联。初始化沿用已保存记录、删除标记、凭证、草稿及历史。
- 有权限的管理员可确认删除主档。未完成接入草稿的继续提交规则待确认。添加供应模型从主档选择，可原地新增主档并返回选中，不自动登记供应关系或连接。批量只接受匹配主档的模型，不接受任意未匹配上游 ID，不生成空连接。
- 对外使用按当前服务、发布与订购条件校验。资料登记及导入遵守对应表单与模板规则，未知事实保持未填写。

## 模型接入

- 新建第三方模型服务连接时，接口格式决定只读的接口端点。切换格式自动更新端点和完整请求地址。手动配置连接时按服务商文档填写服务地址，保留路径及版本前缀。表单实时显示完整请求地址，忽略服务地址末尾斜杠，再追加接口端点。服务地址已包含所选端点时禁止保存。OpenAI Chat 的端点为 `/chat/completions`，Anthropic Messages 为 `/v1/messages`。标准模型列表在同一服务地址下请求 `/models`。

「模型运营 → 模型接入」包含「连接列表」（`providers-reference`）及「连接健康」（`providers-health`）。总表按连接名称搜索，逐条连接展示「连接名称/ID」「服务商」「连接类型」「状态」「服务地址（Base URL）」「操作」，支持分页。名称和 ID 都可进入连接详情。类型按当前配置显示 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、OpenAI Embeddings、火山方舟 Video Generation、DashScope Video Generation 或 MiniMax Video Generation，其他已有接口保留其类型。列表显示系统判定的连接状态，包括待验证、可用、需关注、待复测，以及冻结等限制原因。行操作为「测试连接」和「删除」。连接不支持手动启停。未接入模型时「测试连接」置灰，悬浮或聚焦提示「当前模型连接下暂未配置上游模型」。HTTP 探测展示完整请求地址，说明只检查是否收到 HTTP 响应。在测试弹窗选择「模型调用测试」后，按所选模型的默认任务执行。连接详情的「基本信息」显示类型、连接名称、服务地址、上游 API 密钥数量、状态、简介及创建人／创建时间，并提供「编辑信息」。「模型列表」按模型标识和展示名称搜索，提供「批量测试」「手动添加」，以及单模型编辑、测试、容量设置和删除。第三方连接另提供「获取模型列表」及模型列表接口说明。「手动添加」在当前连接打开「添加上游模型」宽抽屉，顶部单列目标连接、已绑定服务商、接口格式和 Base URL。抽屉只列出「基础资料 → 服务商 → 供应模型」中当前服务商的匹配模型。已保存的接口格式和完整请求地址须与当前连接匹配。同一模型的匹配记录须对应唯一有效的上游模型 ID，候选中的 ID 只读。缺少匹配或匹配到多个不同 ID 的模型不列入候选。已添加和有冲突的候选不可勾选。在「维护模型」旁显示资料来源。列表包括勾选框、模型展示名称／模型编码、上游模型 ID 和状态。「维护模型」在新页签打开当前服务商的供应模型，维护资料后可在抽屉中载入最新数据或重新打开抽屉。按名称、编码、类型或上游模型 ID 搜索，可切换「仅看已选」。翻页和搜索保留勾选，每批最多 50 款。核对采购范围后整批校验并保存，失败保留勾选。保存成功后返回当前模型列表，新模型进入待验证状态。「获取模型列表」抽屉先说明上游接口要求和「手动添加」的入口，并展示模型列表协议、服务地址（Base URL）和可复制的完整请求地址。上游模型列表提供搜索、多选和全选，表中展示上游模型调用标识。列表右上角提供「模拟数据」和获取按钮，首次显示「获取模型列表」，已有结果时显示「更新模型列表」。模拟预览独立于连接数据，退出后恢复原列表、搜索和勾选。底部提供关闭和配置所选模型，模型资料及采购范围在配置时核对。新建连接先选择「连接类型」，默认「第三方模型服务」，也可选择「内置模型推理服务」。第三方连接的「上游接口」依次展示服务商、接口格式、接口端点与服务地址。服务商列表在基础资料中维护，接口格式带出只读端点和完整请求地址。服务商和接口格式选定后，连接名称默认按「服务商 - 接口格式」生成，手动改名后保留用户输入。第三方连接须填写 1–5 把上游 API 密钥，每个非空行计一把。内置连接单选一个就绪且所属部署存在运行中服务端点的模型实例。服务商固定为「内置模型推理」。接口格式、接口端点和服务地址从所选实例对应的部署端点带出，和服务商一起只读展示。「连接信息」只填写连接名称和简介，简介选填。提交只创建一条连接，保存时自动生成连接 ID，新连接显示「待验证」。简介与连接配置一同保存。「编辑信息」维护连接名称、连接类型、接口格式、接口端点、服务地址和简介。基本信息的「上游 API 密钥」显示当前连接已绑定的数量，无绑定时显示 0 把。点击在当前详情切换到「上游 API 密钥池」页签。待验证的密钥配置从「上游 API 密钥池」继续处理。返回总表保留搜索、分页和滚动位置，测试、凭证、采购范围及删除校验沿用现有规则。

「模型接入」的「新建连接」弹窗最大宽度为 720 px，窄屏按视口收窄。单条创建成功后可在当前页签查看新连接。批量创建完成后可逐条在新页签打开连接。进入所选模型配置后返回，恢复原连接和已选模型。「添加上游 API 密钥」复用该弹窗布局，只填写当前服务商的 API 密钥。每行一把，可粘贴多行并一次保存。第三方连接的新建弹窗和密钥池添加弹窗在密钥输入框旁持续显示「最多 5 把」。服务商共享密钥池的总上限为 5 把，连接专属密钥独立计数且最多 5 把。超过相应额度时提示并整批拒绝保存。

「模型接入」详情的「上游 API 密钥池」按当前连接所属服务商展示共享密钥。列表首列为「密钥 ID」，可复制完整 ID。工具栏提供「添加上游 API 密钥」，行内提供「删除」。绑定连接数量可展开查看并打开对应连接。保存后仅展示脱敏值，删除确认显示密钥 ID 及影响范围，确认后使受影响的验证失效。已有连接候选从「基本信息 → 编辑信息 → 核对待验证配置」继续。

- 连接详情的「基本信息」维护共享连接，「模型列表」维护上游模型关联并提供测试，「模型成本」维护采购价，「上游 API 密钥池」维护接入凭证。容量从模型列表的行操作进入。连接名称、连接 ID 和上游模型 ID 各自定位对应对象。
- 第三方连接的创建与添加上游模型分开保存，可通过「获取模型列表」或「手动添加」接入。内置连接创建时接入所选实例对应的模型。新连接待验证，当前配置通过模型调用测试并满足可用条件后自动可用。
- 连接的地址、接口或凭证变更使用候选验证并明确应用。查看影响时按实际共享引用计算，保留未涉及的连接、价格及历史；失败后继续使用原有效配置。
- 删除连接或上游模型前核对模型服务与路由引用。删除单个上游模型时，关联检查和风险确认均显示模型展示名称、上游模型 ID 及所属连接。点击「确认删除」才提交删除，取消则保留该模型。删除上游模型保留连接和供应登记，删除连接保留供应登记。审计与历史价格继续可查。
- 模型资料、服务商资料和供应关系使用各自的表格模板导入。
- 请求地址使用完整 HTTP/HTTPS URL，保留当前第三方 HTTPS/自有 HTTP(S)、禁止嵌入凭证及不允许的查询/片段校验；不将裸域名或基础 `/v1` 冒充模型接口，不重复拼接路径。已配置的多协议地址保持独立测试结果，次协议通过不能替代主地址健康。
- 相同接口、凭证与上游 ID 不能靠不同名称/来源标签重复创建。旧无 ID 关联稳定读取，不回填/丢弃记录；编辑某连接不能误删其他连接。调用配置变化使相关验证失效，单纯名称/成本变更不误清验证；共享影响须确认。
- 停用、删除或解除先检查服务及已发布路由引用，提示真实影响；全局停用与当前路由摘除分开。保存连接不自动改服务映射、售价、路由或上架。旧报价、密钥、价格历史和审计保留。
- 默认样例与官方参考资料不证明真实供应关系、可用性或价格。已有记录不为凑数量重置；显式加载参考目录只补缺失记录，保留自定义资料与已关联模型。一次性案例删除/修改后不自动复活，历史本地授权不能再次用于改写用户浏览器。

### 基础资料与供应登记

- 「基础资料 → 服务商」管理主体。服务商详情在「供应模型」添加已有模型资料、批量导入并添加及维护供应配置，在「基础资料」编辑主体。自定义服务商可从列表删除，保留现存连接和历史及其维护入口。内置服务商「移动云 MoMA」不可删除。仅登记供给不创建连接或启用模型，旧存档保留各自的配置与历史。
- 模型资料的名称与编辑入口共用同一个详情抽屉，查看态默认显示模型资料，可切换「供应服务商」反查服务商并添加供应关系，宽度最多 1200px，并适配窄屏。以入口中心位置判断方向：左半屏入口从右侧展开，右半屏入口从左侧展开；切换查看/编辑保留抽屉方向。两态的字段、分组、顺序及单元格位置一致，查看用文本，编辑用控件；视觉任务类型、资料来源两态均展示，模型编码保持只读，内部资料 ID 不占业务界面。查看态右上角为编辑，编辑态底部固定取消和保存；取消未保存修改需确认，保存沿用资料影响核对，成功后回到当前资料查看态。表格筛选及滚动保留，关闭后焦点回入口。
- 从模型详情的「供应服务商」可进入对应服务商资料。服务商资料列表复用后台筛选、列表和分页，列出名称、编码、Logo、供给类型和供应模型数，行操作为「编辑」。点击名称或模型数进入独立详情页，默认显示「供应模型」，第二个页签为「基础资料」。基础资料统一在模型资料新增和编辑，维护主体字段、Logo、简介、官网、文档链接、联系人、联系方式和备注。
- 服务商详情列出供应模型名称、规范标识、类型和连接数。模型详情反向列出服务商名称、编码、Logo 和供给类型。两侧按稳定主档 ID 读取同一供应登记。删除供应模型直接确认，保存后从当前服务商的手动添加候选中移除。已经保存的上游模型、关联、路由和报价沿用原记录。
- 批量导入支持单独建模型或服务商主档、带入当前服务商批量导入并添加、用服务商编码和模型编码导入供给关系。逐行预览有效、已有、重复和问题记录，确认跳过问题后分批提交，结果支持下载问题行和单独重试提交失败的行。主档先保存，关系随后登记；关联失败保留主档。重试核对当前资料及关系，已有记录不覆盖。
- 模型资料查看和编辑按基本信息、模态与任务、能力与限制、调用参数、技术与来源组织；名称、模型编码、模型类型必填，未知能力保持缺失，不能补成不支持或零。支持参数与默认参数分别保存；默认参数须为 JSON 对象且仅包含已声明支持的参数。原厂发布日期与平台收录时间分开，月精度日期保留。服务模型卡片继续仅展示八个字段。前端使用中文标签及说明，数据库模型文档使用 `name`、`canonical_slug`、`description`、`context_length`、`architecture`、`supported_parameters`、`default_parameters`、`supported_voices`、`knowledge_cutoff`、`expiration_date`、`hugging_face_id` 等英文属性。模型调用标识、模型编码、上游模型调用标识、内部记录 ID 各司其职，不按名称猜测关联。
- 批量导入模型资料只提供表格上传，支持 XLSX、UTF-8 CSV，单文件最多 10 MB、每批最多 500 条；不提供粘贴入口。下载模板为 XLSX，前三列必填项使用红色表头并注明“必填”，第四列视觉任务类型使用橙色表头并注明“视觉模型必填”，其余为选填；冻结首行和前三列，附“填写说明”工作表，表头文字标记可直接导入。模板与资料表单共用字段描述，覆盖基本信息、模态与任务、调用能力、支持参数、技术与来源及各类型专属规格。必填名称、模型编码、模型类型；视觉类型另填图像或视频，其他未知资料留空。可删去可选列或调整顺序，重复/未知表头拒绝；空行不改变原文件行号。填写提示常驻展开，使用清晰分行和 14px 正文。选文件后自动校验并进入预览。支持逐行查看全部已填字段、下载校验清单、筛选和明确跳过问题行、重新上传。重复和已存在记录纳入问题筛选及下载。校验与资料保存复用类型、日期、数值、默认参数依赖及重复身份规则；不适用字段拒绝而非丢弃。常规模型导入仅创建模型资料，不覆盖已有标识。服务商下钻页的「批量导入并登记」使用同一模板和当前服务商，按模型编码复用一致的主档，资料冲突标为待修正，分步保存主档和供给。
- 模型资料列表首列表头为「模型资料名称」，按名称搜索与打开详情。Logo 列标题为「模型 Logo」，以 28px 等比展示档案的图标，不再展示资料状态。未填写或图片加载失败显示“—”，不补造图标；底层资料状态和其他资料保留。其余字段、排序、分页和编辑/删除保护保持。
- 内置目录由 src/data/builtin-model-catalogue.json 定义本次指定的 17 个国产模型。新工作区初始化；已有 D1 通过明确的管理员命令增量安装，每批最多 5 个。仅新增缺失主档，或更新与旧初始配置业务字段完全一致的默认名称、类型和日期；忽略初始化时间差异，任何其他修改和草稿均保留。明确 existingId 或唯一完整编码匹配，不按相似名称合并。安装记录与用户修改分开，重复安装不恢复已删除记录；已有库通过管理员显式清理命令原子保存目录归档 ID，不替换模型、服务商、连接、密钥或价格集合；不补造能力、采购价、凭证或上游标识。
- 供应模型详情维护服务商声明的参数、默认值、范围、必填及组合限制，能力明确支持、不支持或未确认；声明不替代统一主档或连接验证。复制创建须选择目标服务商与主档，只复制声明，不复制连接、密钥、测试、服务或路由；不能覆盖已有供应关系，重新登记保留该关系原有历史。
- 刊例价独立属于服务商×模型×连接，维护计费项、适用条件、单位、币种、生效/到期时间及不可变发布版本。零价与缺价分开，已发布版本保留；新版本到期不恢复被替代旧价。刊例价发布不修改连接采购价、客户售价和历史成本，也不修改其他连接刊例价。旧模型级刊例价历史保留查阅，不自动复制到连接。

## 密钥与维护

- 密钥库与租户 API Key 独立。只保存掩码、SHA-256 去重指纹及引用元数据，明文不进入草稿、存储、审计、日志或产物；不宣称已接服务端凭证库。
- 上游 API 密钥池展示当前绑定连接，页签的操作为添加、删除。连接详情保留绑定数量与历史配置引用。
- 连接状态按当前配置的模型调用测试、凭证、服务商和保护状态判定。冻结和密钥池暂停期间，连接不可用于调用。需要复测的连接须用当前配置重新通过模型调用测试。逐上游模型、逐密钥检测，结果展示时间、HTTP 状态、耗时和失败原因，支持确认、取消和重试。需要重新验证的模型证据有效期为 24 小时。密钥探测记录诊断结果，模型调用测试保存验证结果，本地结果标识「模拟检测」。
- 已有连接候选通过「核对待验证配置」测试和应用，候选流程沿用原验证与引用校验。
- 密钥按实际连接引用聚合，长 ID 可换行；没有密钥不伪造占位记录，不把未关联旧连接作为整个模型目录的错误。添加/替换不回显原文，沿用可见 ASCII、长度、重复和数量校验，保存只提交脱敏信息。
- 删除上游 API 密钥按实际引用范围确认影响并处理验证失效。历史撤销标记及审计保留，已撤销的密钥不可选用或通过回滚恢复。详见[现行接入与维护规格](MODEL_ONBOARDING_SPEC.md#当前接入与维护)。
- 连接配置只选择服务商密钥组并显示可用数量、主要密钥脱敏值及状态。「管理密钥池」进入服务商 API 密钥池并定位所选组，离开前沿用未保存保护，已有连接可返回配置。连接专属密钥随连接提交。连接配置与测试不再内联添加共享密钥。测试切换密钥组仅作用本次检查，明确修改连接配置才持久化；测试结果单一呈现，接口不匹配优先于旧通过记录。测试/调用明确提示用量确认，保留取消、重试和失败恢复。
- 地址和 Key 维护先保存候选并测试，通过后仍需明确应用；失败保留当前配置。历史恢复入口共用固定范围和有效性校验，不保留绕过检查的旧结果直达路径；不因测试成功自动启用、改路由或上架。

- 已开启上下文长度路由的存量配置继续参与连接检查，保留已保存的 Tokenizer 和连接上下文长度。

- 模型服务、服务状态、路由策略和连接配置保存在 5.12.0 共享工作区。已登记的上游模型按接入记录引用。没有通过检查的登记连接时，添加弹窗提供三条标明「模拟连接」的练习选项，用于演练优先级、权重及启停。场景数据由用户选择后随服务保存，已有模拟关联可继续维护。已有配置随记录保留，真实服务地址及调度需网关集成。

- 超时或结果未知先核对同一操作结果再重试；冲突显示差异并保留输入，不自动覆盖。刷新恢复已保存安全内容并重查依赖，不承诺恢复未保存输入或明文 Key。
- 操作成功后持续显示真实对象、版本和生效时间，不只使用短暂通知。不可执行时说明具体缺项或权限原因，原型不伪造成功。

- 从「模型部署 → 部署模型 → 模型库」打开模型库，可按名称和类别查找。名称查找忽略分隔符，按完整匹配、连续匹配与词边界计算相关度，多关键词结果剔除低相关项。无查询按目录顺序值与发布日期展示。卡片显示图标、发布日期、许可证、能力和参数规模。打开部署或切换集群时，先按所选集群的 GPU 筛选规格，每个模式保留目录中的首条兼容规格。默认按吞吐、低延迟、标准及其他模式的顺序选择，其他模式按名称排序。来源只列出保留的规格所支持的选项。切换模式或来源带入所选规格的后端版本或容器镜像、参数与环境变量。手动选择节点和 GPU 后按实际调度规则校验。目标集群没有兼容规格时清空规格及其派生配置，提示缺少兼容 GPU 并拦截提交。用户仍可切换集群恢复兼容配置。「浏览更多模型」进入仓库选择。从卡片或「浏览更多模型」打开后取消，恢复原筛选、已加载页数和滚动位置，焦点回到打开表单的按钮。平台管理员可切换内嵌、URL 和 YAML 来源，官方 URL 与自定义 URL 分别配置更新间隔。下载的官方文件采用 GPUStack 随版本提供的原始 YAML。应用来源与目录内容在同一次写入中保存。未保存的来源地址不能手动更新，读取不到地址对应的内容时保留当前目录。重复检查无变化时保留上次更新时间。新增部署须明确关联已登记模型，匹配稳定编号或唯一精确模型编码时预选。
- 「模型部署」提供「模型列表」和「实例列表」。实例按实例名称、集群、节点及状态筛选，显示推理后端、版本、节点、显存分配和创建时间。查看日志、发起基准测试和删除重建按实例生命周期及角色判断，批量写入前重新核对实例身份。模型表显示目标与就绪副本，支持直接修改相应角色的副本数。新增成功展开新部署。普通部署在未启用定时伸缩时可设 0 副本，保存为停止且不预留 GPU。之后明确确认启动时按 1 副本调度。详情提供概览、监控、实例、GPU 资源及配置，版本历史支持比较和回滚。部署监控按所选时间范围展示数据，支持聚合、按实例以及均值和分位数选择。端点网关记录与可确认关联的硬件观测标出来源。缺少观测显示未采集。
- 运维 Playground 从部署列表或详情进入。入口要求部署可服务、端点运行中，且启用路由仍指向该端点。选中的路由作为请求的模型标识，发送前重新校验。对话表单校验消息和参数，Enter 发送，Shift+Enter 换行，可停止生成并查看模拟用量。多模态对话支持 JPG、JPEG 和 PNG。本地嵌入表单至少填写两条文本，输出可切换图表和 JSON。重排序必填查询、文档和 Top N。请求与结果由运维原型模拟，不写入租户体验或调用计费记录。
- Playground 的嵌入和重排序支持载入样例、按行批量粘贴、增删输入、提交、停止、清空和查看请求代码。嵌入结果可以切换散点图和 JSON，重排序按返回名次排列文档，并保留未进入 Top N 的文档。提交错误定位到摘要。
- 部署表单按来源、运行方式及 GPU 调度方式联动。Hugging Face 与 ModelScope 仓库支持排序、量化筛选、分页及选择 GGUF 文件。排序和翻页保留已选仓库及文件，选取后优先使用可用的 llama.cpp。模型文件带入源节点、文件与适用后端。新增部署版本默认「自动」，提交时解析为目标集群兼容版本。vLLM 和 SGLang 可切换至自定义镜像。自定义后端须填写镜像与执行命令。切换后端清理前一后端的镜像和命令，保留手动编辑的后端参数。历史版本随已有部署配置显示。评估和提交共用名称、编码格式、唯一性和资源校验。已确认的兼容性告警展示「仍然提交」，只有明确确认当前告警才继续提交。更改配置后重新评估。YAML 逐项预览差异，覆盖需要明确确认。部署事务原子更新集群分配、部署状态和端点。描述等非重建字段保存后继续提供服务，停止、失败和删除仅释放一次，重启复用端点。删除保留历史，引用中的配置制品受保护。
- 定时伸缩与 PD 分离互斥。规则支持每天、每周、每月和 Cron，并校验开始、时长与目标副本。窗口外使用独立基线。基线为 0 且当前无规则生效时不预占 GPU。停止部署暂停定时伸缩，重新启动时恢复。启用时关闭手工副本编辑，并可查看当前或下一个窗口。页面打开时模拟定时推进，YAML 导出基线和规则。
- PD 分离对 Prefill、Decode 与 Router 提供各自的运行方式、命令、后端参数、环境变量和调度。Router 固定一副本。GPU 预留按 Prefill 和 Decode 副本及每副本卡数计算。表单按后端、目标厂商和传输模式校验，GGUF 禁用 PD。支持的后端可设置本地或共享 KV，校验模式、提供方和集群。删除共享缓存服务前检查部署与可回滚版本中的稳定 ID 引用。
- 从普通部署的模型列表或详情发起基准测试时，默认选中该模型首个就绪实例，允许手动更换。从普通实例的操作入口发起时，预选该实例。失效实例需要重新选择。PD 部署在表单中只选模型，提交根据当前部署状态确定可用 Router，测试历史记录实际使用的实例。
- 基准测试默认选中具备就绪节点的集群。可先选模型再选就绪实例，也可选能到达运行中语言模型的路由。只有一条可用路由时默认选择，保存重新检查所选路由仍能到达测试模型。从部署打开创建表单时，目标选项不会变成返回列表的筛选条件。选择目标和预设时生成默认名称，手动命名后保留填写值。命名预设锁定负载类型与负载模式，编辑历史任务仅允许修改名称和描述。固定速率允许小数，并发只允许整数。新增或改名校验名称格式，历史任务可保留原名。随机数据集预填种子并可重新生成。手工分阶段的每一阶段必须填写最大请求数或最大耗时。自动调优检查负载范围为整数、测量点至少为 2、单次预热及冷却比例均低于 100%，并要求填写已选 SLO 的阈值。无效提交打开错误所在页签。通过校验后，通过模拟观测展示逐步加压、区间细搜、终止原因和支持收敛的测点。SLO 推荐负载须通过全部设置阈值且请求成功率至少 95%。阶段结果可按执行顺序或负载排序，查看测量点的请求量、吞吐、时延、SLO 和同负载条件下的对比，分别展示出错请求和未完成请求的已知统计。测试列表可选择推荐负载、已有时延统计、成功请求速率和缓存服务。运行环境显示测试提交时能够确认的部署成员、缓存服务和设备分配。操作按状态提供停止、日志及导出。单条结果导出 YAML，批量列表导出所选列的 XLSX。
- 推理后端以名称搜索，并支持按来源筛选。卡片打开版本列表，从详情点击「添加版本」直接打开新版本编辑行。新增、内置编辑及自定义或社区编辑分别使用对应的 GPUStack YAML 字段规则和可展开的字段参考。YAML 在导入文件、离开编辑框和提交时显示解析或字段错误，提供行列和字段位置。有效导入后回到文件开头，提交失败时选中错误位置。保存后锁定名称，内置版本只读。默认版本由用户明确选择。同名受管版本与带有 -custom 后缀的自定义版本可分别选为默认版本。移除或替换版本时校验默认版本和部署引用。完整导出包含详情中的受管版本。编辑抽屉生成可复制和回写的 YAML。社区市场候选详情呈现官方说明的段落、列表、行内代码和可打开的链接，支持启用。列表删除平台社区后端时停用原记录。平台管理员可分别配置内置和社区来源。来源面板显示已载入的目录快照，重复手动同步无变化时保留原时间，最近失败单独显示。手动同步不改动已保存的更新间隔，自定义来源校验失败时保留当前生效内容。
- 推理后端 YAML 按当前模式补全块结构的键和值。输入时提供候选，也可按 Ctrl+空格打开。方向键选择，Enter 或 Tab 接收，Esc 关闭。编辑区显示行号和语法着色，可通过「格式化 YAML」或 Shift+Alt+F 整理基本缩进和键值间距。格式化保留注释、字段值与撤销能力。语法错误时保留原文并定位问题。原版新建模板中留空的环境变量和版本入口命令可导入。可从导出文件新建自定义后端，来源和启用状态按新建或编辑操作确定。
- 推理后端版本列表按框架筛选，选中无匹配版本的框架时显示空态。版本可在折叠状态移除。移除所选默认版本后清空选择，自定义后端保留至少一个版本。保存仍按最新的部署引用检查版本能否移除。
- 「KV缓存」先选择提供方，再配置适用版本、调度、提供方参数和可用的 L2 后端。切换集群时保留手选版本，自动版本按新集群重新计算。仅一个可用节点时默认选中。仅支持自定义版本的提供方直接显示必填容器镜像，保存时标记为自定义。节点标签和环境变量逐项增删并校验键。启动参数按组件编辑。编辑时锁定提供方和集群。创建与重建前检查就绪节点和内存需求，已运行实例在重建完成后使用新配置。通过列表展开实例并按状态查看日志。详情依次展示概览、监控及关联模型实例。监控支持多节点、时间范围和汇总或按实例切换。关联模型实例展示已知的实际归属和指标，缺失的观测显示为空。
- 缓存节点标签根据所选集群提示键和值。新建时无匹配的就绪节点会拒绝提交。已知的设备镜像不兼容、物理内存或可用内存不足会提示受影响的节点。创建时容量预警可正常确认，编辑时只有调度相关配置发生变化且预检有警告才显示「仍然提交」。
- 模型文件按来源路径、解析路径和节点查找。列表显示平台和仓库，存储路径可复制，分片可展开查看。远程来源先选择仓库，搜索结果可排序、按量化格式筛选和翻页。GGUF 文件可按大小和名称排序，排序保留已选文件。目标节点标记已有文件，目录冲突在校验时另行提示。目标集群和节点需处于就绪状态。可指定本地目录，本地来源登记节点上的绝对路径。校验同节点同来源和目录冲突。按稳定文件引用检查删除条件，批量删除默认不勾选磁盘清理。
- 模型文件的「部署」在当前列表上打开抽屉。锁定文件来源和远程仓库，GGUF 显示所选文件名，本地文件路径可编辑。预填名称、所在集群和节点，集群未就绪时仍可查看来源预填信息，保存置灰。推理后端默认选择可用的 vLLM，版本默认「自动」，提交时按目标资源解析。关联已登记模型后生成 MoMA 部署编码。选择 vLLM 或 SGLang 可从版本切换至自定义镜像，选择自定义后端须同时填写镜像和执行命令。调度在自动和手动之间切换，手动要求选择 GPU。0 副本且未启用定时伸缩时保存为停止。表单自动评估兼容性，有告警才能「仍然提交」，必填、格式和资源错误仍须修正。取消保留搜索、节点筛选、分页和滚动位置，焦点回到原行操作。有未保存的修改时先确认。保存成功后进入部署列表并展开本次创建的部署。
- 集群提供节点注册、默认集群、节点池和拓扑，可按状态排序。云集群显示节点池，批量展开和收起影响当前筛选结果。Docker 注册默认自动获取节点及外部地址，可启用覆盖并填写。节点名称与卷映射默认启用。命令预览仅包含已启用的自定义参数，必填参数缺失时定位到对应字段。成功登记节点后确认集群注册，确认失败可基于已保存的节点重试。Kubernetes 配置校验保留的部署字段，节点选择标签和云节点池标签逐行维护。拓扑匹配按填写的标签优先级，批量变更前提示覆盖范围，清除需单独选择。保存时检查正在使用的拓扑层级。新建云集群时各节点池可独立展开、编辑和移除。实例规格可搜索，操作系统镜像可选择或手填。校验失败展开相应节点池并保留其他池的输入。节点池列表显示创建时间。缩容及删除检查部署及角色实际指定的节点或 GPU。节点详情提供概览、监控、模型与实例、配置。GPU 详情提供概览、监控、模型与实例、硬件。GPU 总表与集群详情都支持按节点显示名称搜索，列表可按显存利用率排序。模型与实例按模型分组，显示已知的状态原因、角色和设备，支持打开及下载逐实例日志。节点和 GPU 监控支持相对时间和固定时段，设置固定时段时校验 5 分钟至 7 天且结束时间不晚于当前。展示所选范围内的历史采样与采样步长。刷新保留固定时段，读取失败时保留已读取的历史点。
- 集群和部署沿用工作区事务及稳定地址。目录同步、仓库搜索和文件下载、授权云资源、节点注册、调度、压测、日志及监控采用原型数据。配置密钥由凭证能力管理，部署与商业运营之间的授权、上架及计费继续按现行规则处理。见[模型部署设计](../../docs/admin-v2/MODEL-DEPLOYMENT-DESIGN-5120.md)。
- 节点和 GPU 概览提供最近资源趋势及「查看监控」。GPU 概览可预览已知关联实例，并打开完整列表。GPU 详情可切换同一节点的设备及返回所属节点，保留所选监控时段。GPU 利用率和显存实际用量缺失时显示为空，显存分配单独展示。

路由及映射不提供“查看调用示例”，模型服务不提供“调用指南”入口。普通服务在「路由及映射」表内选择合格连接，经核对和确认后建立映射并发布路由。

路由策略、参与连接及权重默认只读。编辑态提供「取消」和「核对配置」，核对态提供「返回修改」和「确认保存并生效」。取消放弃本次草稿。保存经现有权限、并发和策略校验后生效并返回只读，失败保留输入。

现行模型服务列表、详情及组内路由见[模型服务与调用路由](#模型服务与调用路由)。

现行列表和详情使用[模型售卖](#连接成本与模型售价)，按模型服务 ID 读取已保存的价格。

工作区不显示配置检查提示块；页头保留既有配置状态，接入任务继续入口保留。既有客户范围保留，调用验证从启用或上架检查进入。连接列表不常驻“可用”标签；供给检查结果及原因放入连接详情。连接详情提供明确的打开入口并保留当前对象上下文；保留详情字段、权限及原有操作确认，Esc/关闭后焦点回到对应按钮。连接表展示上游模型调用标识，模型调用标识由对应服务统一展示。Radix 表单代理控件不重复绘制。

模型服务列表提供实际模型 ID、API 路径、协议与完整端点的核对和复制，不再提供后台调用示例编辑页签。

## 模型运营维护交互

- 模型资料基础字段默认展开，高级模态任务、能力、参数和来源分组收起；查看编辑用同一类型名称与上下文单位。编辑共享卡片前提示影响服务。
- 从连接详情批量添加模型时，保存只新增所选上游模型关联，保留共享地址、密钥及其他模型成本。
- 连接或映射被生效路由、草稿引用时禁止解除关联。引用检查继续使用原业务数据。
- 模型 ID 在新建时设置，之后只读。删除服务使用[模型服务与调用路由](#模型服务与调用路由)的检查流程。
- 字典中文名和单位优先，英文与内部标识为辅助。操作记录支持搜索、类型筛选和安全的旧新值摘要；旧记录无快照时明确缺失，不回填虚构值，不展示凭证。

## 连接成本与模型售价

- 模型售卖从模型服务列表按模型服务 ID 一对一展示服务。新建模型服务自动出现在列表中，尚无售卖配置时显示「未开售」和刊例价「待配置」，可直接点「配置模型刊例价」。已有售卖配置沿用原状态、销售范围和刊例价版本。
- 首次成功发布刊例价时，一次保存售卖记录和刊例价 v1。此前列表展示、查看详情和预览属只读，删除检查以实际已保存的售卖配置为依据。每个模型服务 ID 最多保存一条售卖。
- 模型售卖列表按模型服务名称、模型服务 ID 和模型 ID 搜索，按服务和售卖状态筛选。筛选和分页写入 URL，详情面包屑返回时沿用原条件。卡片展示只决定前台入口和范围，模型服务可以在配置卡片前发布刊例价，并在满足开售条件后开售。

- 连接详情的「模型成本」按模型行展示采购价，提供单条「成本设置」和批量设置。单条发布预览对照当前价及拟发布价。计费项、适用条件、金额、币种、单位和生效时间分别保存，保留采购版本。显式零价与缺价分开，改价不追算历史请求。失败保留输入，提交前复核权限、范围及共用工作区修订。
- 成本、售价、连接和资料通过同一 D1 读写边界；直接 URL、刷新、权限、冲突及失败输入保护与原模块一致。新增对象不因缺价落入另一套本地存储。
- 连接详情的「模型列表」按模型行展示容量，并通过「容量设置」维护。容量只展示已配置指标：零项显示「未配置」，一至两项直接显示数值和单位，超过两项显示前两项及「更多 N 项」，浮层只列剩余指标。「容量设置」独立放在连接操作中。缺失值不代表零或无限。容量设置使用 960 px 抽屉，分别维护 RPM、TPM，并按需添加并发上限、RPD、TPD、RPS、输入 TPM、输出 TPM、IPM；TPM、输入 TPM 和输出 TPM 以百万 Token/分钟展示和填写，最多 6 位小数，保存时精确换算为 Token/分钟正整数；其他指标须为正整数。容量按连接稳定关联 ID 独立保存到当前连接的 `capacityLimits`，不从同模型、同服务商或共享连接继承或联动。保存沿用 D1 事务、权限、修订冲突、失败保留输入和未保存保护；查看及取消不写入，容量变化不清除连接测试、报价或路由。这里记录上游额定限额，不代表实时剩余额度或网关限流执行。
- 模型售卖详情按模型服务 ID 定位，提供「模型刊例价配置」「销售对象」「变更记录」。历史版本保存计费项、金额、计费单位、货币及生效时间。售卖独立于卡片可见性；租户从可访问卡片订购卡片中展示的服务。服务停服与自动停售原子提交，重启后保持停售，由运营人员重新开售。
- 内部服务不要求售价且不销售；变更用途必须停服、停售并核对商业依赖。无法核对时阻断，不自动收费、退费或重写权益。
- 管理端模拟记录保留调用时来源、成本版本及计量依据；无成本待核算，内部验证无订单／订阅／销售费用；同操作 ID 重放不重复写版本、请求或费用。

- 管理端模型字段按实际归属命名：主档业务身份为「模型编码」，模型服务中客户调用参数为「模型 ID」，连接上游调用参数为「上游模型调用标识」，内部主档键为「模型档案 ID」。主档/服务/目录别名的可读名称用「模型展示名」，名称取值和归属保留；模型服务名称独立。广场与部署展示实际模型服务 callId，不使用父模型的 modelId 替代。限流目录按模型服务 ID 保存规则，显示模型服务名称和模型 ID。新操作差异按对象命名；既有审计原文、导入文件表头和数据库字段不重写。

模型运营字段、永久 ID 和模块归属统一遵守[字段与身份规范](MODEL_OPERATIONS_IDENTITIES.md)。新建及存量对象均须符合规定前缀与 UUID v4 格式。具体模型服务统一使用 model_service-UUID；旧前缀须通过专用事务同步迁移全库主键与引用，不保留公开旧号或别名。

## 后台访问控制

- 「租户管理」集中办理个人及企业开户和资料状态维护。企业详情提供「基本资料」「租户管理员」「组织及成员」「模型授权」和页头「查看项目」。系统管理员在后台企业详情查看或维护组织及成员，复用成员规则和操作记录。指定管理员及停用、启用操作从「租户管理员」页签办理。选择已有登录账号时默认列出本企业可被指定为管理员的正常成员，可按姓名或登录账号搜索全站正常账号。个人详情提供「基本资料」「模型授权」和「查看默认项目」。
- 「模型授权」展示当前租户获授的模型服务，可按名称或模型 ID 搜索并移除授权。内用企业的「授权模型服务」宽弹窗列出全部模型服务，展示服务名称、模型 ID、服务状态和授权状态。可搜索和多选服务中的未授权独立服务，点击「保存」一次追加授权。已授权和已停服的服务保留显示并禁选。历史映射记录标记「由原服务管理」。资料变更冲突或任一选择不可授权时，整批拒绝并保留弹窗输入。
- 内用的独立模型服务通过当前服务状态、可用上游、租户授权及项目权限后可在线体验或使用项目 API 密钥模拟调用。刊例价、开售、广场卡片和订单只用于对应商业流程。内用项目按已知采购成本归集，缺价待核算。
- 系统管理员可用 `#/admin-2/projects` 直接打开项目列表，按租户及项目名称或 ID 查找。企业详情的「查看项目」带入当前租户，个人详情直达默认项目。管理工作台在内用企业范围提供只读项目列表和详情，项目建立、成员管理、权限、预算、限流和密钥由具备权限的用户在用户控制台办理。运营人员从租户详情进入项目只读视图。外营的后台新建仍选择企业租户和首位项目管理员。
- 项目详情默认展示「项目概览」，提供「预算与限流」和当前项目的「API 密钥」，企业项目另有「项目成员」。项目用量（内部空间为项目成本归集）、调用日志和审计日志按权限在新浏览器页签打开，绑定当前租户及项目。后台写入拒绝内用项目变更。允许的外营项目写入验证管理员会话、租户及项目归属，审计保留实际操作者。
- 个人租户的基本资料提供 L0 至 L5 的服务等级选择，租户列表可查看等级。企业租户的基本资料展示租户名称、ID、类型、创建时间、最近更新时间、备注及已填写的扩展信息。租户项目清单显示已配置模型数；项目详情显示已记录的创建人。

管理工作台中英文切换同时作用于导航、表头、字段标签和组件语言。模型运营字段采用术语表英文列，语言切换保留标识、输入值和资源名称。
