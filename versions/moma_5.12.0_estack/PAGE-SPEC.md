# 5.12.0 页面当前约束

- 个人、企业和后台统一使用 `#/auth/login`。验证成功后按账号身份及角色进入空间或后台工作区，只有原地址在当前权限范围内时才恢复；后台所有模块共用服务端会话，不保留模块登录页或登录弹窗。401 返回统一登录并保留原路径，403 显示权限拒绝；退出及账号切换撤销旧会话。

本文件汇总本版本有效页面与业务约束。模型运营以本页导航和各模块规则为准；实际本地验证及发布边界见[实施台账](MODEL_ONBOARDING_PROGRESS.md)。历史 UX 文档不恢复已移除的入口或旧前置条件。

## 全站 Mock 数据与双面联动

- 5.12.0 初始资源、参考目录和模拟响应统一在 `src/mock/` 配置维护，私有化发布使用 Workers + D1 保存模型运营、模型目录、订购、项目配置与调用记录。本地演示使用版本内浏览器业务存储；详见 [Mock 数据合同](MOCK_DATA.md)。本节替代共享页面中“组织及成员仅保存在独立前台样例”的旧约束，仅适用于本版本。
- 系统初始数据与用户配置分开标记；恢复存档不重放初始生成器、不补回删除资源。手工记录、草稿、订单、历史与未知来源数据保留，旧无归属记录不自动认领。
- 前台 Key、订购、客户智能路由、在线体验和后台组织成员记录落到共享业务集合；客户作用域、所有者、修订冲突及存储错误在写入边界校验。后台修改相同记录后，前台经事件、同源标签页更新或聚焦复查读取新值。
- 「智能路由」提供「智能匹配」「模型预设」两个项目级页签。智能匹配首页只展示 Auto Router，企业管理员、当前项目管理员或个人本人从「路由设置」独立配置、保存和生效 `moma/auto`、`moma/performance`、`moma/cost`。「项目分流」从「智能路由」打开，绑定当前项目。预设有独立详情、编辑、API 调用和版本历史，切换历史版本须重新校验当前资格，调用 ID 保持稳定。启用的 Auto Router 和预设可从详情进入文本生成试用。智能匹配、模型预设的保存、版本、停用、试用、API 示例及调用均绑定同一项目；企业切项目切换配置并退出原项目的预设详情或编辑，个人固定唯一默认项目。各项目可独立使用相同调用 ID，API 按 Bearer 密钥所属项目解析，不接受客户端覆盖项目。项目管理员维护项目智能匹配；普通成员可查看已生效智能匹配及自己的模型预设，保留自有预设维护权，不能访问未加入项目。候选范围同时受项目模型权限、空间授权、订购及 Key 权限限制。后台读取与调用模拟使用同一项目归属和权限，路由审计记录项目 ID；保留稳定 ID、草稿、版本及调用历史。
- 从「智能路由 → 项目分流」进入。项目管理员或企业管理员可编辑，已分配项目的普通成员可查看。API Key 条件引用同项目的有效 Key ID，用户标签条件匹配 `metadata._user`。按规则顺序选取目标服务，未命中使用默认服务，备用模型服务按保存顺序尝试，最多五个。私有化发布的调用示例保留 `project@策略标识`，配置与模拟调用使用客户工作区。
- 调用日志、租户用量、平台概览及用户统计从同一请求和显式身份事件派生。未采集 Tokens、费用或时延显示未知；本地回复不构成真实上游或计费证据。图表样例继续使用静态 JSON 配置和原有派生逻辑；不写入 D1。用户侧未迁移模块仍使用浏览器存储，不与 D1 自动双写。
- 前台编辑在打开时冻结修订号，跨标签页更新不得静默覆盖当前输入；冲突保留输入并要求刷新。账号/客户切换清除旧临时表单及明文 Key，已保存筛选视图按身份隔离。关闭 Key 额度后保存/刷新保持不限，相同额度与周期重新启用保留原用量；TPM/QPM 按实际值保存和模拟校验，不豁免客户额度与权限。
- 用户面项目选择、项目管理和项目分流复用 Semi Design 的页签、操作控件、表单与浮层。窄屏表格在当前面板内滚动，关闭分流编辑前确认未保存的修改。
- 模型广场筛选、搜索、详情操作和订购确认使用 Semi Design。窄屏筛选在抽屉打开，关闭时保留筛选条件并将焦点还给入口。
- 文本生成的输入、参数与新建确认，以及体验共用的模型选择弹窗使用 Semi Design。模型选择保留供应商、类型、计费方式和可体验条件，并沿用项目调用权限。客户账单使用 Semi 表格，用户面共用分页保留原有页容量。
- 文本、图片及视频体验的推荐提示沿用 Semi 填充与文本色；文本推荐在中等宽度显示三列、窄屏显示两列，保留完整提示词填入。新建对话与账号认证的主要入口使用实色按钮。体验参数使用业务名称与必要范围，不重复展示接口字段名。用户面弹窗限制在视口内，项目名称的必填错误在表单内中文提示。订购费用与确认区排在协议之后，不遮挡表单。
- 账号菜单、登录空间选择、密码找回、邀请与个人或企业认证使用 Semi Design。认证保持字段校验、协议链接和分步提交，错误保留在原表单中。
- 密码找回与修改复用登录页的品牌区和表单容器，保留验证码、密码校验与返回路径。
- 空间总览、用量统计、调用观测与调用日志共用 Semi 筛选和视图保存。调用日志使用 Semi 表格和请求详情抽屉，保留筛选导出、详情 JSON 和既有脱敏规则。
- 用户面空列表保留记录数，零条时隐藏分页操作。订购表格按服务、订单及订阅的原始 ID 标识行，刷新不重复。项目表格铺满当前面板并在窄屏局部滚动，日志长服务标识在列表中限两行并提供完整悬停值。组织操作时间按北京时间显示。
- 图片生成、视频生成、语音识别和模型对比使用 Semi 操作控件、参数弹窗与输入框。窄屏时对比列在当前面板内横向滚动，保留同步输入、独立参数和会话权限。
- 组织及成员、批量添加和 API Key 使用 Semi 表格、筛选、表单及浮层。批量添加保留校验和结果步骤，明文 Key 仅在创建或重置成功时交接。
- 统计分类匹配实际模型类型，基础模型筛选纳入其服务商服务调用；请求保留发送时调用 ID，未知计量不填零，音频秒数/字符与 Token 分开。不使用固定样例数作为当前套餐权益或剩余额度。
- 动态历史样例只绑定固定初始资源且保留有效归属，不能因新增/编辑 Key、模型或成员而重分配历史；用户真实动作产生的请求独立保留。重复 Request ID 校验 Key、客户、模型及服务归属，冲突不返回原记录，已撤权 Key 不能重放成功。

## 前台项目管理

- 账号是登录身份，客户/租户是资源和结算主体，空间是进入该主体的控制台视图，项目固定归属一个空间。组织部门和企业成员属于企业空间；项目只引用本企业的部门及成员。同一账号可加入多个企业，也可拥有一个个人空间。多空间从账号菜单切换，单空间不显示切换入口。
- 用户控制台顶部入口为首页和模型广场。功能导航提供「账户管理」，用于查看账号资料与认证。「系统管理 → 项目管理」仅企业空间提供，「当前项目」从该入口下方切换。项目管理默认呈现「我的项目」页签，按企业列出当前账号实际加入的项目，并展示本人在每个项目里的成员角色。仅租户管理员可使用「全部项目」页签，查看当前租户的全部项目及既有部门分组。页签下方左侧是可搜索的项目树，右侧是项目详情。进入页签优先展示当前范围内的当前项目，其次展示本空间第一个可访问的正常项目。窄屏上下排列。
- 个人侧栏从首页进入默认项目概览，直接在默认项目执行体验、接入与调用及调用观测，通过使用设置维护默认项目。企业普通成员可查看授权项目，密钥维护需项目管理权。「系统管理 → 组织及成员」显示登录企业的组织树、成员及操作记录。租户管理员管理本企业，部门管理员管理授权部门内的普通成员。
- 文本、图片、视频、语音体验以及用量统计、调用观测、调用日志均为独立页面入口；模型订购与订购及账单分别进入。保留页面原有业务分类页签；模型订购的按Token用量计费、Token Plan订阅、Coding Plan订阅页签仅将展示名称改为「按量计费」「套餐订阅」「资源包」，内部计费标识、订单记录及过滤逻辑保持不变。账号认证可从「账户管理」或右上角账号菜单进入。空间切换和退出登录从右上角账号菜单进入；模型广场、模型详情和模型订购页面不再显示独立账号/退出广场状态条。
- 私有化站点依据部署授权和已保存的空间策略区分对内使用与对外运营。内用提供本企业空间及授权模型，后台入口为「本组织」，前台按项目使用模型。工厂外营开放多个政企客户及个人客户，政企开户容量与部署方式分别校验。企业内外共用组织与项目权限，部门用于项目归属及成员查找。
- 工厂工作区由企业管理员或个人客户本人按当前空间订购有效按量服务。企业订购生效后在本空间项目分配相应模型；个人默认项目直接继承已开通模型。订单归属空间，调用费用按请求归属项目，通过前后台同一组记录查询订单及用量账单。企业内用在后台按调用时项目主责部门归集成本。
- 个人注册及后台开户原子创建一个默认项目并记录 defaultProjectId，前台命令和后台事务均拒绝增加、替换、重命名、转移或独立改变默认项目状态。历史单项目记录保留原始名称及 ID，以「默认项目」显示；异常记录明确报错，不自动合并或删除。租户管理员可新建和删除本租户项目。创建人获得项目管理员角色。租户管理员和该项目的项目管理员可添加、移除和查看项目成员，并可把新增或已有成员设为「项目管理员」或「普通成员」。项目管理员退出、被移除或降级前须保留另一位有效项目管理员。普通成员在项目管理中可查看已加入项目和成员，并可切换到其他已加入项目；个人项目由本人管理。
- 企业项目详情在标题区展示项目信息，下方默认打开「项目成员」。租户管理员和该项目的项目管理员可编辑项目信息，并使用「项目预算」和「模型限流」页签。新建与编辑仅填写项目名称和描述，既有部门归属保留。具备相应权限时，详情标题区直接提供「编辑项目」「删除项目」或「退出项目」，已停用的企业项目可通过「启用项目」恢复。删除后保留项目 ID、调用、Key 关联及审计。API Key、项目分流及日志留存按当前项目使用。个人「使用设置」保留默认项目的预算、日志、限流和分流。
- 企业新项目逐个开通模型。已有项目缺少项目级配置时继承当前空间授权。项目管理员在空间授权范围内开通模型和配置每模型 RPM／TPM，限制跨项目内全部 Key 与在线体验。空间撤权即时阻断项目调用。项目路由按规则匹配或选择默认模型，备用模型也需通过项目与 Key 权限检查。
- 企业「项目预算 → 设置额度」以百万 Tokens 配置项目预算和每日批处理 Token 限额。预算周期可选永不重置、每小时、每天、每周和每月，按北京时间自然周期统计，周一开始。项目预算统计项目已成功调用的输入和输出 Token，在线体验和 API Key 共用额度，超额拒绝调用。项目 TPM 与 RPM 按最近 60 秒限制项目总量，并与模型和 Key 各自的限流同时生效。每日批处理限额可保存，待批量调用接入后执行。
- 企业首次保存 Token 额度后，项目预算按 Token 规则执行，既有人民币预算记录保留。个人使用设置沿用既有预算。按量 Key 支持独立累计人民币预算，Token Plan Key 支持独立套餐抵扣 Token 预算。所有手工 Key 可设置到期时间。未确认费用单列；无法核算受人民币硬预算约束的新调用时返回错误。套餐购买费用归订购空间。
- Key 在指定项目创建、编辑、启用、停用、重置和删除。用户控制台「API 密钥 → 订阅套餐」按项目 ID 与订阅 ID 独立管理每份订阅的密钥，同名套餐不合并；模型选项取项目和本套餐允许范围的交集。编辑、重置、删除不得改变其他订阅的密钥，不得把已有密钥转入另一订阅或按量范围。创建与重置的密钥只在一次性交接弹窗显示，关闭即清除。列表显示掩码，历史和操作记录保留稳定 Key ID。托管体验 Key 按项目自动使用，隐藏明文和维护操作。
- 模型广场详情点「在线体验」先校验当前空间订购或授权，再使用当前可访问项目；唯一项目自动进入，多项目未选择时弹窗选择。企业空间未订购时管理员可订购，普通成员提示联系企业管理员；内用缺少授权提示管理员。项目未分配模型时项目管理员通过「配置模型权限」授权，普通成员提示联系项目管理员。个人绑定默认项目。模型详情、文本、图片、视频、语音及模型对比发送时绑定项目。配置、调用资格、订单及会话由各自写入边界校验。留存开关默认仅保存日志元数据，开启后新请求可保存脱敏输入输出，仅项目管理员查看，CSV 不含正文。对话历史沿用账号访问规则。
- 个人默认项目概览按北京时间展示请求数、Token、费用和成功率及上期同进度对比。单日按 10 分钟、多日按天显示请求与费用趋势；模型与 API Key 按调用费用或请求数展示 Top 5。配置摘要直达预算、模型权限、项目分流及 Key；用量、日志及请求详情保留项目范围。

## 前台用量统计

- 从「调用观测 → 用量统计」进入，默认打开「概览」。项目入口的热力图、用量分析及导出使用同一项目范围。顶部提供语言、多模态理解、视觉、语音、向量、排序六类模型页签。概览在筛选上方展示近 365 个北京时间自然日的 Token 用量活动。按日每格一天，按周每格一周（周一为起点，首尾按区间截取），累计每格为从区间起点至当天的累计。零值和无计量分别标识。
- 下方「用量分析」首层显示时间、计费方式和项目，筛选仅影响用量分析区。「更多筛选」的调用方组包括 API Key 和调用用户，模型页签增加模型范围组。已选条件持续显示实际日期和生效的细筛条件。项目和计费方式约束 Key，项目、计费方式及 Key 约束已记录的调用用户。政企管理员可筛选调用用户，未记录调用人归入「未识别用户」。变更上级条件会清除失效的下级条件，切换日期保留查询对象。保存视图保留页签和有效筛选。
- 概览指标包括调用次数、调用模型数、调用成功次数及成功率、调用失败次数、已计量 Token、平均每次 Token 和调用费用。桌面宽度允许时排成一行，数量达到 1 万或 1 亿时按对应中文单位缩写，悬停显示原值。Token Plan 显示已记录的套餐抵扣。平均每次 Token 仅以有 Token 计量的调用为分母。订购模型数取当前空间有效订单中关联的模型，按模型去重，说明中展示模型类别分布。
- 概览的用量分析并列展示 Token 构成和已订购模型用量占比，下一行展示单模型用量趋势。模型占比及趋势只统计当前有效订购模型在所选范围的已计量 Token，前五单列、其余合并。趋势单日按小时、多日按天，自定义日期最多 31 天。
- 概览底部展示模型、项目、API Key 三个榜单。三榜共用排序指标，默认按调用次数排序，费用按同一币种比较，各用量榜仅统计有相应计量的调用。切换排序只更新榜单。点模型进入对应页签并选中该模型，点项目或 Key 在概览收窄范围。类别未知的调用仍计入概览调用次数。
- 模型页签保留汇总条、双列趋势和右侧图表导航。选定模型 ID 后展示适用的 Token 构成，采集到上游缓存命中量时展示 Prompt 缓存分析。命中率以同一批请求的输入 Token 为分母，命中 Token 计入输入。语言和多模态理解统计输入、输出及适用的缓存分项，向量和排序只展示有计量的输入 Token。视觉分开显示图片张数、视频时长及已计量 Token，语音识别时长与合成字符数分别统计。
- 年度活动和用量分析复用同一请求去重和 Token 计量规则，分别按各自范围统计。用量分析基础时间桶为北京时间单日 10 分钟、多日按天，含今日时统计至快照时间。CSV 导出当前页签的筛选范围，概览导出按各模型的实际类别标记。仅在本地开发链接 `?page=usage-statistics&usageDemo=1` 使用独立模拟请求。

## 模型运营云端持久化

「模型服务」的列表、详情和变更共用现网 D1。平台管理员和运营人员可逐条导入当前浏览器保存的记录，沿用服务 ID、配置、创建人和创建时间。同一 ID 重复导入不会覆盖现有配置，调用标识冲突时提示核对。

- `listing`、`providers`、`model-market`、`model-costs`、`model-prices`、`model-templates`、`tariff-dictionary` 使用 `/api/5120/`。模型资料、服务商、密钥组/池、渠道及映射、采购/售价历史、服务、路由、检测与试调用、发布和操作审计均落 D1；筛选和未提交输入保留在浏览器。
- 后端以 HttpOnly 会话确认账号及权限，复用 5.12.0 领域规则；前端提交预期修订和操作 ID。业务变更、模拟状态、回执和审计一次原子保存，成功后才关闭编辑；失败保留输入，未知提交结果先核对原操作，冲突要求载入最新数据。断网不回退为本地保存成功。
- 新 D1 初始化计费字典和参考模型主档。平台管理员在研发说明中显式导入两套模型服务演示案例及其依赖，成功后保持下架。已有工作区启动时读取原数据，导入复用同一主档，记录冲突时整包拒绝。
- 私有化发布的客户身份、渠道订单、项目 Key 和各在线体验的项目调用由 D1 校验及保存。项目配置与统计按「前台项目管理」执行。原型调用使用模拟上游。

- 租户空间、账号认证、调用日志、API Key、客户与后台账号沿用[对应共享页面章节](../../docs/PAGE-SPEC.md)；用户管理、账号管理、Token 生产等模块的保留与入口以本版本规格为准。「组织及成员」及其操作记录从用户控制台的「系统管理」进入。个人空间从项目详情查看该项目的调用日志。

## 私有化站点配置

- 运营侧栏的「访问控制」提供「租户管理」。工厂外营展示企业和个人租户列表，企业对内直接打开配置的默认企业。商业运营侧栏提供模型销售和套餐管理。企业详情提供项目用量查询。

- 「平台管理 → License 管理」以一张卡片展示授权范围和状态，运营模式、有效期与已有授权信息在下方对齐展示。页面不列功能清单。商业版显示「政企标准版 + 商业化增强」，内用版显示「政企标准版」。平台管理员通过弹窗粘贴并校验 License，缩小授权范围时需二次确认。内用版展示商业运营分组并标记未授权，禁用商业入口并拒绝商业路由和写入。商业版到期后保留历史查看，写入端拒绝新增订单、开售、售价与销售对象变更及套餐命令。已有订单以原调用权限核验。
- 商业运营侧栏展示「模型销售」「套餐管理」。售价维持统一服务按模型、渠道直选按服务的现有定价方式。经营分析按账期汇总后台已记账的出账与实收金额。

- 私有化构建通过 `VITE_MOMA_PRIVATE_SITE=1` 开启「平台管理 → 站点配置」，仅平台管理员可访问。公开部署的常规构建默认关闭。
- 「基础配置」分别维护「用户控制台展示名称」与「管理工作台展示名称」。前者用于用户控制台顶栏和共用登录品牌区，默认「模型服务平台 MoMA 政企版」。后者用于后台顶栏和概览欢迎卡，默认「Token 管理工作台」。两个名称独立保存，留空使用各自默认值。已有单一平台名称带入用户控制台展示名称。Logo、浏览器标题、Favicon 和认证插图分别配置。图片支持本地上传（单张 512 KB）、HTTP/HTTPS 链接、预览和恢复默认。
- 「协议管理」通过「用户协议」「隐私政策」切换文档，每次展示一个宽版编辑区，支持正文、HTTP/HTTPS 外部链接、草稿预览和分别恢复默认。两份协议通过「保存协议」一起发布。每份协议有可复制、无需登录的站点地址，认证及邀请沿用同一地址。公开阅读只读取已保存的服务端配置，未配置正文或链接时读取对应内置模板。
- 基础配置使用版本专属的浏览器本地存储。协议发布由系统管理员经同源接口写入原型数据存储，比较修订号，保存失败保留草稿。首次发布前可在编辑器带入当前浏览器已有的自定义协议，保存后对外生效。两类配置都以站点为范围。

## 平台审计日志

- 「平台管理 → 审计日志」仅向系统管理员开放。列表和详情使用当前后台账号的服务端会话，未登录统一跳转 `#/auth/login`，登录后按权限返回原页面。通过 `/api/v1/audit-logs` 读取已有 D1 审计事件，覆盖发布服务路由、轮换共享密钥、替换 API 密钥、批量停用所选模型渠道供给、项目管理和个人空间开关。
- 列表依次展示事件 ID、时间、操作人、操作类型、模块、IP 地址、客户端、租户、项目、结果和操作对象。按时间与事件 ID 倒序，按游标翻页。支持按时间范围、完整事件 ID、操作人、操作类型和客户端类型查询；「更多筛选」提供对象或记录 ID 搜索、操作结果、对象类型、客户和项目。默认近 7 天，自定义日期按北京时间查询。「刷新」保留已应用筛选并回到第一页。
- 列表中的操作人名称和账号 ID 各占一行，超出列宽时省略。悬停或打开审计详情可查看完整内容。
- 点击事件 ID 打开审计详情。详情保留列表中的身份与来源字段，补充原始操作 Code、操作 ID、阶段和关联验证标识。「请求证据」展示操作 ID、命令和已采集的安全参数，历史记录仅展示留存的内容。「响应证据」展示操作 ID、记录的 HTTP 状态、操作结果及可用的工作区修订号。「变更证据」展示前后值、目标、关联对象和逐项结果。「原始详情」展示接口返回的脱敏审计 JSON。各 JSON 页签支持展开、收起、复制和全屏。
- 新事件在同一业务事务的审计行保存字段摘要、安全参数和可识别的 Web 来源。租户和项目按已记录的归属展示。客户端未知时显示「未记录」，IP 地址、租户和项目缺失时显示占位。密钥明文、掩码、指纹、完整配置、内部配置地址以及完整请求和响应体排除在返回字段外。配置提交属于原型证据，网关实际生效须由独立执行回执确认。

## 流量运营

- 限流配置页使用 Semi Design 卡片、页签、表格、表单、弹窗、抽屉和反馈组件。运营区「流量运营」下提供「用户限流」「模型限流」两个页签，默认进入用户限流。平台管理员和运营人员可访问。
- 用户列表显示账号名称、账号 ID、账号类型、默认值、生效值、规则来源、一客一策条数和操作。默认值取用户全局默认，生效值取账号通用额度。两个值均包含 RPM 和 TPM。支持按账号名称或 ID 搜索，以及按账号类型筛选。通用额度可单独或批量修改、恢复全局默认，已有一客一策仍按模型匹配。筛选、切换页签和批量操作成功时清空选择。
- 全局默认在 D1 初始化为 60 请求/分钟和 300 万 Tokens/分钟，放在用户列表搜索行，Tooltip 说明继承规则。新账号和没有自定义通用额度的账号使用当前值。
- 点击账号行的一客一策条数打开右侧宽抽屉，显示账号名称和 ID，支持搜索并添加模型、修改额度和移除，统一保存。一个账号的同一模型只能配置一条额度。账号规则优先级依次为一客一策、账号自定义、全局默认。
- 账号行的「限流可视化」打开只读宽抽屉，展示通用额度以及各模型的账号侧额度、命中规则、模型共享上限和最终上限。RPM 和 TPM 分别取两侧较小的值，账号侧额度无法读取时最终上限显示「—」。
- RPM 使用请求/分钟。TPM 固定以百万 Tokens/分钟展示和输入，最多 6 位小数。组合额度在数值旁直接标注 RPM 和百万 TPM。保存时 RPM、TPM 均为正整数。
- 模型限流搜索行沿用用户限流布局，右侧维护「模型默认」，D1 初始值为 600 请求/分钟和 3,000 万 Tokens/分钟。列表展示 D1 模型资料主档的名称、标识、默认值、生效值和规则来源。模型共享上限按主档关联，由调用该模型的账号共用。单模型可覆盖默认或恢复为继承当前默认。
- 页头「变更历史」打开只读抽屉，按时间倒序展示变更时间（北京时间）、变更对象、操作、变更前、变更后和操作人。D1 记录两类默认、账号通用额度、一客一策及单模型覆盖。批量操作按实际改动的账号列出，一客一策按模型列出增改删，恢复默认显示继承关系。旧审计缺失的字段显示「未记录」。
- 两个页签使用同一个后台登录会话读写 D1 限流配置。用户列表复用稳定的登录账号 ID，模型关联复用 D1 资料主档 ID。读取失败提示登录或重试，缺失额度显示「—」。保存同时提交配置与审计，校验角色、修订号与幂等标识，失败保留输入。浏览器旧存档保留，当前生效配置以 D1 为准。当前原型范围为配置及规则解析。

## 套餐制作

- 套餐制作和套餐数据复用后台 Semi 页头、卡片、筛选和小尺寸表格。套餐制作包含「套餐列表」和「模型抵扣系数」两个页签，默认进入套餐列表。套餐在独立表单编辑，右侧为购买页预览。抵扣规则按模型分组，在弹窗编辑。离开未保存的表单时可继续编辑或放弃本次修改。
- 运营区「套餐运营」下提供「套餐制作」，平台管理员和运营人员可访问。列表以名称或套餐编号搜索，按套餐形式和状态筛选，统一分页。套餐形式为按周期订阅或一次性资源包，首次保存后只读。套餐类型可选个人版、团队版或平台管理员添加的共享类型。新建、编辑和查看为独立表单，返回保留筛选和页码，离开时保护未保存输入。
- 订阅套餐配置每周期 Token 额度、周期售价、订阅周期、总周期数和余量结转规则。资源包配置每份 Token 总额度、单价和生效后的有效天数。两类共用套餐名称、购买页展示名称、简介、顺序及每位用户累计限购份数。支持订购的用户类型可多选政企用户、个人用户，新建默认全选，发布和上架至少选一项。展示顺序可填 0 至 200 的整数，数值越小越靠前，留空排在最后。购买页预览在大号套餐名称下方显示一行简介，并展示有效期限。
- 按月、季度、年订阅分别按原生效日期加 1、3、12 个日历月推算周期边界，目标月缺少对应日期时取月末，后续仍以原生效日推算。当前套餐制作展示规则，实际订购到期时间由权益系统计算。
- 状态为草稿、待上架、已上架、已下架。新增和编辑表单的「保存」将套餐存为草稿，允许缺少发布必填项。发布从列表发起，校验通过后进入待上架，操作为编辑和上架。仅从未发布的草稿可在列表确认删除，移除后保留审计且编号不复用。上架与下架需确认。已上架套餐只读，修改下架或待上架套餐后需重新发布。下架只停止新订购，已购权益用尽或到期后结束。
- 平台管理员可删除未被套餐引用的自定义类型，删除需确认。内置类型和被任意状态套餐引用的类型不可删除，删除成功后从选项中移除并保留审计。
- 「模型抵扣系数」列表展示已添加的模型，新增选项来自「模型服务」中尚未添加的未归档模型。每个模型默认不允许加入套餐。平台管理员和运营人员可配置「允许加入套餐」、全平台共用的抵扣规则和修改说明。添加及编辑只保存草稿，发布后切换生效版本，待发布期间继续使用当前生效规则。修改历史记录发布版本、时间、操作人、变更前后规则和修改说明。
- 先选择模型，再按该模型当前生效售价中的计费项分别配置抵扣规则。没有生效计费项时提示先配置并发布模型售价。留空的计费项不生成规则，新增模型至少配置一条。切换模型时保护未保存输入。保存和发布均校验计费项归属，已有生效规则保留至新版本发布。规则使用模型主档 ID。同一计费项可不分档，或配置互不重叠的输入 Token 档位。下限不含、上限含，允许留空一端。下限留空从 0 开始，上限留空代表无上限。按单次请求的输入 Token 数判档，整笔使用命中系数。各计费项的实际用量乘以对应系数，再相加得到套餐扣减额度。系数须大于 0、最多两位小数。
- 套餐制作的「支持模型」支持搜索和多选已发布、允许加入套餐且有生效规则的模型。选中后展示当前计费项、档位和系数，套餐只保存模型关联。暂无可选模型时提供模型抵扣系数页签入口。发布和上架至少选一个符合条件的模型。模型仍被套餐引用时，发布规则须保留允许状态和至少一条规则，服务不可归档。被草稿或生效规则引用的计费项不可删除。原模型级系数作为历史值保留。
- 使用说明和使用范围是独立的可选文本，各最多 500 字符。套餐配置、共享类型、操作回执及审计通过 5.12.0 的 D1 接口保存。原浏览器套餐记录保留在原存档。

## 套餐数据

- 运营区「套餐运营」下的「套餐数据」提供一张套餐汇总表。默认全部套餐，支持筛选订阅套餐或资源包。每款套餐一行，依次展示套餐名称、资费ID、新增销售数、累计到期数、额度消耗率（平均值）。资费ID使用现有套餐编号。新增销售数统计所选期间售出的份数，累计到期数统计截至结束日已到期的份数。额度消耗率对当前范围内明细所列且截至结束日已生效的权益，逐份计算累计消耗量除以套餐额度，再取算术平均。无可计算权益显示「—」。已下架套餐仍可查看。筛选沿用[运营时间与事实](#运营时间与事实)的北京时间口径。

- 套餐列表读取 D1，缺失的真实经营数据和权益明细显示「待接入」。独立演示视图按北京时间映射样例日期，超出覆盖范围显示「无演示数据」。演示统计与 D1 套餐及用户侧订购、扣减和权益分开。

## 模型身份与资料

- 「模型资料」下的「模型作者」与「模型系列」均和「模型」同级。各自维护标准名称、别名和启停状态，系列关联所属作者。存量文本按作者与系列的现有取值初始化，同名或已登记别名精确归类，无法匹配的原值保留为待核对。改名沿用原引用，停用后原有资料继续展示。字典变更沿用模型运营工作区的角色、修订和审计。
- 模型资料表格在作者后展示模型系列、模型版本，支持按作者和系列筛选。「批量导入模型资料」在「模型」页签的筛选区右侧。资料表单选择作者后再选其系列，系列可留空。从资料表单可在新页签打开作者或系列维护，载入最新数据后保留当前表单输入。批量导入沿用模型编码及原表头，预览展示已匹配的标准分类，未匹配或系列归属错误按行标明。服务商接入选择现有模型资料时可核对模型编码和版本，渠道分别记录各自的上游模型调用标识。用户侧模型广场按同一分类筛选已可见模型。

- 术语由 [GLOSSARY](GLOSSARY.md)定义：模型资料、供应关系和销售服务各有职责，资料 ID/模型编码/上游模型调用标识/模型调用标识 不混用，模型作者不等于服务商；采购参考价、采购价和平台售价分开。完整 URL 称请求地址，Key 按当前绑定渠道表达。
- 模型资料提供参考内容，最终展示信息由模型广场维护。按稳定 ID、显式关联或精确编码识别模型，不按名称近似合并版本。四模块的永久 ID 展示、字段归属及批量导入导出遵守[身份与导入契约](MODEL_OPERATIONS_IDENTITIES.md)，复用存量 ID，不改写已有引用。
- 六类主要用途为语言模型、视觉理解、视觉生成、语音模型、向量模型、重排模型；语言模型可支持图像/视频输入，不能仅因名称含 VL 或具备图像能力改类。既有类型代码、图像/视频任务及计量单位保留。输入/输出模态与向量/相关性等结果类型区分，未知能力/规格保持未填写。
- 资料库保留表格、查看、编辑及删除入口；长内容提供完整值的可访问查看方式，宽度不足时在表格区域滚动。资料列表名称/编码、作者、正式发布日期、类型、适用场景、模态及上下文各有语义；日期来自可核对官方首次发布记录，场景不替换为支持任务。维护分页 20/50/100、默认 20，选择流程保留自己的容量；切换容量只提交一次容量和第一页。
- 基础资料库的共享主档编辑按用途分区：模型卡片维护名称、Logo、类型、输入/输出模态、结果类型、上下文与模型描述；模型详情维护作者、适用场景、支持语言、任务、资料链接、详细介绍及按类型展示的能力规格；模型编码、系列、版本与发布日期在“其他信息”，技术与接口属性独立展开。广场公共展示内容按模型 ID 维护一次，模型资料更新不覆盖已保存的广场内容。售价在独立模型售价维护；模式、关联和模型调用标识 在路由及映射维护；既有模型级客户范围保留并继续参与经营检查。
- 前台卡片和详情读取同一份已生效资料：Logo 缺失或存储内容不合法时使用默认图标，图片加载失败时名称仍可读；详情复用卡片公共信息，并显示已填写的长介绍、模型编码、版本/发布日期、能力规格、技术接口属性及资料链接。未知属性不补零或“支持”，正式发布日期与卡片的资料更新时间分开；不把采购价、供应密钥、内部请求地址和资料核对记录投影给客户。点击卡片进入独立详情页，按面包屑、模型介绍与三项参数、服务商报价、API 调用、详细资料组织；返回广场保留当前筛选并恢复原卡片焦点。URL 保留稳定模型与服务 ID，支持刷新和浏览器前进/后退；失效或无权访问时显示不可用，不自动替换为其他服务。
- 渠道直选模式详情每条已上架且对客户可见的渠道服务一行，显示服务商和来源名称。展开可查看已发布计费项、独立模型调用名，按所选渠道订购或在线调用。统一模型服务模式只有一个平台服务入口。登录、订购状态和调用由 D1 校验；调用区按所选服务同步模型调用名。
- 前台模型广场按稳定模型 ID 聚合 D1 的有效上架服务，一款模型一张卡片。按发布日期排序，服务商筛选按服务商 ID 去重并匹配卡片内各服务。渠道直选模式详情可选择渠道服务，售价、调用 ID、订单和在线调用使用同一服务身份；统一模型服务模式使用平台统一售价和调用 ID。当前路由缺少有效采购价或售价时，对应服务暂不出现在广场，D1 拒绝新订购并保留上架配置及历史。售价仅取平台已发布销售快照，明确币种/计量单位，未提交输入、采购价和内部渠道不对客展示。每条调用记录保留当时的渠道、路由和售价引用。
- 主档名称、介绍、图标等在当前表单编辑，预览受影响服务并明确提交后同步引用展示；不因展示文字修改重测连接。类型、能力、模态、任务、版本及深度思考/结构化能力变更走专门影响检查，重验受影响范围；不兼容依赖先修复或明确下架，合格后发布，不直接覆盖在线配置。仅属性顺序变化不误判，稳定身份、权限、修订、存储和焦点保护保留。
- 模型运营初始数据集中于 [Mock 配置](MODEL_OPERATIONS_MOCK_DATA.md)，基础资料、供应管理、模型服务共用稳定引用与目录范围，前台读取后台生效服务。只在没有存档时初始化；已有用户配置、删除记录、凭证、草稿与历史不因刷新或配置更新被补回或覆盖。
- 删除主档须没有供应、服务或活动配置引用，界面禁用与事务校验一致。添加供应模型从主档选择，可原地新增主档并返回选中，不自动登记供应关系或渠道。批量只接受匹配主档的模型，不接受任意未匹配上游 ID，不生成空渠道。
- 对外服务正式资料沿用其现有完整校验；技术接入可以先保存最低身份资料，任务/能力缺失保持待完善，不能据此启用技术服务或上架。资料与服务编码规则的已知差异见 [MODEL_OPERATIONS_TERMS_REVIEW](MODEL_OPERATIONS_TERMS_REVIEW.md)，不靠改名宣称差异已修复。XLSX/CSV 前两列统一模型编码/模型资料名称，不增加旧表头别名。

## 渠道管理

「渠道管理」的「添加新的渠道」弹窗最大宽度为 720 px，窄屏按视口收窄。 单条创建成功后可在当前页签查看新连接。批量创建完成后可逐条在新页签打开连接。进入所选模型配置后返回，恢复原连接和已选模型。该入口的「添加 API 密钥」弹窗只填写密钥。

两个新版入口的渠道详情分别提供「服务商 API 密钥池」页签。页签按当前连接所属服务商读取密钥组和凭证，优先打开当前连接绑定的组。支持新建组、添加密钥、调整优先级、测试连接、替换以及原有启停与撤销操作。选择「当前绑定渠道」可在同一入口打开对应连接。密钥保存后仅展示脱敏值。连接编辑的「密钥管理」用于设置单个连接的凭证来源。

「渠道管理（new）」为独立入口 `providers-reference`，与另外两套渠道管理共用数据。总表按渠道名称搜索，逐条连接展示「渠道名称/ID」「服务商」「渠道类型」「状态」「服务地址（Base URL）」「操作」，支持分页。名称和 ID 都可进入渠道详情。类型按当前配置显示 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、OpenAI Embeddings、火山方舟 Video Generation、DashScope Video Generation 或 MiniMax Video Generation，其他已有接口保留其类型。列表状态为「已启用」或「已停用」。行操作为「测试连接」、当前状态对应的「停用」或「启用」，以及「删除」。测试连接须先接入模型。渠道详情的「基本信息」显示类型、渠道名称、API 地址、脱敏 API Key、状态、简介及创建人／创建时间，并提供「编辑信息」。「模型列表」按模型标识和展示名称搜索，提供批量测试、获取模型列表后勾选接入、自定义添加模型，以及单模型编辑、测试和删除。添加渠道的首项为「渠道类型」，可选第三方模型服务或自有模型推理服务。「上游接口」依次展示服务商、接口格式、接口端点与服务地址。可直接录入，也可点击「从基础资料导入」，选择匹配渠道类型的已启用服务商及公开接口资料。同一服务商有多套资料时选择其中一套。导入值仅写入当前草稿，可修改或补齐。「渠道信息」依次展示渠道名称、创建方式、API 密钥、多密钥模式下的密钥策略及选填简介。批量创建时名称字段变为渠道名称前缀。保存时自动生成渠道 ID，新渠道显示「已停用」。简介与渠道配置一同保存。编辑信息支持修改类型、名称、地址、API Key 和简介。返回总表保留搜索、分页和滚动位置，测试、凭证、采购范围及删除校验沿用现有规则。

「模型运营」侧栏并列提供「渠道管理（新）」和「渠道管理（new）」。原「渠道管理」可通过旧链接访问，默认打开服务商总表，沿用现有权限。新入口 `providers-new` 默认打开「渠道视图」，可切换至「服务商视图」。渠道视图按模型分组，每条模型渠道一行，显示渠道及服务商、状态、上游模型调用标识及 API 地址、容量和采购成本。支持按模型、渠道、服务商或渠道 ID 逐行搜索、按状态筛选，并在详情返回时保留筛选和页码。「编辑」打开当前渠道的原配置抽屉，「更多」提供容量设置和成本设置。两页读取同一供给数据，复用现有编辑、权限、验证和保存操作。

服务商列表操作只保留编辑与删除，删除流程及风险确认统一使用「删除」文案，保留原两步关联检查、软归档和历史保护；服务商名称继续作为详情入口。服务商详情及其 JSON 页不提供「批量维护」，渠道表原有批量操作保持；模型渠道的单条、批量删除入口统一称「删除模型渠道」，沿用关联检查、停服下架与风险确认，不物理删除模型资料和历史。API 密钥池原「检测」操作称「测试连接」，校验行为保持。渠道名称支持预设选择及输入自定义值，输入新值后提供明确的「添加自定义渠道名称」操作。渠道 JSON 读取当前保存状态，独立汇总服务商、模型登记、连接与模型渠道数量；已删除渠道不进入当前渠道行，仍保留的模型登记照常导出，不把登记数当作有效渠道数。

模型渠道行的原「配置」入口统一称「编辑」，沿用同一编辑抽屉与保存/验证校验。新增渠道的「模型」选项使用名称与模型编码组合展示（名称 · 编码），选择仍按稳定模型 ID 定位并联动模型编码，不合并存储。渠道名称可选择官方、自营、转售或输入自定义名称；新建默认自营，切换模型不覆盖手工名称；编辑沿用存量名称，连接名称字段仍独立。容量表下方的「添加容量指标」打开复选弹窗，可一次选择多项后「添加所选项」；已添加指标勾选禁选，取消不修改容量草稿，添加保留已有数值；RPM/TPM、单位转换、保存校验、修订冲突和取消保护不变。

服务商总表将「服务商」和「服务商编码」拆成独立两列，服务商 ID 不在列表显示；名称下钻、编码复制和按 ID／名称／编码搜索保留，永久 ID 的存储、关联、详情与 JSON 查询不变。模型总表及服务商下钻的模型渠道、待配置模型、已登记模型抽屉和模型详情供应服务商表，继续按原有方式合并名称与编码展示；模型表头为「模型」，名称在上、编码在下，保留编码复制、详情、分组及其他永久 ID 列。

- 停用、删除或解除先检查服务及已发布路由引用，提示真实影响；全局停用与当前路由摘除分开。保存渠道不自动改服务映射、售价、路由或上架。旧报价、密钥、价格历史和审计保留。

## 密钥与维护

- 密钥库与租户 API Key 独立。只保存掩码、SHA-256 去重指纹及引用元数据，明文不进入草稿、存储、审计、日志或产物；不宣称已接服务端凭证库。
- 产品继续使用 API 密钥，不改名 API 凭证。服务商密钥页维护密钥资产和分组；渠道的密钥池维护多条绑定、启用状态和 1–100 优先级，数值小者优先，同级按列表顺序。旧专属、默认及共享组引用不自动转换；移除“设为主要”入口，已有组顺序保留。
- 渠道列表和渠道模型展示健康状态；健康与启用分开。逐渠道模型、逐密钥检测，结果展示时间、HTTP 状态、耗时和失败原因，支持确认、取消和重试。结果有效期为 24 小时；地址、模型映射、密钥版本变化要求复测；单 Key 通过不代表整个密钥池正常。检测只写诊断历史，不修改启用、映射、路由或价格；本地结果标识“模拟检测”。
- 密钥池变更走候选配置→逐条测试全部启用密钥→明确应用，校验全部必要模型及服务影响；单 Key 通过不能替代其他 Key，失败、过期、待完成及不匹配回执均不放行。未关联模型须先接入模型再验证。本批不新增自动轮询、额度调度或熔断冷却。
- 密钥按实际渠道引用聚合，长 ID 可换行；没有密钥不伪造占位记录，不把未关联旧渠道作为整个模型目录的错误。添加/替换不回显原文，沿用可见 ASCII、长度、重复和数量校验，保存只提交脱敏信息。
- 正常轮换与撤销分开：正常轮换不自动撤销旧 Key；专属渠道和共享组按实际引用范围处理，不能误改其他渠道。替换/删除等影响动作保留确认、稳定身份/关联规则及验证失效处理，相关细节见[接入规格第 23 节](MODEL_ONBOARDING_SPEC.md#23-目录外接入与日常维护简化2026-10-31)。
- 渠道配置只选择服务商密钥组并显示可用数量、主要密钥脱敏值及状态。「管理密钥池」进入服务商 API 密钥池并定位所选组，离开前沿用未保存保护，已有渠道可返回配置。渠道专属密钥随渠道提交。渠道配置与测试不再内联添加共享密钥。测试切换密钥组仅作用本次检查，明确修改渠道配置才持久化；测试结果单一呈现，接口不匹配优先于旧通过记录。测试/调用明确提示用量确认，保留取消、重试和失败恢复。
- 地址和 Key 维护先保存候选并测试，通过后仍需明确应用；失败保留当前配置。历史恢复入口共用固定范围和有效性校验，不保留绕过检查的旧结果直达路径；不因测试成功自动启用、改路由或上架。
- 成功、超时等模拟场景选择只在地址参数 `devtools=1` 的研发视图显示，普通业务页面隐藏；测试结果保留实际来源，不将本地 Mock 记为真实上游证据。

- 模型服务列表的「更多」提供「删除」。确认前检查启停、上架、路由、草稿、映射和未完成任务，存在订单、调用或套餐引用时拒绝删除并提示归档或先处理引用。删除后移出服务目录，保留模型资料、渠道、价格、路由及审计历史；再次添加同一模型复用稳定 ID，并重新选择服务模式，旧价格与路由不自动生效。

## 模型服务与调用路由

- 「模型运营 → 模型链路」位于「模型服务」之后。页面展示协议、网关、模型服务、路由策略、协议转换、渠道、渠道模型。渠道展示接口格式、请求端点和启停状态。渠道模型展示上游标识、优先级、权重和启停状态。权重仅在加权随机时生效。模拟请求回放依次展示候选校验、优先级选组、组内选路、协议转发和响应。视频生成回放以任务受理结束。画布使用只读模拟配置。

- 「模型运营」侧栏显示「模型服务」。旧模型服务、旧渠道管理和旧渠道别名已退出导航，原地址回到当前工作区概览。

  - 多模态理解：图片理解、视频理解、文档理解、视觉问答。
  - 视觉模型：文生图、图生图、图像编辑、文生视频、图生视频、视频编辑。
  - 语音模型：语音识别、语音合成、语音对话、语音转语音、音乐生成、音频理解。
  - 向量模型：文本向量化、图像向量化、多模态向量化。
  - 重排序模型：文本相关性重排、多模态重排。
  - 其他专用模型：文本分类、内容审核、翻译、3D生成。
- 服务状态为「已启用」或「已停止」。启用要求有效的已登记渠道。停止前检查广场关联及上架状态，已上架的关联模型需先下架。停止后，在模型广场、项目授权和原型调用中按服务标识排除对应调用入口。列表的「编辑」只修改模型服务名称。
- 「删除」仅在已停止时可点击。点击后检查广场关联、上架状态和租户授权，解除广场关联并移除现有租户授权后方可确认。已删除服务保留审计和原有调用历史。
- 「渠道模型」顶部可单选当前模型服务的路由策略。支持 LiteLLM 的加权随机、最少并发、低延迟优先、按用量分流和成本优先，未设置的服务默认使用加权随机。保存后更新当前策略，切回加权随机时读取已保存权重。按用量分流展示渠道的 RPM 和 TPM 上限，成本优先提示缺少有效采购价的渠道。
- 「渠道模型」在所有策略下显示「优先级」和「权重」。非加权随机时，权重保留原值并置灰，权重输入框和「批量设置权重」禁用，优先级仍可编辑。权重表头及禁用控件提示「仅在「加权随机」策略下生效，用于在同优先级的可用渠道模型之间分配请求。」
- 上下文长度路由可配置 Tokenizer 和各已启用渠道的上下文长度。关闭时保留配置。开启后可输入请求 Token 数预览。预览先排除停用、不可用及上下文不足的渠道，再取优先级最靠前的一组。加权随机展示预计分流比例，其他策略展示候选渠道。
- 「模型服务 → 添加模型服务」提供模型服务名称、模型调用标识、从基础资料带入、模型类型、备注、服务描述及可展开的模型资料字段。名称和调用标识必填，描述最多 300 字。模型资料选项按「模型展示名称（模型编码）」显示，选定后带出对应类型。未关联模型资料的服务可先保存，并通过基本信息补关联后再添加渠道。
- 模型服务、服务状态、路由策略和渠道配置保存在 5.12.0 共享工作区。模型资料和已登记渠道用于只读引用。没有通过检查的登记渠道时，添加弹窗提供三条标明「模拟渠道」的同模型选项，用于演练优先级、权重及启停。场景数据由用户选择后随服务保存，已有模拟关联可继续维护。已有配置随记录保留，真实服务地址及调度需网关集成。

已保存的路由、映射、价格、销售范围及审计继续保留。旧模型服务与旧渠道管理页面已下线。

## 保存、发布与恢复

- 后台不提供草稿保存、恢复或丢弃入口。编辑输入仅在当前页面保留；测试验证连接配置，不自动启用或上架。预览展示本任务差异、范围和阻塞项；明确发布或应用后才切换对应有效版本。
- 售价发布成功后立即作用于后续新请求，含已有订购客户；已开始请求及历史保留原价格快照，内部重试不换新售价。客户展示、后台及客户调用使用同一有效版本，不提供预约调价和专属协议价。
- 地址、密钥、路由、资料、售价和客户范围按相关任务独立提交；任何发布不得顺带应用其他任务输入。保存或发布失败保留当前输入和旧有效配置。
- 离开未提交页面只提供放弃本次修改／继续编辑；刷新不恢复未提交输入。历史未发布记录原样保留，不自动应用或作为新编辑的起点；报价历史可沿用后明确提交新版本。
- 超时或结果未知先核对同一操作结果再重试；冲突显示差异并保留输入，不自动覆盖。刷新恢复已保存安全内容并重查依赖，不承诺恢复未保存输入或明文 Key。
- 操作成功后持续显示真实对象、版本和生效时间，不只使用短暂通知。不可执行时说明具体缺项或权限原因，原型不伪造成功。

## 用量数据

## Token 生产

- 保留集群纳管、模型部署、制品镜像、生产观测；制品镜像是独立入口，内部模型制品/基础镜像/运行时镜像分类保持，部署不再重复模块切换栏。
- 部署为列表、全页三步编辑与详情；模型权重/挂载路径和运行时镜像分别校验，不能把基础镜像或权重当运行时。目标/就绪副本独立，缺少历史观测显示未知，不编造监控、日志、自动扩缩容或滚动发布。
- 生命周期通过部署事务原子同步集群分配、部署状态和端点；停止/失败只释放一次，重启复用端点。失败/停止可修复重建，待处理任务不能更新；扩缩容不增加配置版本。回滚保留完整旧配置，当前及回滚权重/镜像引用受保护。
- 部署不自动发布销售服务或改供应/价格；仍为本地生命周期模拟。详细规格见[模型部署设计](../../docs/admin-v2/MODEL-DEPLOYMENT-DESIGN-5120.md)，布局与验收沿用[后台通用约束](../../docs/PAGE-SPEC.md#后台视觉实施与验收)。

路由及映射不提供“查看调用示例”，模型服务不提供“调用指南”入口。普通服务在「路由及映射」表内选择合格渠道，经核对和确认后建立映射并发布路由。

路由策略、参与渠道及权重默认只读。编辑态提供「取消」和「核对配置」，核对态提供「返回修改」和「确认保存并生效」。取消放弃本次草稿。保存经现有权限、并发和策略校验后生效并返回只读，失败保留输入。

渠道直选的「路由配置」在当前服务对应渠道行组下方展开，保留详情页头、原表格及服务商分组，每次仅打开一个编辑区。主渠道选择、对外接口、转发方向和上游接口使用紧凑白底表格，连线与箭头表示转发关系；不重复模型调用标识、上游标识、服务商及固定策略。列宽随实际内容区分配，协议、地址和按钮能单行时不强制换行，空间不足时仅在表格内滚动或按可用宽度换行，不撑宽整页。对外接口地址从部署配置 VITE_MOMA_API_BASE_URL（当前原型默认 http://xxxx）拼接为完整 HTTP(S) URL，保留部署路径前缀且不重复 /v1；不在界面显示变量，不使用上游地址或当前页面域名代替网关，未配置时明确显示未配置且不提供无效复制。上游地址读取当前渠道配置。展开配置时，上方渠道表暂收起重复的协议和地址列，关闭后恢复；两侧协议与完整地址分别对齐，地址和复制按钮保持同行，窄屏使用表内滚动。转换列只显示原生转发或协议转换，具体协议由两侧字段表达；其他渠道区不重复列出当前正常主渠道，没有其他条目或异常时不显示。「添加路由」依次选择对外接口、具体的转换方向、匹配的上游接口，后两项由前一项解锁，变更上一步会清除下游选择。上游接口下拉仅显示当前主渠道已登记的匹配地址，协议由转发方向显示。同一对外接口只有一条路由，已有路由在原位置编辑，保留其对外接口。完成一条后可继续编辑其他条目。保存前核对变更的接口、转发方式、上游地址和主渠道。确认后随路由版本原子保存，列表和映射详情显示已生效配置。OpenAI Responses 和 Anthropic Messages 到 OpenAI Chat Completions 的转换是配置演示，网关协议转换和对外接口调用不在本原型流程执行。

模型服务列表提供实际模型调用标识、API 路径、协议与完整端点的核对和复制，不再提供后台调用示例编辑页签。

点击「模型服务」先进入列表。以一个模型服务永久 ID 为一行，渠道直选的同一模型不同服务独立显示，不再合并名称或操作。列顺序：模型服务名称 / ID、模型调用标识、API 路径、API 协议、关联的渠道、模型编码、模型服务状态、API 端点、操作（路由及映射｜故障转移配置｜更多）。名称与永久 ID 同列，ID 不因名称或调用值变更而变化，支持完整复制及悬停查看；未关联渠道、尚未形成具体服务的配置项显示待配置，不补造服务 ID。关联渠道按实际模型映射或渠道直选关联定位，展示服务商名称（渠道名称）和完整渠道 ID，不用连接 ID 替代。渠道或端点有多项时首项加数量，点击查看全部。API 路径含方法与路径，协议逐项对应，端点为平台对外完整地址；仅展示真实开放的接口，不把上游地址或仅声明的接口当成已开放平台端点。模型服务状态为已启动／已停止，与销售上架独立。第一列和操作列固定，窄屏只固定操作列，表格局部横向滚动；每批展示 20 条服务，计数以服务为单位，待配置项单列计数。搜索覆盖服务名、永久 ID、调用标识、模型编码及关联渠道名称/ID，筛选命中具体服务行。详情定位所选服务的路由及渠道上下文，面包屑返回恢复筛选、已展示数量和滚动位置。删除以所选模型服务永久 ID 定位，只处理该调用入口；校验启停、上架、路由/草稿、订单/调用及套餐引用，确认后移出列表，其他服务、模型资料和历史记录保留。列表、详情和 JSON 页均不提供模型服务批量维护；详情页签为路由及映射、故障转移、操作记录，不提供调用指南。

列表和详情页头均可打开「批量新增模型服务」弹窗。模型通过可搜索多选下拉选择渠道管理中已登记的模型，每批最多 5 个；触发器只显示首个标签和剩余数量，剩余项可展开查看，另显示已选数量，不因多选撑高或截断整个控件。服务模式为统一模型服务模式或渠道直选模式，各提供可悬停或键盘聚焦的说明：统一模式由平台在合格渠道间调度；渠道直选由用户指定渠道服务，在选定范围内调用。名称、类型从所选模型读取。保存后模式固定，原子创建且不自动关联渠道、启用或上架；失败保留选择，取消保留未保存保护。具体规则见本章模型服务批量创建条款。

从渠道检测或接入任务进入服务管理时，按明确的主档引用打开已有服务；若需新建，沿用该主档与类型。主档缺项时显示「维护模型资料」入口。服务端核对供应登记和重复服务，保留已有稳定 ID、资料、供应、价格和路由历史。

## 模型运营维护交互

- 模型资料基础字段默认展开，高级模态任务、能力、参数和来源分组收起；查看编辑用同一类型名称与上下文单位。编辑共享卡片前提示影响服务。
- 接入模型内联搜索多选，一次提交后可继续接入渠道。接入渠道可新建或复用当前服务商已有连接，复用只新增模型关系，不改共享地址、密钥或其他模型成本。采购项优先显示对应类型常用项，保留全部搜索。
- 渠道或映射被生效路由、草稿引用时禁止解除关联。引用检查继续使用原业务数据。
- 模型调用标识维护先下架停服，核对原值与新值并确认客户迁移；保持规范身份、记录ID及历史，不创建自动别名。归档服务须无活动路由、草稿、映射、服务商和未完成任务；归档记录及恢复条件保留，不提供列表归档入口；恢复保持下架停服。
- 字典中文名和单位优先，英文与内部标识为辅助；密钥紧急动作位于更多操作中并明确影响。操作记录支持搜索、类型筛选和安全的旧新值摘要；旧记录无快照时明确缺失，不回填虚构值，不展示凭证。

## 渠道成本与模型售价

- 模型销售支持按模型展示名、服务商和状态组合筛选。模型及服务商选项按稳定 ID 去重。筛选和分页写入 URL，详情面包屑返回时沿用原条件。

- 渠道管理的模型总表、服务商详情和模型详情渠道表的「成本」共用同一有效采购记录与单元格，使用一个展示列，每条渠道占一行，多个计费项在同一成本单元格内横向排列，以分号分隔，窄屏按可用宽度换行；每个计费项按名称、适用条件、价格、币种及单位组合展示，例如「输入 Token：1.00 元/百万 Token」。人民币显示元，其他币种按记录显示。成本设置表单及数据库分别保存计费项、金额、币种、单位和条件。模型总表展示有效采购价、币种及适用条件。「成本设置」按当前渠道打开 960 px 宽抽屉，标题显示渠道名称及成本设置，顶部显示服务商与模型。每条渠道分别维护计费项、条件、币种、价格、单位及历史版本；首次无采购配置时为空。下一步预览发布配置生效及到期时间，确认成功后刷新当前表格。复用采购版本事务、角色、修订冲突、失败输入保护与未保存保护。零价与缺价分开，调价不追改旧请求及价格快照，不清除技术证据。
- 成本、售价、渠道和资料通过同一 D1 读写边界；直接 URL、刷新、权限、冲突及失败输入保护与原模块一致。新增对象不因缺价落入另一套本地存储。
- 渠道详情的「模型列表」按模型行展示容量，并通过「容量设置」维护。容量只展示已配置指标：零项显示「未配置」，一至两项直接显示数值和单位，超过两项显示前两项及「更多 N 项」，浮层只列剩余指标。「容量设置」独立放在渠道操作中。缺失值不代表零或无限。容量设置使用 960 px 抽屉，分别维护 RPM、TPM，并按需添加并发上限、RPD、TPD、RPS、输入 TPM、输出 TPM、IPM；TPM、输入 TPM 和输出 TPM 以百万 Token/分钟展示和填写，最多 6 位小数，保存时精确换算为 Token/分钟正整数；其他指标须为正整数。容量按渠道稳定关联 ID 独立保存到当前渠道的 `capacityLimits`，不从同模型、同服务商或共享连接继承或联动。保存沿用 D1 事务、权限、修订冲突、失败保留输入和未保存保护；查看及取消不写入，容量变化不清除连接测试、报价或路由。这里记录上游额定限额，不代表实时剩余额度或网关限流执行。
- 模型售价按统一模型服务模式或服务商服务的稳定 ID 定位；详情仅保留售价配置、变更记录；不提供销售设置、查看关联成本或查看服务与路由入口，售价金额下不展示采购成本提示。变更记录仅展示当前服务的计费项与售价版本，含价格版本 ID、版本号、生效时间、计费项、金额、单位和币种，不混入上架、可见性、渠道、路由或销售范围操作。完整审计记录保留在原存储与模型服务操作记录中。既有销售范围及经营校验不变；失效价格不作为生效价，历史价格按原服务及代际查阅。
- 内部服务不要求售价且不销售；变更用途必须停服、停售并核对商业依赖。无法核对时阻断，不自动收费、退费或重写权益。
- 管理端模拟记录保留调用时来源、成本版本及计量依据；无成本待核算，内部验证无订单／订阅／销售费用；同操作 ID 重放不重复写版本、请求或费用。

- 管理端模型字段按实际归属命名：主档业务身份为「模型编码」，客户调用参数为「模型调用标识」，渠道上游调用参数为「上游模型调用标识」，内部主档键为「资料 ID」。主档/服务/目录别名的可读名称用「模型展示名」，名称取值和归属保留；模型服务名称独立。广场与部署中渠道直选模式展示实际渠道服务 callId，不使用父模型的 modelId 替代。限流模型目录读取主档 canonical_slug，使用「模型编码」。新操作差异按对象命名；既有审计原文、导入文件表头和数据库字段不重写。

模型运营字段、永久 ID、JSON 批量维护及模块归属统一遵守[字段与身份规范](MODEL_OPERATIONS_IDENTITIES.md)。新建及存量对象均须符合规定前缀与 UUID v4 格式。具体模型服务统一使用 model_service-UUID；旧前缀须通过专用事务同步迁移全库主键与引用，不保留公开旧号或别名。


「查看 JSON」按模块、服务商、模型、服务商下模型或具体模型服务层级进入独立页，标题与导出范围一致。总表按钮在模块页头，详情按钮在对象信息区右侧；模型广场的模型操作提供模型级入口。当前范围完整 JSON 不受搜索、分页、折叠或页签影响，全文自然滚动并可复制，支持刷新和来源上下文返回；对象和数组支持逐层展开／收起以及全部展开／收起，默认全部展开；收起后显示字段或项目数量，空对象、空数组及基本值完整保留。折叠仅影响浏览，完整复制与批量维护始终使用完整 JSON。无效对象不回退全量。v2 JSON 使用 scope、target、revision、rows 和只读 references，字段、共享对象、价格历史和回导规则遵守[字段与身份规范](MODEL_OPERATIONS_IDENTITIES.md#批量维护-json)。JSON 页及来源页面的批量维护使用同一 target，复用宽抽屉和原子保存；越界、篡改只读引用、过期修订等整批拒绝，连接变更预览显示受影响渠道。

## 后台访问控制

- 「租户管理」集中办理个人及企业开户和资料状态维护。企业详情提供「基本资料」「租户管理员」「组织及成员」「模型开通」「项目」「API 密钥」。系统管理员在后台企业详情查看或维护组织及成员，复用成员规则和操作记录。指定管理员及停用、启用操作从「租户管理员」页签办理。个人详情提供基本信息、模型开通、项目、API 密钥。资源接口独立验证系统管理员会话及租户对象范围，审计保留实际操作者。
- 「模型开通」列出当前租户已授权的模型服务，可按名称或调用标识搜索。系统管理员从未授权且符合上架与销售范围的模型中新增开通，并对单个模型设置 RPM、TPM 或确认移除。限流在当前租户的项目间共享，同一模型的各调用标识共用限流。TPM 仅适用于按 Token 计量的模型。开通仍受订购等调用条件约束，移除只撤销本租户授权。
- 「项目」按租户展示项目清单和详情。有权操作的系统管理员可在清单直接新建项目，保存后刷新清单。点开项目后，可在新浏览器页签配置当前项目，「查看记录」集中提供项目用量、调用日志和审计日志。配置和记录绑定当前租户及项目。租户汇总用量在「运营分析 → 用量数据」按客户查询。查看项目密钥时可返回该项目。
- 租户基本信息提供 L0 至 L5 的服务等级选择，列表可查看等级。资料只展示业务字段和已填写的扩展信息。租户项目清单显示已配置模型数；项目详情显示已记录的创建人。
