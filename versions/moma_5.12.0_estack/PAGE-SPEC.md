# 5.12.0 页面当前约束

本文件汇总本版本已确认的页面与业务约束，替代原 AGENTS 中按日期追加、互相覆盖的页面指令。按任务读取对应章节；实现完成情况及发布证据见 PROGRESS。模型运营采用用户已确认的 [UX v1.0 基线](MODEL_OPERATIONS_UX_DESIGN.md)，实施与验收按 [分阶段计划](MODEL_OPERATIONS_UX_IMPLEMENTATION_PLAN.md) 和 [当前验收要求](MODEL_ONBOARDING_ACCEPTANCE.md) 执行。当前源码保留并行工作；P1—P3 实现及 P4 技术证据见实施台账，已发布至既有 Cloudflare Pages 项目，真人新人试用仍待验收。本文不替代实际验收或上线记录。

## 全站 Mock 数据与双面联动

- 5.12.0 初始资源、参考目录和模拟响应统一在 `src/mock/` 配置维护，管理端模型运营运行数据由 Workers + D1 统一持久化，其他模块通过版本内浏览器业务存储关联；详见 [Mock 数据合同](MOCK_DATA.md)。本节替代共享页面中“组织及成员仅保存在独立前台样例”的旧约束，仅适用于本版本。
- 系统初始数据与用户配置分开标记；恢复存档不重放初始生成器、不补回删除资源。手工记录、草稿、订单、历史与未知来源数据保留，旧无归属记录不自动认领。
- 前台 Key、订购、组织及成员、客户智能路由和在线体验记录落到共享业务集合；客户作用域、所有者、修订冲突及存储错误在写入边界校验。后台修改相同记录后，前台经事件、同源标签页更新或聚焦复查读取新值。
- 调用日志、租户用量、平台概览及用户统计从同一请求和显式身份事件派生。未采集 Tokens、费用或时延显示未知；本地回复不构成真实上游或计费证据。图表样例继续使用静态 JSON 配置和原有派生逻辑；不写入 D1。租户侧和其他未迁移模块仍使用浏览器存储，不与 D1 自动双写。
- 前台编辑在打开时冻结修订号，跨标签页更新不得静默覆盖当前输入；冲突保留输入并要求刷新。账号/客户切换清除旧临时表单及明文 Key，已保存筛选视图按身份隔离。关闭 Key 额度后保存/刷新保持不限，相同额度与周期重新启用保留原用量；TPM/QPM 按实际值保存和模拟校验，不豁免客户额度与权限。
- 统计分类匹配实际模型类型，基础模型筛选纳入其供应商服务调用；请求保留发送时调用 ID，未知计量不填零，音频秒数/字符与 Token 分开。不使用固定样例数作为当前套餐权益或剩余额度。
- 动态历史样例只绑定固定初始资源且保留有效归属，不能因新增/编辑 Key、模型或成员而重分配历史；用户真实动作产生的请求独立保留。重复 Request ID 校验 Key、客户、模型及服务归属，冲突不返回原记录，已撤权 Key 不能重放成功。

## 模型运营云端持久化

- `listing`（含接入向导）、`providers`、`model-templates`、`tariff-dictionary` 使用 `/api/5120/`。模型资料、供应商、密钥组/池、渠道及映射、采购/售价历史、服务、路由、检测与试调用、发布和操作审计均落 D1；筛选和未提交输入保留在浏览器。
- 后端以 HttpOnly 会话确认账号及权限，复用 5.12.0 领域规则；前端提交预期修订和操作 ID。业务变更、模拟状态、回执和审计一次原子保存，成功后才关闭编辑；失败保留输入，未知提交结果先核对原操作，冲突要求载入最新数据。断网不回退为本地保存成功。
- 仓库 JSON 只作为首次导入与只读参考来源；已有 D1 不因刷新、发布或切换演示范围重置。完整历史静态模型集合保留原 ID，默认仍展示两个运营案例；旧版价格按原记录保留，不能补造当前生效价格或检查证据。
- 本期仅管理端模型运营切换。用户浏览器旧存档保持原状，不隐式导入、合并或删除；租户侧订购、体验、计费及后台统计继续沿用原范围，不能把管理端 D1 模拟当作真实上游或租户网关。

## 导航与共享页面

- 模型运营登录保留账号、密码与原认证流程；错误信息紧邻表单。窄屏自适应，短窗口允许滚动，文字、控件及键盘焦点保持可读可达。
- 后台 2 运营分析为用量数据、用户数据、供给数据、经营数据四个同级入口；运营和系统管理员可访问，运维不可访问。运维入口称调用数据，保留 `call-analysis` 路由。模型运营依次为模型接入、模型服务（默认入口）、模型资料；模型资料含模型、计费项、计价单位、货币四个 Tab。
- 不提供独立 `service-routing` 页面；路由在模型工作区“路由及映射”维护，领域事务、历史配置和数据保留。概览为运营默认首页，不恢复旧独立工作台或安全治理模块。
- 运营导航底部的入门指导分组保留“模型运营”指南（`getting-started`），运维不可访问；接入和维护流程就近提供帮助，不强制先读教程，不因首次登录强制新建。模型接入不恢复旧使用引导弹窗。
- 面包屑复用版本内 `breadcrumbs.mjs`。向导为“模型运营 > 接入并上架模型”，返回注明来源；任务跳转保留模型、页签、筛选及当前输入，缺失对象不静默替换。普通详情不重复返回按钮；独立订购页返回当前版本订购入口。
- 租户空间、账号认证、调用日志、API Key、客户与后台账号沿用[对应共享页面章节](../../docs/PAGE-SPEC.md)；5.11.0 删除的用户管理、账号管理、Token 生产等不适用于本版本。前台隐藏模型排行，组织及成员/组织操作记录仅政企空间，调用日志不向个人空间渲染。

## 模型身份与资料

- 术语由 [GLOSSARY](GLOSSARY.md)定义：模型资料、供应关系和销售服务各有职责，资料 ID/模型编码/上游模型 ID/对外调用 ID 不混用，模型作者不等于供应商；采购参考价、采购价和平台售价分开。完整 URL 称请求地址，Key 按当前绑定渠道表达。
- 模型资料库统一维护当前主档；按稳定 ID、显式关联或精确编码识别模型，不按名称近似合并版本。已有运营资料是主档，旧模板不能成为第二个可编辑来源；服务和供应页面读取同一主档。
- 六类主要用途为语言模型、视觉理解、视觉生成、语音模型、向量模型、重排模型；语言模型可支持图像/视频输入，不能仅因名称含 VL 或具备图像能力改类。既有类型代码、图像/视频任务及计量单位保留。输入/输出模态与向量/相关性等结果类型区分，未知能力/规格保持未填写。
- 资料库保留表格、查看、编辑及删除入口；长内容提供完整值的可访问查看方式，宽度不足时在表格区域滚动。资料列表名称/编码、作者、正式发布日期、类型、适用场景、模态及上下文各有语义；日期来自可核对官方首次发布记录，场景不替换为支持任务。维护分页 20/50/100、默认 20，选择流程保留自己的容量；切换容量只提交一次容量和第一页。
- 基础资料库的共享主档编辑按用途分区：模型卡片维护名称、Logo、类型、输入/输出模态、结果类型、上下文与简短介绍；模型详情维护作者、适用场景、支持语言、任务、资料链接、详细介绍及按类型展示的能力规格；模型编码、系列、版本与发布日期在“其他信息”，技术与接口属性独立展开。共用字段仅维护一次，不新增第二套卡片/详情可编辑主档。售价在“售价管理”，模式、关联和对外调用 ID 在“路由及映射”，客户范围保留页头入口。
- 前台卡片和详情读取同一份已生效资料：Logo 缺失或存储内容不合法时使用默认图标，图片加载失败时名称仍可读；详情复用卡片公共信息，并显示已填写的长介绍、模型编码、版本/发布日期、能力规格、技术接口属性及资料链接。未知属性不补零或“支持”，正式发布日期与卡片的资料更新时间分开；不把采购价、供应密钥、内部请求地址和资料核对记录投影给客户。点击卡片进入独立详情页，按面包屑、模型介绍与三项参数、服务商报价、API 调用、详细资料组织；返回广场保留当前筛选并恢复原卡片焦点。URL 保留稳定模型与服务 ID，支持刷新和浏览器前进/后退；失效或无权访问时显示不可用，不自动替换为其他服务。
- 分供应商详情每家服务商一行，展开显示全部已发布计费项、对外调用 ID 及体验入口；统一服务只有平台统一服务一行。API 调用区按获取 API Key、调用模型服务两步组织，分供应商可切换服务商并同步代码示例。密钥由既有 API Key 页面维护，不在详情复制维护表；没有订单依据不展示“已订购”，没有实际平台发布时间不冒用模型发布日期。可见性、客户授权、发布验证及任务准入条件保留。
- 前台模型广场按稳定模型 ID 聚合卡片；已有演示集时默认只展示 GLM-5.3（分供应商）和 DeepSeek-V4-Flash-0731（统一服务），“全部模型”保留其他已授权服务。按发布日期排序，不把分供应商服务计为多个模型；供应商筛选匹配卡片内各服务。分供应商详情可选择提供方，售价、调用 ID、调用示例和在线体验使用同一服务身份；统一服务使用平台统一售价和调用 ID。售价仅取平台已发布销售快照，明确币种/计量单位，未提交输入、采购价和内部渠道不对客展示。调用示例与后台复用生成规则；体验选择器和新回复显示提供方，历史回复保留当时身份。
- 主档名称、介绍、图标等在当前表单编辑，预览受影响服务并明确提交后同步引用展示；不因展示文字修改重测连接。类型、能力、模态、任务、版本及深度思考/结构化能力变更走专门影响检查，重验受影响范围；不兼容依赖先修复或明确下架，合格后发布，不直接覆盖在线配置。仅属性顺序变化不误判，稳定身份、权限、修订、存储和焦点保护保留。
- 模型运营初始数据集中于 [Mock 配置](MODEL_OPERATIONS_MOCK_DATA.md)，基础资料、供应管理、模型服务共用稳定引用与目录范围，前台读取后台生效服务。只在没有存档时初始化；已有用户配置、删除记录、凭证、草稿与历史不因刷新或配置更新被补回或覆盖。
- 删除主档须没有供应、服务或活动配置引用，界面禁用与事务校验一致。添加供应模型从主档选择，可原地新增主档并返回选中，不自动登记供应关系或渠道。批量只接受匹配主档的模型，不接受任意未匹配上游 ID，不生成空渠道。
- 对外服务正式资料沿用其现有完整校验；技术接入可以先保存最低身份资料，任务/能力缺失保持待完善，不能据此上架。资料与服务编码规则的已知差异见 [MODEL_OPERATIONS_TERMS_REVIEW](MODEL_OPERATIONS_TERMS_REVIEW.md)，不靠改名宣称差异已修复。CSV 前两列统一模型编码/模型名称，不增加旧表头别名。

## 模型接入

两条旧演示渠道 supplier-review-CH-001 / supplier-review-CH-002 及其四条初始样例映射不再作为默认数据安装；已有线上记录须核对无供应、路由、模型关联及任务引用后，通过现有删除渠道事务归档。合法手工保存的未关联渠道继续保留，不因状态文案自动清理。


模型接入页头仅保留添加供应商，移除“接入并上架模型”入口；模型、渠道继续通过供应商详情分别添加。指定的三条 D1 验收供应商及其已下架服务、独占渠道/映射和服务路由经管理员明确确认后逐条原子归档，不按名称前缀清理。保留主档、价格历史、调用与审计；存在非验收业务引用、运行中的服务、未完成任务或新增资源时拒绝归档。


- 模型接入默认进入供应商视图，视角切换按供应商、模型排列；显式模型视图链接继续进入模型视图。模型工作区提供本模型的供应接入入口；同源查询和 provider/tab 上下文继续复用。资源视角切换与搜索在目录面板内，键盘焦点和空目录可操作，不复制业务记录。
- 供应商详情不展示“供应商更多操作”及其停用弹窗；保留独立的供应商资料编辑入口。模型渠道表中的模型名称仅展示，不提供修改图标、改名弹窗或改名命令；已有供应商登记名称和配置不清空，统一模型资料仍在模型资料模块维护。渠道编辑、测试连接和删除等操作保留。
- 供应商视图仅保留模型渠道、共享API密钥两个页签；主体资料通过编辑入口维护，未知页签显示模型渠道。模型渠道表格依次为模型名称、渠道、状态、上游模型标识、上游 API 地址、计费项、渠道采购价、计费单位、操作；模型视图复用同一表格，以供应商替换首列并合并同供应商单元格。同一模型跨其渠道和计费项合并模型名称，同一渠道的状态、标识、地址及操作跨计费项合并；按模型分组分页。模型标识读取当前关联的上游请求标识，API 地址为实际模型调用地址；两列均提供可访问的复制入口，复制完整原值，缺失时显示横线且不提供复制。采购价读取当前采购配置的显式采购金额，或按原目录价及采购折扣计算，不使用渠道刊例价或客户售价；币种随金额显示，零与缺价区分。渠道采购价 tooltip 为“当前平台采购供应商的价格，用于成本及利润分析”。状态沿用真实配置及检测结果，冻结、停用、缺少模型或凭证不可标成可用。表格操作为渠道维度的编辑、测试连接、启用／停用供给、删除渠道；无渠道时渠道列显示“待添加渠道”，该模型行提供接入新渠道和删除模型。删除均先弹窗确认；只要当前供应商/渠道已被模型服务关联（包括仅关联供应商、未上架、下架、停服、停用供给），或仍被当前路由/草稿引用，就必须先解除关联，不能仅下架后直接删。未完成接入/检测任务也阻断删除。删除共享渠道时只移除当前模型关联；最后一个模型关联删除后，渠道资源一并归档，其他模型和历史记录保留。模型必须先删完全部渠道；模型删除只移除当前供应商登记，基础资料保留。后端重新校验所有者、角色及修订，失败不部分删除。编辑抽屉维护共享渠道名称、当前模型标识、API 地址及共享/独立密钥配置，以及当前模型的计费项、采购价、货币、单位和适用条件，一次原子保存；预设接口的完整任务地址须先明确确认识别出的服务根地址；地址或共享密钥组变更先保存待验证配置，再进入现有测试及应用流程，当前地址和密钥保持服务，不覆盖其他未完成候选；采购变更发布立即生效的新版本，保留旧价及其他模型配置，仅改名不产生采购版本；名称同步同渠道关联，标识不改其他模型或供应商，被服务或生效路由引用时阻断标识修改，修改后相关映射需复测和明确启用。测试连接打开当前模型供给的服务端检测任务，支持结果、检查详情、重试和原提交恢复；检测通过后单独启用供给。停用须确认影响，保留采购配置和历史；恢复不自动创建服务或上架。缺少明确接口类型的旧渠道先进入编辑，人工确认协议和地址，再验证应用，不静默改写既有连接。无渠道模型及缺报价仍展示；未关联模型的渠道不能直接发起模型调用测试。原主体资料、资源、采购/刊例价/售价版本、路由、审计与权限保护保留；跨供应商模型视图保留既有资源维护流程。模型名称只读，统一主档在模型资料中维护。
- 模型资料的名称与编辑入口共用同一个详情抽屉，宽度最多 1200px，并适配窄屏。以入口中心位置判断方向：左半屏入口从右侧展开，右半屏入口从左侧展开；切换查看/编辑保留抽屉方向。两态的字段、分组、顺序及单元格位置一致，查看用文本，编辑用控件；视觉任务类型、资料来源两态均展示，规范模型标识保持只读，内部资料 ID 不占业务界面。查看态右上角为编辑，编辑态底部固定取消和保存；取消未保存修改需确认，保存沿用资料影响核对，成功后回到当前资料查看态。表格筛选及滚动保留，关闭后焦点回入口。

## 密钥与维护

- 密钥库与租户 API Key 独立。只保存掩码、SHA-256 去重指纹及引用元数据，明文不进入草稿、存储、审计、日志或产物；不宣称已接服务端凭证库。
- 产品继续使用 API 密钥，不改名 API 凭证。供应商密钥页维护密钥资产和分组；渠道的密钥池维护多条绑定、启用状态和 1–100 优先级，数值小者优先，同级按列表顺序。旧专属、默认及共享组引用不自动转换；移除“设为主要”入口，已有组顺序保留。
- 渠道列表和渠道模型展示健康状态；健康与启用分开。逐渠道模型、逐密钥检测，结果展示时间、HTTP 状态、耗时和失败原因，支持确认、取消和重试。结果有效期为 24 小时；地址、模型映射、密钥版本变化要求复测；单 Key 通过不代表整个密钥池正常。检测只写诊断历史，不修改启用、映射、路由或价格；本地结果标识“模拟检测”。
- 密钥池变更走候选配置→逐条测试全部启用密钥→明确应用，校验全部必要模型及服务影响；单 Key 通过不能替代其他 Key，失败、过期、待完成及不匹配回执均不放行。未关联模型须先接入模型再验证。本批不新增自动轮询、额度调度或熔断冷却。
- 密钥按实际渠道引用聚合，长 ID 可换行；没有密钥不伪造占位记录，不把未关联旧渠道作为整个模型目录的错误。添加/替换不回显原文，沿用可见 ASCII、长度、重复和数量校验，保存只提交脱敏信息。
- 正常轮换与撤销分开：正常轮换不自动撤销旧 Key；专属渠道和共享组按实际引用范围处理，不能误改其他渠道。替换/删除等影响动作保留确认、稳定身份/关联规则及验证失效处理，相关细节见[接入规格第 23 节](MODEL_ONBOARDING_SPEC.md#23-目录外接入与日常维护简化2026-10-31)。
- 渠道配置和测试可打开已有添加密钥弹窗，父表单当前输入保留。测试切换密钥组仅作用本次检查，明确修改渠道配置才持久化；测试结果单一呈现，接口不匹配优先于旧通过记录。测试/调用明确提示用量确认，保留取消、重试和失败恢复。
- 地址和 Key 维护先保存候选并测试，通过后仍需明确应用；失败保留当前配置。历史恢复入口共用固定范围和有效性校验，不保留绕过检查的旧结果直达路径；不因测试成功自动启用、改路由或上架。
- 成功、超时等模拟场景选择只在地址参数 `devtools=1` 的研发视图显示，普通业务页面隐藏；测试结果保留实际来源，不将本地 Mock 记为真实上游证据。

## 保存、发布与恢复

- 后台不提供草稿保存、恢复或丢弃入口。编辑输入仅在当前页面保留；测试验证连接配置，不自动启用或上架。预览展示本任务差异、范围和阻塞项；明确发布或应用后才切换对应有效版本。
- 售价发布成功后立即作用于后续新请求，含已有订购客户；已开始请求及历史保留原价格快照，内部重试不换新售价。客户展示、后台及客户调用使用同一有效版本，不提供预约调价和专属协议价。
- 地址、密钥、路由、资料、售价和客户范围按相关任务独立提交；任何发布不得顺带应用其他任务输入。保存或发布失败保留当前输入和旧有效配置。
- 离开未提交页面只提供放弃本次修改／继续编辑；刷新不恢复未提交输入。历史未发布记录原样保留，不自动应用或作为新编辑的起点；报价历史可沿用后明确提交新版本。
- 超时或结果未知先核对同一操作结果再重试；冲突显示差异并保留输入，不自动覆盖。刷新恢复已保存安全内容并重查依赖，不承诺恢复未保存输入或明文 Key。
- 操作成功后持续显示真实对象、版本和生效时间，不只使用短暂通知。不可执行时说明具体缺项或权限原因，原型不伪造成功。

## 资费字典与参考价格

- 字典分类为计费项、计价单位、货币，中英文名称、来源/状态及货币 ISO 三位大写代码保持。计费项引用一个单位；新引用只允许启用项，已停用引用可原样保留并明确显示。未知 unitId 不推断，历史报价保存文字/单位/币种/条件快照，不随字典改名重写。
- 内置项只读，领域校验不能由伪造 builtin 标志绕过；仅自定义可新增、编辑、启停、确认删除，单位被计费项引用时不能删。创建入口统一为“新增计费项”，其他文案同称计费项；计费说明最多 160 字，默认集合不代表所有模型均支持。
- ID 显示为由稳定记录 ID 派生的完整 128 位 UUIDv5 的 22 位 Base64url 短码，不截断、不新增持久化身份；列表分别称计费项 ID/计价单位 ID/货币 ID，表单不编辑 ID，搜索支持短码、中英文及货币代码。
- 计费项按计量对象定义，缓存有效期不作计量单位；长度档、时段、模态、分辨率等条件严格区分区间端点，按秒计价不套分钟。只有计费项、单位、币种、区间/条件和实际采购金额均一致时才可合并，零价、缺价和不同手动金额不能合并。
- MoMA 官方目录是有来源日期的参考快照，只保留主站自营、合作及机密模型的按量项，排除省市节点、资源包抵扣和 TPM 预留；明确的后续参考资料更新不扩大排除范围。精确名称不一致时待核对，不猜测上游调用 ID、不套另一模型金额、不以参考目录产生可用渠道。
- 已保存报价（含空集合、零价、旧币种和自定义条件）优先于参考表；读取不迁移存储，其他供应商不继承 MoMA 报价。当前渠道采购价为明确配置金额，不复活旧目录折扣/覆盖值来推算渠道成本。
- 历史目录报价及其手动采购值保留于领域记录和历史，不恢复被移除的目录折扣/平台成本 UI。金额使用既有整数百万分位与六位小数精度；采购/销售价格各自版本化，币种分别汇总，不自动汇率换算，缺价不当零。具体历史报价及核验数量归发布/来源记录，不作为永久价格事实。

## 运营时间与事实

- 运营概览、用量、用户、供给、经营数据统一提供今日、昨日、近 7 天、近 30 天和自定义。昨日默认/重置，近 7/30 天截至昨日；自定义可选至今日、最多 365 天，禁止未来日期。北京时间今日及包含今日的范围只统计截至当前时刻的已发生事实，不补未来时段或外推全天；环比按上一等长期间的相同进度计算，用户页今日注明对比昨日同时段。图表、明细、客户下钻和导出使用同一范围；客户下钻页顶部提供同样的快捷时间、自定义范围及重置，默认继承来源日期，切换同步更新指标、模型用量和最近调用；范围写入 URL 并保留客户身份，刷新及浏览器前进后退保持一致，返回用户数据时按 URL 还原范围；保存视图恢复时重算快捷日期，自定义保留具体日期并限制至今日。月活来自明确成功登录身份事件，用户去重不能从 tenant/Key 推断；注册/构成/详情同源。租户和运维日期规则独立。
- 请求先按 requestId 取最终修订再筛选；模型/供应商/渠道来自真实关联，用户来自显式 userId、客户来自 tenantId，不能互相替代。已删除端点仍以稳定 ID 列入未归属，缺计量为待确认/断点，零值保留，非 Token 单位不相加。
- 派生 usage-demo 在读取时按北京时间自然日/小时重建，工作日、昼夜、客户和模型分布有差异，完成时段刷新/跨日稳定。调用、Token、占比、分层必须对账，关联 ID 有效；不持久化或重置用户业务记录，非派生请求和异常计量保留。

## 供给数据与经营数据

- 图表展示核心指标，保留相关数据明细入口。供给默认三图：供应商调用趋势、供应商用量占比、供应商客户覆盖热力图；同模型视角只展示成功率和P95耗时两张横向对比图，必须选定单个模型。按北京时间自然日聚合，调用趋势单日仅一个真实点位，不编造小时数据。
- 供应商用量占比为环形图，单一计量单位的已确认用量作分母，前五家以外合并为其他，中心显示同口径总量；旁侧直接显示供应商、占比、用量。点击供应商下钻渠道，其他查看完整供应商明细；空结果不画虚假零值圆环。
- 客户覆盖热力图横轴日期、纵轴供应商，每格只显示该供应商当日最终承接的去重客户数。无调用为零，客户归属缺失保留待确认；色阶显示数量，数字及提示不依赖颜色辨认。按周期去重客户数排序，默认前十家，放大展示完整集合。点击格子按对应日期和供应商下钻，抽屉明确显示该日期。
- 经营首页三图：收入与采购成本趋势、销售服务毛利排行、供应商采购成本排行。仅收入与成本同图显示两条同币种曲线；排行均为单指标横向条形图，百分比固定0—100%，负毛利保留负方向。核算不完整的销售服务不进入完整毛利排行；无经营事实时保持空状态，不填造零金额。有核对缺口但无可确认金额的日期保留断点，不能画成零收入或零成本。
- 图表提供放大和查看明细，条形可下钻对应对象；长排行默认前十，放大查看完整结果。趋势默认周期前五家供应商，可显示全部及切换图例，显隐不改变统计范围；不同系列采用稳定颜色及线型。
- 供给数据按供应商或固定同模型跨供应商比较，按实际调用渠道归属，Token/张/秒/字符分别统计并下钻渠道。重试和回退按每次上游尝试归属，平台前置拒绝不计供应商故障；跨模型/跨单位质量与成本不可直接比较。
- 供给明细为供应商业务、渠道供给、上游调用尝试三级；渠道按模型×渠道分别汇总。客户按tenantId分别去重，不累加每日或各供应商客户数作为周期客户总数。网关检查、计量测试、平台试调用不混入客户业务规模。上游质量仅取实际尝试结果和耗时，不使用客户整段回退耗时；平均耗时、样本数、失败和未知数量留在明细。

- 收入为调用用量乘当时售价的应计收入，按销售服务归属，不等于实收；采购成本逐次汇总各实际供给，与供应商成本图一致。网关检查、计量测试和平台试调用不计客户收入。

## Token 生产

- 保留集群纳管、模型部署、制品镜像、生产观测；制品镜像是独立入口，内部模型制品/基础镜像/运行时镜像分类保持，部署不再重复模块切换栏。
- 部署为列表、全页三步编辑与详情；模型权重/挂载路径和运行时镜像分别校验，不能把基础镜像或权重当运行时。目标/就绪副本独立，缺少历史观测显示未知，不编造监控、日志、自动扩缩容或滚动发布。
- 生命周期通过部署事务原子同步集群分配、部署状态和端点；停止/失败只释放一次，重启复用端点。失败/停止可修复重建，待处理任务不能更新；扩缩容不增加配置版本。回滚保留完整旧配置，当前及回滚权重/镜像引用受保护。
- 部署不自动发布销售服务或改供应/价格；仍为本地生命周期模拟。详细规格见[模型部署设计](../../docs/admin-v2/MODEL-DEPLOYMENT-DESIGN-5120.md)，布局与验收沿用[后台通用约束](../../docs/PAGE-SPEC.md#后台视觉实施与验收)。

路由及映射不再提供“查看调用示例”，调用内容统一在 API 调用指南 Tab 维护。普通服务以新增映射抽屉替代直接关联渠道入口，先保存、验证，再明确启用；不自动参与路由。

路由策略、参与渠道及权重默认只读，提供各路由功能区域的“编辑”入口，点击后修改；仅编辑态提供“取消”和“保存并生效”。取消恢复原配置并返回编辑入口；保存经变更核对及现有权限、并发和策略校验后生效并返回只读，失败保留输入。

统一服务与分供应商售价在“售价管理”Tab 内原位展示及编辑，复用同一价格表；完整显示全部计费项，金额、币种和单位清晰对应。展示态提供“编辑售价”，编辑态提供添加、移除、取消和预览变更；取消恢复当前生效售价，未保存修改仍需确认。价格表业务字段顺序为供应商名称、对外调用标识、计费项、售价、计价单位，末尾保留编辑操作列。统一服务的供应商名称读取稳定记录 provider-moma 的当前名称；该内置平台供应商在供应商目录置顶，禁止删除。分供应商读取对应供应商的当前名称。对外调用标识读取对外调用 ID（统一服务为模型级 ID，分供应商为对应服务 ID），tooltip 为“用户调用时填写的 Model ID”，在售价页只读，仍在路由及映射维护。售价单元格内保留金额与币种，不新增独立货币列；不展示适用条件输入列及售价历史区域。保留既有条件数据、历史版本及发布校验。

工作区不显示配置检查提示块；页头保留既有配置状态，接入任务继续入口保留。移除页头“维护客户范围”和“平台试调用”按钮；调用验证仍从 API 调用指南进入。渠道列表不常驻“可用”标签；供给检查结果及原因放入渠道详情。渠道详情提供明确的打开入口并保留当前对象上下文；统一服务与分供应商共用，保留详情字段、权限及原有操作确认，Esc/关闭后焦点回到对应按钮。模型映射列表明确标注“上游模型 ID”，对外调用 ID 由对应服务统一展示。Radix 表单代理控件不重复绘制。

后台 API 调用指南提供 cURL、Python、Java、Go 示例；各示例独立编辑、取消、保存并生效、复制和格式化所选 JSON。编辑时提供名称明确的“预览”和“输入代码”区域，窄屏与键盘操作保持可达；一次编辑一个示例，前台语言切换保持不变。

模型服务目录创建区仅“新增模型服务”为主按钮，移除“更多模型创建方式”及其接入/批量导入菜单；不再单独显示接入主按钮、批量导入图标或演示范围选择器。目录数量仅在标题显示。演示模型/全部模型切换位于研发说明中的模型服务案例区，使用原有目录查询和未保存守卫，已有记录与当前模型上下文保留。新增服务必须从模型接入中已登记的模型选择，候选与模型接入的模型视图共用供应登记查询，按主档去重；没有供应登记的模型资料不进入候选，已有服务的模型仍显示但禁止重复创建。进入新增服务须保留 catalogue 参数；已有服务的资料仍标记并禁用重复创建。历史与手工资料不删除、不改名、不合并。

新增模型服务只读展示引用的模型卡片，缺少正式服务必需资料时通过“维护模型资料”补全后返回；不在新建服务页另填名称、类型和能力。服务模式及对外调用标识在创建时填写。渠道检测后的“前往服务管理”打开该主档的已有服务；没有服务则直接预选该模型进入创建，不静默展示另一款模型。新增模型服务标注“已接入模型”为必选，提供“前往模型接入”入口；服务端重新检查主档和当前供应登记关系，关系已移除时拒绝保存，跳转保留未保存保护。 对尚未进入当前服务目录、但已占用内部服务身份的历史主档，创建时原子复用其稳定服务ID并保留独立主档，禁止重复创建；新服务保持未上架和调用关闭，既有供应、价格和路由历史保留。
